### Q2. 你的 C++ 水平到什么程度？

不是"会不会"，而是**具体到哪一层**。请对号入座：

| 等级 | 特征 | 影响 |
|---|---|---|
| L1 | 会写 C，没碰过 class/template | 需要先补 C++ 现代特性 |
| L2 | 会 class / STL / 引用，没用过模板元编程 | 可以开始 JUCE，边做边补 |
| L3 | 懂 RAII、move 语义、智能指针、模板 | 可以直接啃 DSP 代码 |
| L4 | 写过并发 / 无锁 / SIMD / 性能优化 | 可以直接做硬核 DSP |

> [!warning] 这个答案很重要
> JUCE 的代码大量使用模板、回调、智能指针。L1 直接上 JUCE 会非常痛苦，
> 我建议的路线会完全不同（先写 3 个纯 C++ 的 DSP demo，再碰框架）。

**另外**：你写过多少行 C++？最近一次写是什么时候？

### Q3. 数学底子还剩多少？

DSP 的门槛几乎全在数学，不在编程。请诚实评估：

- **复数与极坐标**：还记得 $e^{j\omega} = \cos\omega + j\sin\omega$ 吗？
- **z 变换 / 传递函数**：知道 $H(z)$ 是什么吗？
- **傅里叶变换**：能解释 DFT 和 FFT 的区别吗？
- **微积分**：能看懂微分方程吗？
- **线性代数**：矩阵乘法没问题吧？

> [!tip] 不用怕
> 做**效果器**需要的数学其实很窄——主要是 z 变换、差分方程、和一点复数。
> 做**合成器**需要更多（振荡器抗混叠、滤波器稳定性）。
> 做**物理建模**才需要真正的数值方法。
> 我只需要知道从哪一层开始写。

### Q4. 你要用 AI/Agent 做什么？

"结合 AI 和 Agent" 至少有 5 种完全不同的意思：

- **A. AI 当开发助手** — 用 Claude/Cursor 帮你写插件代码（最现实，马上能做）
- **B. AI 进插件里** — 插件内部跑神经网络（如 Neural Amp Modeler 那种）
- **C. AI 当音乐生成** — 插件生成 MIDI/音频素材
- **D. AI 当设计伙伴** — 用 Agent 做音色设计、参数空间探索
- **E. AI 当测试/测量** — 用 Agent 自动跑音频测试、听感对比

> [!note] 我的判断
> **A 是入口，B 是护城河，E 是效率倍增器。**
> C 已经很卷了（Suno/Udio），D 最有趣但最难落地。
> 如果只能选一个先做，我建议 **A + E**——因为这两个立刻提升你所有其他工作的速度。

## 🟡 P2 — 工作方式

### Q8. 你希望 Agent 的介入程度？

| 模式 | 描述 | 风险 |
|---|---|---|
| 助手 | 你写，Agent 查资料、解释、review | 慢但学得牢 |
| 结对 | 你设计，Agent 实现，你审阅 | 平衡 |
| 代笔 | Agent 写，你审阅和调试 | 快但学不到 |
| 自动 | Agent 全自动，你只看结果 | 知识库会被污染 |

> [!warning] 我推荐"结对"起步
> 因为你的目标里同时有"**构筑知识库**"和"**开发插件**"。
> 如果 Agent 全代笔，知识库会变成 AI 的自言自语，你三个月后看不懂自己库里的东西。
