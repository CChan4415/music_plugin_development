# 位深与动态范围

> [!important] 一句话
> **位深决定动态范围**，公式是 $\text{DR} \approx 6.02N + 1.76$ dB。
> 每多 1 bit，动态范围增加 **6.02 dB**。

## 采样率 vs 位深：两个独立维度

> [!important] 别混淆这两个
> | | 决定 | 单位 | 提高它得到 |
> |---|---|---|---|
> | **采样率** | 频率**带宽** | Hz | 更高的频率上限 |
> | **位深** | 动态**范围** | bit | 更低的噪声底 |
>
> **提高采样率不会让量化噪声变小。**
> **提高位深不会让高频变得更好。**

| 位深 | 理论动态范围 | 量化台阶（±1.0 满幅） |
|---|---|---|
| 8 | 49.9 dB | -42.1 dBFS |
| 12 | 74.0 dB | -66.2 dBFS |
| **16**（CD） | **98.1 dB** | **-90.3 dBFS** |
| 20 | 122.2 dB | -114.3 dBFS |
| **24**（专业） | **146.2 dB** | **-138.5 dBFS** |
| 32（float） | 1529.2 dB* | -138.5 dBFS |

> [!note] 32-bit float 那行的星号
> 1529.2 dB 是**理论指数范围**（$20\log_{10}(\text{max}/\text{min\_normal})$），
> 但在 ±1.0 附近的**实际精度**只有 -138.5 dBFS——
> 也就是**和 24-bit 定点一样**。
>
> 见 [[浮点音频表示]]。

---

## 一、公式验证

**理论**：满幅正弦的量化 SNR

$$\text{SNR} = 6.02N + 1.76 \ \text{dB}$$

**实测**（本库验证，整数周期正弦）：

| 位深 | 理论 DR | **实测 SNR** | 差 |
|---|---|---|---|
| 8 | 49.92 dB | 49.74 dB | -0.18 |
| 12 | 74.00 dB | 73.75 dB | -0.25 |
| 16 | 98.08 dB | 97.84 dB | -0.24 |
| 20 | 122.16 dB | 122.68 dB | +0.52 |
| 24 | 146.24 dB | 146.71 dB | +0.47 |

> [!important] 公式验证通过（最大偏差 0.52 dB）
> 偏差来自量化误差与信号的**轻微相关性**——
> 不加 dither 时误差不完全随机。
> 见 [[抖动 dither]]。

**为什么是 6.02**：

$$20\log_{10}(2) = 6.0206 \ \text{dB}$$

每多 1 bit，可表示的幅度范围翻倍 → +6.02 dB。
1.76 dB 是量化误差（均匀分布）+ 正弦信号功率比的常数项。

---

## 二、量化台阶的实际含义

| 位深 | 台阶（相对 ±1.0） | 折合 dBFS |
|---|---|---|
| 16 bit | $1/32767 = 3.05\times10^{-5}$ | -90.3 |
| 24 bit | $1/8388607 = 1.19\times10^{-7}$ | -138.5 |

> [!warning] 这不是"能听到多小的声音"
> 上面是**单个台阶**的大小。实际能听到的最小信号取决于：
> - 量化噪声的**频谱分布**（白噪声 vs 集中在某处）
> - 是否有 **dither**
> - 播放环境的噪声底（房间通常 30-40 dB SPL）
>
> **16-bit 的 98 dB 动态范围远超任何听音环境。**

---

## 三、什么时候真的需要 24 bit

> [!tip] 实用判断

| 场景 | 16 bit 够吗 | 原因 |
|---|---|---|
| **最终发行**（CD/流媒体） | ✅ 够 | 播放环境噪声底 >> 量化噪声 |
| **录音** | ❌ 不够 | 需要 headroom + 后期增益 |
| **混音中间文件** | ❌ 不够 | 多次处理累积误差 |
| **插件内部处理** | ❌ 不够 | 用 float（见 [[浮点音频表示]]） |
| **母带** | 🟠 边际 | 24 bit 更保险 |

> [!important] 关键区别：**"发行位深" vs "处理位深"**
> - **处理链**用 32-bit float（或至少 24-bit）
> - **最终输出**才降到 16/24-bit
>
> 中间环节用 16-bit 会**累积量化误差**——
> 每次处理都加一次噪声，几十个插件叠加后就听得出来了。

---

## 四、降位深必须加 dither

> [!danger] 这是"降位深"时的必做步骤
> 从 32-bit float 降到 16/24-bit 时，**必须加 dither**。
>
> **实测**（1 LSB 幅度的小正弦，16-bit）：
>
> | dither | 谐波 | 噪声 | 谐波−噪声 |
> |---|---|---|---|
> | **无** | **-101.0 dB** | -147.1 dB | 46.1 dB |
> | **TPDF** | **-126.8 dB** | -135.4 dB | 7.5 dB |
>
> **谐波降低 25.8 dB**——失真的"性质"从刺耳的谐波变成了宽容的宽带噪声。
>
> 见 [[抖动 dither]]（含噪声整形的实测数据）。

> [!warning] 什么时候**不**需要 dither
> - **32→32-bit float**：没有量化，不需要
> - **插件内部**：绝对不要（白白增加噪声）
> - **32-bit float → 24-bit**：边际（差距 -138 vs -144 dB）

## 五、整数 vs 浮点：行为的本质区别

| | 定点（int16/int24） | 浮点（float32） |
|---|---|---|
| 超出范围 | **硬削波 / 回绕** ⚠️ | **只是损失精度** ✅ |
| 动态范围 | 固定（由位深定） | 巨大（指数部分） |
| ±1.0 处精度 | 由位深定 | -138.5 dBFS |
| 处理累积误差 | 每次处理都加 | 相对误差恒定 |
| 存储 | 小 | 大（但现代不是问题） |

> [!danger] 定点溢出的两种行为
> | 类型 | 溢出行为 | 后果 |
> |---|---|---|
> | **饱和**（saturating） | 钳到最大/最小值 | 失真但可控 |
> | **回绕**（wrapping） | 从最大跳到最小 | **极刺耳的爆音** |
>
> int16 的"回绕"会让 +32767 变成 -32768——**符号翻转**，
> 听起来是完全的噪声。所以整数处理必须小心增益结构。

> [!important] 这就是为什么插件内部用 float
> 浮点溢出不会崩，只会丢精度，而且**可以恢复**（把增益降回来）。
> 定点溢出是**不可逆**的信息丢失。

## 六、AI 会怎么写错

| # | AI 常犯 | 后果 | 怎么查 |
|---|---|---|---|
| 1 | **在插件内部用 int16 处理** | 累积量化噪声 | 内部应全程 float |
| 2 | **降位深不加 dither** | 低电平谐波失真（实测差 25.8 dB） | 检查最终输出级 |
| 3 | **32→24 bit 也加 dither** | 无意义的复杂度 | 差距太小，边际 |
| 4 | **以为浮点溢出会削波** | 概念错误 | 浮点只是丢精度 |
| 5 | **整数运算不回绕保护** | 爆音 | 用饱和，或转 float |
| 6 | **16-bit 中间文件** | 多级处理后噪声累积 | 用 float |
| 7 | **说"24-bit 更温暖"** | 无意义 | 位深只影响噪声底 |
| 8 | **混淆"位深"与"采样率"** | 概念错误 | 见开头对照表 |
| 9 | **忘了归一化约定**（32767 vs 32768） | 差 1 LSB | 统一约定 |

> [!danger] 第 1 和第 2 条是一对
> AI 写一个"16-bit 效果器"，会在内部用 int16 处理**并且**不做 dither——
> 两个错误叠加，结果是**明显的低电平失真**。
>
> 但如果你只用满幅信号测试，**听不出来**（满幅时量化台阶相对很小）。
> 要在**低电平**下测。

## 七、常见坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 低电平有"沙沙"的谐波 | 降位深没加 dither | 加 TPDF dither |
| 多级处理后噪声变大 | 中间用了低精度 | 中间全用 float |
| 导出后听起来比预览差 | 导出时没 dither | 最终级加 dither |
| 整数溢出爆音 | 回绕 | 用饱和或转 float |
| 增益调整后失真 | 定点 headroom 不够 | 用 float 内部处理 |
| 大幅提升音量后噪声爆炸 | 放大了已有的量化噪声 | 源头用更高精度 |

## 八、怎么验证

```python
import numpy as np

def measure_snr (bits, f0=1000.0, sr=48000.0):
    """测量 N-bit 量化的 SNR（用整数周期避免截断）"""
    n = int (sr * 1000 / f0)          # 整数个周期
    t = np.arange (n) / sr
    x = np.sin (2*np.pi*f0*t)

    levels = 2**(bits-1) - 1
    q = np.round (x * levels) / levels
    err = q - x

    snr = 10*np.log10 (np.mean (x**2) / np.mean (err**2))
    theory = 6.02*bits + 1.76
    return snr, theory

print (f"{'位深':>5} {'实测':>9} {'理论':>9} {'差':>7}")
for bits in [8, 12, 16, 20, 24]:
    snr, theory = measure_snr (bits)
    print (f"{bits:>5} {snr:>9.2f} {theory:>9.2f} {snr-theory:>+7.2f}")
    assert abs(snr - theory) < 1.0, f"{bits} bit 公式不符"

print ("✅ 6.02N + 1.76 公式验证通过")
```

```python
# 验证 dither 的作用（低电平信号）
def test_dither (bits=16, f0=1000.0, sr=48000.0):
    n = int (sr * 1000 / f0)
    t = np.arange (n) / sr
    levels = 2**(bits-1) - 1
    x = (1.0/levels) * np.sin (2*np.pi*f0*t)     # 1 LSB 幅度
    rng = np.random.default_rng (7)

    def harmonics (sig):
        w = np.hanning (len(sig))
        X = np.abs (np.fft.rfft (sig*w)) / np.sum(w) * 2
        f = np.fft.rfftfreq (len(sig), 1/sr)
        fund = X[np.argmin (np.abs (f - f0))]
        h = np.sqrt (sum (X[np.argmin(np.abs(f-k*f0))]**2
                          for k in range(2,12) if k*f0 < sr/2))
        return 20*np.log10 (h/(fund+1e-20) + 1e-20)

    q_no  = np.round (x*levels)/levels
    d = (rng.uniform(-0.5,0.5,n) + rng.uniform(-0.5,0.5,n))/levels   # TPDF
    q_tpd = np.round ((x+d)*levels)/levels

    print (f"  无 dither 谐波: {harmonics(q_no):>7.1f} dB")
    print (f"  TPDF 谐波:     {harmonics(q_tpd):>7.1f} dB")
    # 期望：TPDF 明显更低

test_dither()
```
