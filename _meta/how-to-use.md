# 怎么用这个知识库

## 日常循环

```
① 遇到东西 ──→ ② 丢 Inbox ──→ ③ 让 Agent 处理 ──→ ④ 你审阅 ──→ ⑤ commit
   看论文         不整理         按契约整理成          只改你不同意      可回滚
   看视频         允许脏         Source + Wiki         的地方
   自己试验
```

## 三种输入，三种处理

| 输入 | 放哪 | 谁处理 |
|---|---|---|
| 外部资料（论文/文档/视频） | `10-Sources/` | Agent 写摘要，原文链接必须保留 |
| 你的理解/判断/疑问 | `20-Notes/` | Agent 可起草，**你必须确认** |
| 你的代码实验 | `50-Playground/` | 你写，Agent 可帮你写测试和测量脚本 |

## 给 Agent 的标准指令

```
读取 00-Inbox 中的所有内容。

1. 先搜索 30-Wiki 和 20-Notes，判断哪些内容已有覆盖
2. 输出计划：新建哪些页、更新哪些页、有哪些不确定
3. 我确认后再动手
4. 遵守 AGENTS.md 的溯源规则
```

处理完记得让它**报告哪些结论需要你核实**——这是防止幻觉污染的关键。

## 反模式（别做这些）

| ❌ 别做 | 为什么 |
|---|---|
| 一次性导入几百篇论文 | 会得到几百个 stub，且没有一个是你能用的 |
| 让 Agent 全自动写入不审阅 | 三个月后你分不清哪句是论文说的 |
| 建"完美分类法" | 分类会变，先写内容 |
| 把代码复制进笔记 | 复制会过期，链接不会 |
| 只有 Wiki 没有 Notes | 那就成了 AI 的笔记，不是你的知识库 |

## 健康度自检（每月一次）

- [ ] `00-Inbox/` 是否清空
- [ ] `30-Wiki/` 里 `status: stub` 的比例是否 < 40%
- [ ] 最近一个月是否有新的 `20-Notes/`（如果没有，说明你只在消费不在思考）
- [ ] `_meta/open-questions` 里的问题是否在减少
