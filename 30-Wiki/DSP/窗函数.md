# 窗函数

> [!important] 一句话
> **窗函数是"在信号两端做淡入淡出"**——为了让 FFT 不把截断处的突变误读成高频成分。
> 代价是频率分辨率下降。**选择窗就是在主瓣宽度和旁瓣高度之间取舍。**

## 为什么需要窗

FFT 假设信号是**周期性的**（首尾相接）。但实际信号被截断——首尾不连续 → 这个"台阶"在频谱里表现为**泄漏**（leakage）。

```
截断的信号：   ~~~~~~~~|      ← 突然从有到无（或首尾不接）
FFT 看到的：   ~~~~~~~~~~~    ← 以为有个巨大的跳变 → 泄漏
```

> [!note] 泄漏的具体表现
> 一个纯正弦的频谱应该是**一根线**，但截断后变成**一片"裙摆"**——
> 能量从正确的 bin 漏到相邻 bin。弱信号会被强信号的裙摆**淹没**。

---

## 一、实测：五种窗的取舍

**测试**：N = 1024 点的窗，8192 点 FFT（本库实测）。

| 窗 | 主瓣宽（-3dB，bin） | **最高旁瓣** | **相干增益** |
|---|---|---|---|
| **矩形 rect** | **8** | **-13.4 dB** | **1.0000** |
| **Hann** | 12 | **-31.5 dB** | **0.4995** |
| **Hamming** | 12 | **-42.7 dB** | **0.5396** |
| **Blackman** | 14 | **-58.3 dB** | **0.4196** |
| **Kaiser β=8.6** | 14 | **-63.4 dB** | 0.4204 |

> [!important] 三个规律
> 1. **旁瓣可以低 45 dB**（矩形 -13.4 → Blackman -58.3）
> 2. **代价是主瓣变宽**（8 → 14 bin）→ 频率分辨率下降
> 3. **相干增益不是 1**（Hann 是 0.5）→ **必须做幅度校正**

> [!danger] 第 3 条是本库踩过的真实 bug
> Hann 窗的相干增益恰好是 **0.4995 ≈ 0.5**，
> 所以加窗后测得的所有幅度都**低 6.02 dB**（$20\log_{10}0.5$）。
>
> 修复方法是**除以 `sum(w)` 而不是 `N`**：
> ```python
> X = np.abs(np.fft.rfft(x * w)) / np.sum(w) * 2      # ✅ 正确
> X = np.abs(np.fft.rfft(x * w)) / len(x) * 2         # ❌ 差 6 dB
> ```
> 见 [[2026-10-14 测量工具会骗你 —— 十次踩坑记录]]。

## 二、常用窗的公式

| 窗 | $w[n]$（$0 \le n < N$） | 参数 |
|---|---|---|
| **矩形** | $1$ | — |
| **Hann** | $0.5 - 0.5\cos\frac{2\pi n}{N-1}$ | — |
| **Hamming** | $0.54 - 0.46\cos\frac{2\pi n}{N-1}$ | — |
| **Blackman** | $0.42 - 0.5\cos\theta + 0.08\cos 2\theta$ | $\theta = \frac{2\pi n}{N-1}$ |
| **Kaiser** | $\frac{I_0(\beta\sqrt{1-(2n/(N-1)-1)^2})}{I_0(\beta)}$ | $\beta$ 可调 |

> [!tip] 怎么选
> | 场景 | 推荐 | 理由 |
> |---|---|---|
> | **通用频谱分析** | **Hann** | 旁瓣 -31 dB，够用且主瓣较窄 |
> | 需要更高动态范围 | Blackman / Kaiser | 旁瓣 -58 以上 |
> | **精确测量幅度** | Hann + 相干增益校正 | 增益恰好 0.5，好算 |
> | 需要精确频率（低泄漏） | Hamming | 旁瓣 -42 dB |
> | 信号正好整数周期 | **矩形** | 无泄漏，无需加窗 |
> | **重叠相加（OLA）** | Hann（周期性） | 满足 COLA 条件 |
>
> ⚠️ 最后一条见 [[重叠相加 overlap-add]]——那里必须用**周期性** Hann，不是对称的。

## 三、⚠️ 对称 vs 周期性：一个隐蔽的坑

`np.hanning(N)` 返回的是**对称窗**（首尾都是 0）：

$$w[n] = 0.5 - 0.5\cos\frac{2\pi n}{N-1}$$

但 **OLA / STFT 需要的是周期性窗**（分母是 $N$ 而不是 $N-1$）：

$$w[n] = 0.5 - 0.5\cos\frac{2\pi n}{N}$$

**实测差异**（COLA 条件检验）：

| 窗 | COLA 误差 |
|---|---|
| `np.hanning`（对称） | **1.5e-3** ❌ 不满足 |
| 周期性 Hann | **4.4e-16** ✅ 满足 |

> [!danger] 这个坑很隐蔽
> 两者只差**分母里的 1**，波形看起来几乎一样，
> 但一个满足 OLA 的重建条件、一个不满足。
>
> **后果**：OLA 重建的信号有轻微周期性起伏（约 -56 dB 的调制噪声）。
> 你可能会以为"这是我算法的误差"，其实是窗选错了。
>
> ```python
> def hann_periodic (n):
>     return 0.5 - 0.5*np.cos(2*np.pi*np.arange(n)/n)   # 分母是 n，不是 n-1
> ```

## 四、窗的数学本质

**加窗 = 时域相乘 = 频域卷积**：

$$x[n]\,w[n] \quad \longleftrightarrow \quad X(e^{j\omega}) * W(e^{j\omega})$$

所以频谱被**窗的频谱"涂抹"**了：

| 窗的频谱特征 | 对测量结果的影响 |
|---|---|
| **主瓣宽度** | 决定**频率分辨率**（两个邻近频率能否分开） |
| **旁瓣高度** | 决定**动态范围**（弱信号能否从强信号旁被发现） |
| 主瓣形状 | 决定**幅度测量精度**（是否好校正） |

> [!important] 这就是"取舍"的来源
> 主瓣和旁瓣**此消彼长**——这是傅里叶变换的**不确定性原理**的直接结果。
> 你不可能同时得到"窄主瓣"和"低旁瓣"。
>
> **选窗 = 明确你更在乎哪个。**

## 五、代码

```python
import numpy as np

def hann_periodic (n):
    """周期性 Hann（OLA / STFT 用这个）"""
    return 0.5 - 0.5 * np.cos (2*np.pi*np.arange(n) / n)

def coherent_gain (w):
    """相干增益：幅度校正因子"""
    return np.sum (w) / len (w)

def spectrum (x, sr=48000.0, window='hann', nfft=None):
    """正确的频谱（含相干增益校正）"""
    n = len(x)
    if nfft is None: nfft = n

    if window == 'hann':
        w = hann_periodic (n)          # ⚠️ 周期性，不是 np.hanning
    elif window == 'hamming':
        w = np.hamming (n)
    elif window == 'blackman':
        w = np.blackman (n)
    elif window == 'rect':
        w = np.ones (n)
    else:
        raise ValueError (window)

    # ⚠️ 关键：除以 sum(w) 而不是 n
    X = np.abs (np.fft.rfft (x * w, nfft)) / np.sum (w) * 2
    f = np.fft.rfftfreq (nfft, 1/sr)
    return f, X
```

```python
# 自检：0.5 幅度的正弦应该测得 -6.02 dBFS
x = 0.5 * np.sin (2*np.pi*1000*np.arange(48000)/48000)
f, X = spectrum (x)
peak_db = 20*np.log10 (X.max())
print (f"{peak_db:.2f} dBFS")       # → -6.02 ✅
assert abs (peak_db + 6.02) < 0.05
```

## 六、AI 会怎么写错

| # | AI 常犯 | 后果 | 怎么查 |
|---|---|---|---|
| 1 | **不加窗** | 频谱全是泄漏毛刺 | 检查有没有 `* w` |
| 2 | **加窗但除以 `N`** | 幅度**低 6 dB**（Hann） | 除以 `sum(w)` |
| 3 | **OLA 用 `np.hanning`** | 不满足 COLA（误差 1.5e-3） | 用周期性 Hann |
| 4 | **以为"加窗总能让频谱更准"** | 整数周期信号反而变差 | 判断是否整数周期 |
| 5 | **用矩形窗做弱信号检测** | 旁瓣 -13 dB 淹没弱信号 | 换 Hann/Blackman |
| 6 | **忘了窗会降低频率分辨率** | 两个邻近频率分不开 | 主瓣宽度 ≥ 2 bin |
| 7 | **对已加窗的信号再加窗** | 双重衰减 | 检查处理链 |
| 8 | **用 `np.hanning` 算相干增益** | 数值微小偏差（0.4995 vs 0.5） | 用 `sum(w)/N` 实测 |

> [!danger] 第 2 条是最常见的"静默错误"
> 加窗的代码看起来完全正确，程序也能跑，
> **只是所有幅度都低 6 dB**。
>
> 而你如果不做校准，就会以为"我的滤波器增益不对"、
> 然后去改**正确的**滤波器代码。
>
> **防线**：用 0.5 幅度的正弦校准——应该测得 **-6.02 dBFS**。

## 七、常见坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 所有幅度低 6 dB | 加窗没补偿相干增益 | 除以 `sum(w)` |
| 频谱有毛刺 | 没加窗 | 加 Hann |
| 邻近频率分不开 | 主瓣太宽 / 窗太重 | 换矩形窗，或加长 N |
| 弱信号被淹没 | 旁瓣太高 | 换 Blackman/Kaiser |
| OLA 重建有起伏 | 用了对称 Hann | 用周期性 Hann |
| 整数周期信号测不准 | 加窗反而引入误差 | 整数周期时用矩形窗 |
| 窗增益随 N 变化 | 相干增益与 N 无关 | 检查是否用了 `sum(w)/N` |

## 八、怎么验证

```python
import numpy as np

def check_window (w, name):
    N = len(w); NFFT = 8192
    W = np.abs (np.fft.rfft (w, NFFT))
    W /= W[0]

    # 主瓣宽（-3dB）
    half = np.argmax (W < np.sqrt (0.5))

    # 第一个极小（主瓣边缘）
    n1 = next ((i for i in range (1, len(W)-1)
                if W[i] < W[i-1] and W[i] <= W[i+1]), len(W)//4)

    # 最高旁瓣
    sl = W[n1:].max()

    print (f"{name:<12} 主瓣 {2*half:>3} bin, "
           f"旁瓣 {20*np.log10(sl+1e-20):>6.1f} dB, "
           f"相干增益 {np.sum(w)/N:.4f}")
    return 2*half, 20*np.log10(sl+1e-20), np.sum(w)/N

N = 1024
check_window (np.ones(N),           '矩形')
check_window (np.hanning(N),        'Hann(对称)')
check_window (hann_periodic(N),     'Hann(周期)')
check_window (np.hamming(N),        'Hamming')
check_window (np.blackman(N),       'Blackman')

# ✅ 期望（本库实测）：旁瓣 -13.4 / -31.5 / -31.5 / -42.7 / -58.3 dB
```

**幅度校准测试**（最重要的一条）：

```python
# 0.5 幅度的正弦 → 必须测得 -6.02 dBFS
x = 0.5*np.sin(2*np.pi*1000*np.arange(48000)/48000)
_, X = spectrum(x)
assert abs(20*np.log10(X.max()) + 6.02) < 0.05, "幅度校正不对！"
```
