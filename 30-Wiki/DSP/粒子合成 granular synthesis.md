# 粒子合成 granular synthesis

> [!important] 一句话
> **粒子合成 = 把声音切成极短的小段（粒子），再重新铺开。**
> 它能在**不改变音高**的情况下改变时长——这是它最著名的能力。

## 为什么值得做

| 想要的效果 | 粒子合成能做到吗 |
|---|---|
| **时间拉伸不变调** | ✅ **能**（这是它的看家本领） |
| 音高变换不变时长 | ✅ 能 |
| 把短音变成持续的 pad | ✅ **能**（最经典的用法） |
| 制造"云状"纹理 | ✅ 能 |
| 实时变调（像 Melodyne） | 🟠 更难（需要检测音高） |

---

## 一、核心参数

| 参数 | 典型值 | 作用 |
|---|---|---|
| **粒子长度（grain size）** | 5–200 ms | ⭐ 决定音色（见实测） |
| **hop / 密度** | 粒子的 1/4 ~ 1/2 | 每秒铺多少粒子 |
| **窗函数** | Hann | 消除粒子的起始/结束咔哒 |
| **播放位置** | 随机或顺序 | 决定"从哪取"粒子 |
| **音高偏移** | ±12 半音 | 重采样粒子 |

---

## 二、实测：粒子长度决定音色（本库验证）

> [!important] 度量方式：**单个粒子**的频谱主瓣宽度
> "粒子长度决定音色"的**正确度量**不是看整个输出（那取决于铺放方式），
> 而是看**一个粒子本身**的频谱——它的主瓣有多宽。

**测试**（440 Hz 正弦 × Hann 窗，零填充 8× 看形状）：

| 粒子长度 | **−3 dB 主瓣宽度** | 理论 $2/T$ | $\Delta t \cdot \Delta f$ |
|---|---|---|---|
| **5 ms** | **325.0 Hz** | 400 | 1.62 |
| 10 ms | 150.0 Hz | 200 | 1.50 |
| 20 ms | 81.2 Hz | 100 | 1.62 |
| 50 ms | 30.0 Hz | 40 | 1.50 |
| 100 ms | 15.0 Hz | 20 | 1.50 |
| **200 ms** | **7.5 Hz** | 10 | 1.50 |

> [!important] 怎么读这张表
> - **粒子越短 → 主瓣越宽**：5 ms 时 **325 Hz**，200 ms 时只有 **7.5 Hz**（差 43 倍）
> - **$\Delta t \cdot \Delta f pprox 1.5$ 是常数**（最后两列）——
>   这就是时间-频率不确定性原理的直接体现：
>   $$\Delta t \cdot \Delta f \ge 	ext{常数}$$
>   时间上切得越碎，频率上就越模糊。
> - 实测值约为理论 $2/T$ 的 **75%**（因为 Hann 窗的主瓣比矩形窗宽、
>   且 $-3$ dB 点相对主瓣宽度位置固定）

> [!tip] 实践含义
> | 想要 | 粒子长度 |
> |---|---|
> | 清晰的原音（主瓣窄） | 100–200 ms |
> | 有"颗粒感"但音高可辨 | 50–100 ms |
> | **云状/纹理化**（频谱糊） | **5–20 ms** |
>
> 经典说法：**< 50 ms 才叫"粒子"**，再长就变成普通的拼接了。

> [!warning] ⚠️ 一处修正记录（本库 2026-10-16）
> 本页初版给的是一张"整个输出的带宽"表（5ms→421.9 Hz），
> 但那个数字来自**另一个实现变体**（源位置稀疏跳跃），
> **与本节下方的代码不符**——用下方代码实测，带宽恒为 ~2 Hz（与粒子长度无关）。
>
> **原因**：规则铺放 + 源同速前进 → 输出几乎是原信号的重建，
> 频谱当然是窄的。
>
> **已改为测单个粒子的频谱**——那才是"粒子长度决定音色"的正确度量。
>
> **教训**：**表格里的数字必须由页面里的代码产生**，
> 否则读者复现不出来。

## 三、时间拉伸不变调（核心能力）

**原理**：
```
① 从原始信号里按位置 p 取出一个粒子
② 加窗（Hann）
③ 放到输出的 q 位置
④ p 和 q 以**不同速度**前进
```

- **q 比 p 快** → 输出变短（但每个粒子内部的音高不变）
- **q 比 p 慢** → 输出变长（音高仍不变）

> [!important] 为什么音高不变
> 因为**粒子内部的内容没有被重采样**——只是放的间隔变了。
> 音高由粒子内部的波形决定，与铺放速度无关。
>
> 对比：**变速磁带**（改变播放速度）会同时改变音高。

**窗的作用**：
```
粒子边界如果不加窗 → 每次开始/结束都是一个"台阶" → 咔哒声
Hann 窗让粒子的两端渐入渐出 → 边界平滑
```

> [!warning] 加窗会带来音量起伏
> Hann 窗让粒子中间响、两端轻。若 hop 太大，粒子之间会"接不上" → 音量抖动。
>
> **规则**：**hop ≤ 粒子长度 / 2**（50% 重叠以上），让窗的重叠部分互补。

## 四、实现

```python
import numpy as np

def granular (x, grain_ms=50.0, hop_ms=None, sr=48000.0, seed=0):
    """最简粒子合成（教学版）"""
    if hop_ms is None:
        hop_ms = grain_ms / 2.0            # ⚠️ 默认 50% 重叠
    gw = int (sr * grain_ms / 1000.0)
    hop = int (sr * hop_ms / 1000.0)
    w = np.hanning (gw)

    # ⚠️ 输出要留够空间（粒子会超出原长）
    out = np.zeros (len(x) + gw)
    pos = 0
    src = 0
    while src + gw <= len(x) and pos + gw <= len(out):
        out[pos:pos+gw] += x[src:src+gw] * w
        pos += hop
        src += hop                          # 同速 = 不变时长
    return out

def granular_stretch (x, stretch=2.0, grain_ms=50.0, sr=48000.0):
    """时间拉伸（不变调）"""
    gw = int (sr * grain_ms / 1000.0)
    hop = max(1, int (gw / 4.0))            # 粒子内 hop
    out = np.zeros (int (len(x) * stretch) + gw)
    w = np.hanning (gw)
    pos = 0
    src = 0.0
    while src + gw < len(x) and pos + gw < len(out):
        i = int (src)
        out[pos:pos+gw] += x[i:i+gw] * w
        pos += hop
        src += hop / stretch                # ⭐ 源以 1/stretch 速度前进
    return out
```

> [!warning] 上面是**教学版**
> 生产实现要考虑：
> - **不要每个粒子重新计算窗**（prepare 里算好）
> - **重叠相加要处理增益补偿**（重叠会让音量上升）
> - 随机播放位置（避免周期性的"梳状"感）
> - 立体声的多粒子分布

## 五、和相邻技术的对比

| 技术 | 原理 | 音质 | 适合 |
|---|---|---|---|
| **粒子合成** | 切碎 + 重铺 | 🟠 有颗粒感 | 纹理、pad、时间拉伸 |
| **变速（resample）** | 改变播放速度 | ✅ 干净 | 但会变调 |
| **相位声码器** | FFT + 相位传播 | ✅ **最干净** | 高质量时间拉伸 |
| **WSOLA** | 波形相似重叠 | ✅ 好 | 语音/音乐变速 |

> [!important] 相位声码器 vs 粒子合成
> - **相位声码器**：在频域做，保持相位连续性 → 音质好、无颗粒感
> - **粒子合成**：在时域做 → 有颗粒感（有时这正是想要的）
>
> 见 [[FFT 与 STFT]]、[[相位声码器]]（待写）。

## 六、经典应用：把短音变成 pad

```
一个 0.5 秒的钢琴音
→ 取 50ms 粒子，随机播放位置，高密度铺开
→ 得到一个持续的、有钢琴音色的 pad
```

**关键参数**：
| 参数 | 建议 |
|---|---|
| 粒子长度 | 50–100 ms（保留音色） |
| hop | 10–25 ms（高密度） |
| 播放位置 | **随机**（避免周期性） |
| 立体声 | 每个粒子随机分配到左右 |

## 七、AI 会怎么写错

| # | AI 常犯 | 后果 | 怎么查 |
|---|---|---|---|
| 1 | **不加窗** | 每个粒子边界咔哒 | 检查是否有 Hann |
| 2 | **hop > 粒子长度/2** | 音量抖动 | 50% 重叠以上 |
| 3 | **没做重叠增益补偿** | 音量随密度上升 | 测 RMS |
| 4 | **以为粒子越短越好** | 音高糊掉（实测带宽 421 Hz） | 看频谱扩散 |
| 5 | **粒子太长** | 失去颗粒感，变成拼接 | 用 < 50 ms |
| 6 | **每个粒子重算窗** | 慢 | prepare 里算 |
| 7 | **周期性播放位置** | 梳状/机械感 | 用随机 |
| 8 | **在音频线程分配缓冲** | 违反实时契约 | prepare 里分配 |
| 9 | **忘了加输出长度余量** | 尾部被截断 | `len(x) + gw` |
| 10 | **以为能实时变调** | 需要先检测音高 | 见 [[实时神经网络推理约束]] |

> [!warning] 第 4 条需要说清"糊的是什么"（本库修正过一处说法）
> AI 会以为"粒子越短越细腻"，但也不能简单说"越短越糊"。
>
> **实测区分两个不同的量**（440 Hz 正弦，规则铺放）：
>
> | 粒子长度 | **单粒子主瓣宽度** | **整个输出的主峰** |
> |---|---|---|
> | 5 ms | **325.0 Hz** | **439.8 Hz** |
> | 20 ms | 81.2 Hz | 440.2 Hz |
> | 100 ms | 15.0 Hz | 440.0 Hz |
>
> - **单粒子主瓣**：粒子越短越宽（时间-频率不确定性）→ 决定**音色**
> - **整个输出的主峰**：规则铺放时**仍≈440 Hz** → 音高**没有**糊
>
> **所以"音高糊了"这个说法不准确**：
> 短粒子改变的是**音色（频谱包络）**，不是音高。
>
> 真正让音高糊掉的是**随机播放位置**或**粒子间相位不连续**——
> 那会让各粒子的相位互不相关，主峰才会散开。

## 八、常见坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 咔哒声 | 没加窗 | 加 Hann |
| 音量抖动 | hop 太大 | 50% 重叠 |
| 音量变大 | 没做重叠补偿 | 归一化 |
| 音高糊了 | 粒子太短（实测） | ≥ 20 ms |
| 听起来"机械" | 周期播放位置 | 随机化 |
| 尾部被切 | 输出长度不够 | 加 grain 长度 |
| CPU 高 | 每粒子重算窗 | 预计算 |

## 九、怎么验证

**三个必做检查**：

| # | 检查 | 期望 |
|---|---|---|
| 1 | **无咔哒** | 输出连续（粒子边界无跳变） |
| 2 | **音高保持**（长粒子时） | 主峰 ≈ 原频率 |
| 3 | **时长可控** | stretch 参数生效 |

```python
import numpy as np
SR = 48000.0
t = np.arange (int (SR)) / SR
x = 0.5 * np.sin (2*np.pi*440*t)

# ① 长粒子应保留音高
y = granular (x, grain_ms=100.0)
Y = np.abs (np.fft.rfft (y * np.hanning (len(y)))); f = np.fft.rfftfreq (len(y), 1/SR)
pk = f[np.argmax (Y)]
print (f"  100ms 粒子: 主峰 {pk:.1f} Hz")
assert abs (pk - 440.0) < 20, "长粒子应保留音高"

# ② 单个粒子的主瓣宽度：粒子越短越宽（时间-频率不确定性）
def grain_mainlobe (grain_ms, f0=440.0, sr=SR):
    gw = int (sr*grain_ms/1000.0)
    n = gw*8
    tt = np.arange (gw)/sr
    g = np.sin (2*np.pi*f0*tt) * np.hanning (gw)
    Y = np.abs (np.fft.rfft (g, n)); fr = np.fft.rfftfreq (n, 1/sr)
    Y /= Y.max()
    i = int (np.argmax (Y))
    l = i
    while l > 0 and Y[l] > 0.7079: l -= 1
    r = i
    while r < len(Y)-1 and Y[r] > 0.7079: r += 1
    return fr[r] - fr[l]

for gm in [5, 50, 200]:
    bw = grain_mainlobe (gm)
    print (f"  {gm:>4}ms 粒子: 主瓣 {bw:>7.1f} Hz  (Δt·Δf = {bw*gm/1000:.2f})")

# 期望：5ms→~325Hz, 50ms→~30Hz, 200ms→~7.5Hz；Δt·Δf ≈ 1.5
assert grain_mainlobe(5) > grain_mainlobe(50) > grain_mainlobe(200), \
    "粒子越短主瓣应越宽"
print ("✅ 时间-频率不确定性规律成立")
```

> [!important] 第二个检查的价值
> 它把"粒子越短越糊"这个**物理规律**变成断言。
> 如果你改实现后 5 ms 的带宽不扩散了，说明**有 bug**（可能是没真的切碎）。
