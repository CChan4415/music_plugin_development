# 非线性处理

> [!important] 一句话
> **非线性 = 输出不只是输入的线性组合**（有乘、平方、饱和、阈值等）。
> 它是失真、饱和、压缩、限幅的共同数学基础——**也是混叠的唯一来源**。

## 为什么这一页重要

你听过的"温暖"、"激进"、"塑料味"、"数字味"，**全部来自非线性的具体形式**：

| 你的听感 | 工程原因 |
|---|---|
| "温暖的失真" | 有**偶次谐波**（非对称 shaper） |
| "激进的失真" | 主要是**奇次谐波**（对称 shaper） |
| "塑料味 / 数字味" | **混叠**（非线性产生超 Nyquist 谐波折回） |
| "很模拟" | 谐波衰减快 + 轻微噪声 + 不对称 |
| "越加失真越糊" | 高次谐波过多 + 混叠 |

> [!note] 这一页和 [[动态处理的原理]] 的分工
> 那页讲"音乐上为什么这样做"；这一页讲**数学与实现**。

## 一、核心判定规则：奇偶谐波来自对称性

> [!important] 这条规则是**数学上精确的**，不是经验

| 函数的对称性 | 产生的谐波 | DC 分量 |
|---|---|---|
| **奇函数** $f(-x) = -f(x)$ | **只有奇次**（h1, h3, h5...） | **恒为 0** |
| **偶函数** $f(-x) = f(x)$ | **只有偶次**（h2, h4...） | 有 |
| **一般非对称** | 奇次 + 偶次 | 有 |

**实测验证**（输入 1kHz 正弦，幅度 0.5，48kHz）：

| shaper | 对称性 | h2 | h3 | h4 | h5 | 真实 DC |
|---|---|---|---|---|---|---|
| hard clip | 奇函数 | -162.5 | **-16.5** | -175.5 | **-35.6** | -2.8e-16 |
| tanh | 奇函数 | -221.7 | **-18.4** | -235.3 | **-34.5** | -8.1e-17 |
| atan | 奇函数 | -221.4 | **-16.7** | -233.6 | **-28.3** | -2.2e-17 |
| $x - x^3/3$ | 奇函数 | -219.5 | **-7.4** | -227.9 | -239.0 | 6.3e-17 |
| $T_3 = 4x^3-3x$ | 奇函数 | -221.8 | **-19.1** | -236.6 | -246.0 | 1.0e-16 |
| $x + 0.5x^2$ | **非对称** | **-18.1** | -235.3 | -244.5 | -250.8 | 6.3e-02 |
| $\tanh + 0.3\tanh^2$ | **非对称** | **-18.8** | **-18.4** | **-30.2** | **-34.5** | 1.6e-01 |
| $\tanh^2 - 0.5$ | 偶函数 | 221.3 | **1.9** | 209.9 | **-7.2** | 1.9e-02 |

> [!warning] 怎么读这张表
> - 奇函数那几行的 **h2 在 -220 dB 左右 = 纯数值噪声**，不是真的存在偶次谐波
> - 非对称 shaper 的 h2 高达 **-18 dB**——这是**真实的偶次谐波**
> - 偶函数（$\tanh^2$）**只有奇次**（h3 = +1.9 dB！）
>
> **关键：想要偶次谐波（"温暖"），必须用非对称 shaper。**

## 二、非对称 shaper 会产生真实 DC（必须去直流）

> [!danger] 这是最容易忽略的问题

**实测**：

| shaper | 输出 DC | 折合 dBFS | 输出峰值 |
|---|---|---|---|
| tanh（对称） | -8.1e-17 | -321.8 | 0.9051 |
| $\tanh + 0.3\tanh^2$ | **1.556e-01** | **-16.2** | 1.1509 |
| $\tanh^2 - 0.5$ | 1.86e-02 | -34.6 | 0.5000 |
| $x + 0.5x^2$ | 6.25e-02 | -24.1 | 0.6250 |

**-16 dBFS 的直流！** 这不是数值误差，是真实的直流偏置。

> [!warning] 直流对压缩器的伤害远大于对耳朵的伤害
> 耳朵听不到 DC，但：
> - **压缩器/限制器会把它当成"能量"** → 白白占用 headroom
> - 后续处理可能放大它 → 削波
> - 扬声器会做无用功（发热）
>
> **必须在 shaper 之后加 DC blocker**（一阶高通，截止 5–20 Hz）。

```cpp
// 一阶 DC blocker（高通，截止约 10Hz @48kHz）
class DCBlocker
{
public:
    void prepare (double sampleRate, double cutoffHz = 10.0)
    {
        // R 接近 1 但小于 1；截止频率越低，R 越接近 1
        R = 1.0f - (float) (2.0 * M_PI * cutoffHz / sampleRate);
    }
    float process (float x)
    {
        const float y = x - xPrev + R * yPrev;
        xPrev = x;  yPrev = y;
        return y;
    }
private:
    float R = 0.999f, xPrev = 0.0f, yPrev = 0.0f;
};
```

## 三、谐波衰减速率：决定混叠的严重程度

> [!important] 衰减越慢 → 高次谐波越多 → 混叠越严重

**实测**（相对基频的谐波电平，dB）：

| shaper | h3 | h5 | h7 | h9 | h11 | h13 |
|---|---|---|---|---|---|---|
| **hard clip** | -16.5 | -35.6 | -32.2 | -51.0 | -39.9 | -85.9 |
| $x - x^3/3$ | -7.4 | -239.0 | -250.8 | -258.2 | -263.3 | -267.6 |

> [!tip] 结论
> - **hard clip 的谐波衰减最慢**（约 -12 dB/oct）→ **混叠最严重**
> - **tanh / atan 衰减快得多** → 同样过采样倍率下，混叠低 **10–20 dB**
> - $x - x^3/3$ 只有 3 次谐波（h5 已在 -239 dB）→ 最容易抗混叠
>
> ⚠️ 但这**不意味着** tanh 不需要过采样，只是需要**更低的倍率**。
> 见 [[过采样 oversampling]]。

## 四、drive 如何改变谐波结构

**实测**（tanh，输入 1kHz）：

| drive | h1 | h3 | h5 | h7 | h9 | THD |
|---|---|---|---|---|---|---|
| 0.5 | -12.18 | -45.8 | -90.0 | -134.1 | -178.2 | -45.8 |
| 2.0 | -1.81 | -23.5 | -45.1 | -66.5 | -88.0 | -23.5 |
| 3.0 | +0.09 | -18.4 | -34.5 | -50.4 | -66.3 | -18.2 |
| 6.0 | +1.64 | -12.6 | -21.9 | -30.7 | -39.4 | -12.0 |
| 12.0 | +2.00 | -10.3 | -16.3 | -21.3 | -25.9 | -9.0 |

> [!note] 两个现象
> 1. **drive 越大，THD 越高**（-45.8 → -9.0 dB）——符合直觉
> 2. **drive 越大，基频也越大**（-12.18 → +2.00 dB）
>    → 因为 tanh 在小信号时近似线性（增益 ≈ drive）
>    → **这就是为什么失真插件通常需要自动增益补偿**（不然一拧 drive 音量就爆）

## 五、Chebyshev 多项式：精确设计谐波（但有陷阱）

Chebyshev 恒等式：$T_k(\cos\theta) = \cos(k\theta)$

所以 $T_2(x) = 2x^2-1$ 作用在 $\cos\theta$ 上，**理论上只产生 2 次谐波**。

**实测——但有陷阱**：

| 输入幅度 | T2 的输出 |
|---|---|
| **1.0** | 只有 h2（h1/h3/h4 都在 -220 dB 以下） |
| **0.5** | **同时产生 h2/h3/h4/h5**，不再纯净 |

> [!danger] 这是用 Chebyshev 做"精确谐波设计"时最容易踩的坑
> **Shaper 是幅度相关的。** 输入电平一变，谐波结构就变。
>
> 对插件设计的意义：
> - 如果你按"输入满幅"设计谐波结构，**用户降低输入电平后音色就变了**
> - 想稳定 → 需要**输入归一化**（自动增益到固定电平再进 shaper）
> - 这也是很多"模拟味"插件在低电平下"没味道"的原因

## 六、偶次谐波与过采样无关

> [!important] 一个常见的误解

**实测**（输入 3kHz，h2=6k、h5=15k、h7=21k 都在带内；h9=27k 越界）：

| shaper | h2 | h3 | h4 | h5 |
|---|---|---|---|---|
| tanh（奇函数） | -240.7 | -18.4 | -254.4 | -34.5 |
| $\tanh + 0.3\tanh^2$（非对称） | **-18.8** | -18.4 | **-30.2** | -34.5 |

> [!tip] 结论
> **偶次谐波是"带内"的合法成分，过采样不会动它（也不该动）。**
> 过采样只压低"越过 Nyquist 折回来"的那部分。
>
> 所以：**"加了过采样后音色变暖"是错觉**——
> 变的是**混叠少了**，不是偶次谐波多了。
>
> 想要"温暖"，要改的是 **shaper 的对称性**，不是过采样倍率。

## 七、实现

```cpp
// 常用 shaper 集合
namespace Shapers
{
    // 硬削波：奇函数，谐波衰减最慢，混叠最严重
    inline float hardClip (float x, float drive) noexcept
    { return std::clamp (drive * x, -1.0f, 1.0f); }

    // tanh：奇函数，谐波衰减快，混叠较轻
    inline float tanhShaper (float x, float drive) noexcept
    { return std::tanh (drive * x); }

    // 非对称（产生偶次谐波 + DC！）
    inline float asymmetric (float x, float drive, float asym) noexcept
    {
        const float t = std::tanh (drive * x);
        return t + asym * t * t;          // ⚠️ 必须跟 DC blocker
    }

    // 三次多项式：只有 3 次谐波，最容易抗混叠
    inline float cubic (float x, float drive) noexcept
    {
        const float d = std::clamp (drive * x, -1.5f, 1.5f);
        return d - d * d * d / 3.0f;
    }
}
```

**完整使用（含 DC blocker 和过采样）**：

```cpp
void processBlock (juce::AudioBuffer<float>& buffer, juce::MidiBuffer&) override
{
    // 1. 过采样（非线性必须过采样，见 [[过采样 oversampling]]）
    juce::dsp::AudioBlock<float> block (buffer);
    auto upBlock = oversampling->processSamplesUp (block);

    for (size_t ch = 0; ch < upBlock.getNumChannels(); ++ch)
    {
        auto* data = upBlock.getChannelPointer (ch);
        for (size_t i = 0; i < upBlock.getNumSamples(); ++i)
            data[i] = Shapers::asymmetric (data[i], drive, asymmetry);
    }

    oversampling->processSamplesDown (block);

    // 2. DC blocker（非对称 shaper 必须）
    for (int ch = 0; ch < buffer.getNumChannels(); ++ch)
    {
        auto* data = buffer.getWritePointer (ch);
        for (int i = 0; i < buffer.getNumSamples(); ++i)
            data[i] = dcBlocker[ch].process (data[i]);
    }

    // 3. 输出增益补偿（drive 会改变电平）
    buffer.applyGain (outputCompensation);
}
```

## 八、AI 会怎么写错

| # | AI 常犯 | 后果 | 怎么查 |
|---|---|---|---|
| 1 | **完全不做过采样** | 混叠（"数字味"） | 检查是否有 `Oversampling` |
| 2 | **用了非对称 shaper 但不加 DC blocker** | DC 偏置占用 headroom | 测输出均值 |
| 3 | **用 hard clip 当"温和饱和"** | 谐波衰减最慢，混叠最重 | 换成 `tanh` |
| 4 | **以为"加过采样会让声音变暖"** | 概念错误 | 温暖来自 shaper 对称性 |
| 5 | **不做增益补偿** | 一拧 drive 音量爆 | 检查有没有补偿 |
| 6 | **Chebyshev 设计不归一化输入** | 电平一变音色就变 | 检查是否先归一化 |
| 7 | **对整个处理链过采样** | 浪费 CPU | 只对非线性部分过采样 |
| 8 | **忘记报告过采样引入的延迟** | 宿主补偿错 | `setLatencySamples` |
| 9 | **在音频线程构造 shaper 对象** | 违反实时契约 | 在 prepare 里建 |

> [!warning] 第 2 条最隐蔽
> 非对称 shaper 的 DC 在**耳朵听不出来**，
> 但会让**压缩器**误判能量 → 用户觉得"这个插件一挂上就变小声"。
> **测输出均值**（`np.mean(y)`）就能发现。

## 九、常见坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 高频"沙沙"/塑料味 | 混叠 | 过采样，或换谐波衰减快的 shaper |
| 挂上后整体变小声 | 非对称 shaper 的 DC | 加 DC blocker |
| 拧 drive 音量爆 | 没做增益补偿 | 加自动补偿 |
| 低电平时"没味道" | shaper 幅度相关 | 输入归一化 |
| 听起来"太干净"不像失真 | 过采样倍率太高 | 适当降低（混叠也是一种"味道"） |
| CPU 占用高 | 整链过采样 | 只对非线性部分 |
| 立体声左右不一致 | 共用 shaper 状态（如 DC blocker） | 每声道独立 |

## 十、怎么验证

```python
import numpy as np
SR = 48000
# ⚠️ 必须用**整数周期**！否则截断会让信号本身带上微小 DC，
#    测出来像是 shaper 产生的（实测：非整数周期时 tanh 的"DC" 是 1.7e-4，
#    整数周期时是 1.6e-16）
F0, CYCLES = 1000.0, 1000
N = int(SR * CYCLES / F0)          # = 48000，正好 1000 个周期

def shaper(x, d=3.0): return np.tanh(d*x)

def harmonics(y, f0=F0, sr=SR):
    """返回各次谐波相对基频的 dB"""
    X = np.abs(np.fft.rfft(y * np.hanning(len(y)))) / (len(y)/4)
    fr = np.fft.rfftfreq(len(y), 1/sr)
    def at(f): return X[np.argmin(np.abs(fr - f))]
    h1 = at(f0)
    return [20*np.log10(at(k*f0)/(h1+1e-20) + 1e-20)
            for k in range(1, 10) if k*f0 < sr/2]

t = np.arange(N)/SR
x = 0.5*np.sin(2*np.pi*F0*t)

# 1. 奇函数 → 偶次谐波应为 0（实测 h2 ≈ -198 dB = 数值噪声）
h = harmonics(shaper(x))
print("谐波（相对基频 dB）:", [f"h{i+1}={v:.1f}" for i, v in enumerate(h)])
assert h[1] < -100, "奇函数不应有偶次谐波！"

# 2. 对称 shaper → DC 应为 0（整数周期下实测 1.6e-16）
print(f"对称 shaper 的 DC = {np.mean(shaper(x)):.2e}")
assert abs(np.mean(shaper(x))) < 1e-10, "对称 shaper 不应有 DC"

# 3. 非对称 shaper → 有真实 DC（实测 -16 dBFS）
y2 = np.tanh(3*x) + 0.3*np.tanh(3*x)**2
print(f"非对称 shaper 的 DC = {np.mean(y2):.4f}  ← 必须加 DC blocker")

# 4. DC blocker 要去掉它（注意要跳过暂态！）
def dcblock(x, fc=10.0, sr=SR):
    R = 1.0 - 2*np.pi*fc/sr
    y = np.zeros_like(x); xp = yp = 0.0
    for i in range(len(x)):
        y[i] = x[i] - xp + R*yp
        xp, yp = x[i], y[i]
    return y

# ⚠️ 10Hz 高通的 τ ≈ 16ms，但完全稳定要几倍 τ —— 测稳态要跳过前 2 秒
y3 = np.concatenate([y2, y2, y2])          # 3 秒
out = dcblock(y3)
print(f"DC blocker 稳态 DC = {np.mean(out[2*SR:]):.2e}  ← 已去掉")
```
