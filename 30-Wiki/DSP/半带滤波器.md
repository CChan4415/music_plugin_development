# 半带滤波器

> [!important] 一句话
> **半带滤波器是专门为 2× 采样率变换设计的 FIR**——
> 它有一半系数是 0，所以在 2× 过采样/降采样里**计算量减半**。

## 定义性的三个特征

> [!important] 这三条是判据，不是"特性"

| # | 特征 | 怎么验证 |
|---|---|---|
| 1 | **在 $f_s/4$ 处增益恰好 = 0.5（-6.02 dB）** | 测频响 |
| 2 | **约一半系数为 0**（偶数偏移处，中心除外） | 看冲激响应 |
| 3 | **通带纹波 = 阻带纹波**（对称） | 比较两者 |

**实测**（本库验证，31 抽头）：

```
中心系数 h[M]              = 0.500000
直流增益 sum(h)            = 1.000052
H(fs/4)                    = 0.500000  (-6.02 dB)  ← 判据 ①
H(fs/4) / H(0)             = 0.499974  （应为 0.5）
```

> [!danger] 第 1 条是最容易搞错的
> **$f_s/4$ 处是 -6.02 dB，不是 -3 dB。**
>
> 因为半带滤波器要在 2× 降采样时：
> - 通带（$< f_s/4$）保留
> - 阻带（$> f_s/4$）被抑制
> - **交界处恰好衰减一半**（0.5 = -6.02 dB）
>
> 如果你测出 -3 dB，那不是半带滤波器。

---

## 一、为什么一半系数是 0

**理想的半带冲激响应**（截止 $f_s/4$）：

$$h[\text{off}] = \begin{cases} 0.5 & \text{off} = 0 \\[4pt] 0 & \text{off 为偶数} \\[4pt] \dfrac{\sin(\pi\,\text{off}/2)}{\pi\,\text{off}} = \dfrac{(-1)^{(|\text{off}|-1)/2}}{\pi\,\text{off}} & \text{off 为奇数} \end{cases}$$

其中 $\text{off} = n - M$（相对中心的偏移），$M = (N-1)/2$。

> [!important] 这直接带来 2× 的计算节省
> | 操作 | 朴素 | 半带 |
> |---|---|---|
> | 每输出样本的乘加 | $N$ | $N/2$（跳过 0 系数） |
> | 加上多相分解 | $N$ | **$N/4$** |
>
> **半带 + 多相 = 4 倍的节省**（见 [[多速率处理 multirate]]）。

> [!warning] 我在这里犯过一个错（本库记录）
> 我第一次用 `np.sinc((n-M)/2)/2` 作初值，再"强制奇数位置为 0"。
>
> **结果直流增益 = 0.5（应该 1.0）**，因为
> `sinc(x/2)` 在 $x$ 为**偶数**时为 0——
> **我把该保留的系数清零了，保留了该清零的。**
>
> 正确的做法是**直接按上面的公式构造**，而不是"从 sinc 出发再修正"。
>
> **判据**：直流增益应 ≈ 1，$f_s/4$ 处应 = -6.02 dB。
> 两个都检查，就能立刻发现错误。

## 二、实测：抽头数与性能

**测试**（$f_s$ = 96 kHz，Kaiser 窗 $\beta$ = 6.0，65536 点 FFT）：

| 抽头 | 直流增益 | $f_s/4$ 处 | 阻带最高 | 过渡带宽度 |
|---|---|---|---|---|
| 11 | 0.99998 | **-6.02 dB** | -11.6 dB | 27105 Hz |
| 21 | 1.00007 | **-6.02 dB** | -20.3 dB | 13578 Hz |
| 31 | 1.00005 | **-6.02 dB** | -34.5 dB | 9053 Hz |
| 51 | 1.00005 | **-6.02 dB** | -66.6 dB | 5430 Hz |
| 101 | 1.00009 | **-6.02 dB** | -71.2 dB | 2713 Hz |

> [!important] 怎么读
> - **$f_s/4$ 处恒为 -6.02 dB**——与抽头数无关（这是结构性质）✅
> - **抽头越多 → 阻带越低、过渡带越窄**
> - 51 抽头已经能到 **-66.6 dB** 阻带
> - 101 抽头到 -71.2 dB（改善变小，收益递减）
>
> **典型选择：31–63 抽头**（在 CPU 和阻带之间平衡）。

> [!tip] 一个实用的经验
> 阻带从 -11.6 dB（11 抽头）到 -71.2 dB（101 抽头），
> 但**过渡带**从 27105 Hz 缩到 2713 Hz——**约 10 倍**。
>
> 过渡带窄 = 通带保留更多 = 过采样质量更好。
> 所以**抽头数主要由过渡带需求决定**，不是阻带。

## 三、2× 过采样的完整结构

```
升 2×：
  ① 零插值（插 0）
  ② 半带滤波（多相，跳过 0 系数）
  ③ × 2 增益补偿

处理：
  ④ 在高采样率下做非线性/处理

降 2×：
  ⑤ 半带滤波（多相）
  ⑥ 抽取（每 2 个取 1）
```

> [!warning] 上升和下降用的是**同一个**滤波器
> 因为半带滤波器在 $f_s/4$ 处对称——
> **升采样和降采样可以用同一组系数**。
>
> 这是半带的另一个便利之处（省一半内存和设计工作）。

**关键参数**：

| 参数 | 值 | 说明 |
|---|---|---|
| 截止（-6dB） | $f_s/4$ | 定义性 |
| 通带边缘 | 约 $0.4 f_s$ | 取决于抽头数 |
| 阻带边缘 | 约 $0.6 f_s$ | 对称 |
| 增益补偿 | **× 2** | 零插值后能量减半 |

## 四、实现

```cpp
// 半带滤波器（利用"一半系数为 0"跳过计算）
class HalfBandFilter
{
public:
    void prepare (const std::vector<float>& taps)
    {
        // taps 长度必须为奇数
        jassert (taps.size() % 2 == 1);
        h = taps;
        N = (int) h.size();
        M = (N - 1) / 2;
        delay.assign ((size_t) N, 0.0f);
        pos = 0;
    }

    float process (float x) noexcept
    {
        delay[(size_t) pos] = x;

        // 中心抽头（系数 0.5）
        float acc = 0.5f * delay[(size_t) ((pos - M + N) % N)];

        // ⚠️ 只遍历**奇数偏移**（偶数偏移系数为 0，直接跳过）
        for (int k = 1; k <= M; k += 2)
        {
            const int i1 = (pos - (M + k) + N) % N;
            const int i2 = (pos - (M - k) + N) % N;
            acc += h[(size_t) (M - k)] * (delay[(size_t) i1] + delay[(size_t) i2]);
        }

        pos = (pos + 1) % N;
        return acc;
    }

private:
    std::vector<float> h, delay;
    int N = 0, M = 0, pos = 0;
};
```

> [!tip] 两个优化都体现出来了
> 1. **跳过 0 系数**（只遍历奇数偏移）
> 2. **利用对称性**（`h[M-k]` 同时乘两个延迟样本）
>
> 合起来是朴素卷积的 **1/4** 计算量。

> [!warning] 上面的取模运算可能成为瓶颈
> 每样本多次 `% N` 很慢。
> 生产实现应该用环形缓冲 + 两个线性区段，或单调索引 + 位与。
> 见 [[SPSC 队列]] 的同类技巧。

## 五、和其他抗混叠滤波器的对比

| 方案 | 计算量 | 相位 | 延迟 | 用途 |
|---|---|---|---|---|
| **半带 FIR** | 低（1/4） | ✅ **线性** | $M$ 采样 | ✅ **2× 过采样标准** |
| 一般 FIR 低通 | 高 | ✅ 线性 | $M$ 采样 | 任意倍率 |
| IIR（椭圆） | **最低** | ❌ 非线性 | 很小 | 要求低延迟 |
| 多相 IIR 全通 | 低 | ❌ 非线性 | 很小 | JUCE 的一种模式 |

> [!important] JUCE 的过采样提供两种
> `juce::dsp::Oversampling` 有 **FIR（半带）** 和 **IIR** 两种模式：
> - **FIR**：线性相位，但延迟大（$M$ 采样 × 级数）
> - **IIR**：延迟小，但相位非线性
>
> ⚠️ 具体 API 与延迟数值需查你锁定版本的 JUCE 文档。
> 见 [[过采样 oversampling]]。

## 六、AI 会怎么写错

| # | AI 常犯 | 后果 | 怎么查 |
|---|---|---|---|
| 1 | **用普通低通冒充半带** | $f_s/4$ 处不是 -6.02 dB | 测 $f_s/4$ |
| 2 | **$f_s/4$ 处设计成 -3 dB** | 不是半带 | 应为 **-6.02 dB** |
| 3 | **忘了 ×2 增益补偿** | 升采样后音量减半 | 检查增益 |
| 4 | **遍历所有系数（不跳过 0）** | 慢 2 倍 | 检查循环步长 |
| 5 | **不用对称性** | 慢 2 倍 | 检查是否合并对称项 |
| 6 | **抽头数为偶数** | 半带结构不成立 | 必须奇数 |
| 7 | **不归一化** | 直流增益不是 1 | `sum(h)` 应 ≈ 1 |
| 8 | **升/降采样用不同的滤波器** | 浪费（半带可以共用） | 检查 |
| 9 | **忘了报告延迟** | 多轨错位 | `setLatencySamples` |
| 10 | **在音频线程设计滤波器** | 违反实时契约 | prepare 里设计 |

> [!danger] 第 1、2 条是最本质的错误
> AI 会写一个"截止在 $f_s/4$ 的普通低通"，然后声称是半带滤波器。
> **但普通低通在 $f_s/4$ 处可能是 -3 dB、-1 dB 或别的值**——
> 那**不是**半带。
>
> **判据**：$f_s/4$ 处必须**恰好** -6.02 dB（±0.1 dB）。

## 七、常见坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 过采样后音量不对 | 忘了 ×2 补偿 | 加增益 |
| 混叠没被抑制 | 阻带太差（抽头太少） | 加抽头 |
| 通带高频衰减 | 过渡带太宽 | 加抽头 |
| CPU 占用高 | 没跳过 0 系数 | 优化循环 |
| $f_s/4$ 处不是 -6 dB | 不是真正的半带 | 检查设计公式 |
| 直流增益不是 1 | 没归一化 | `sum(h)` 应 ≈ 1 |
| 多轨错位 | 没报告延迟 | `setLatencySamples` |

## 八、怎么验证

**三个必做测试**：

| # | 测试 | 判据 |
|---|---|---|
| 1 | **$f_s/4$ 处** | **-6.02 dB**（±0.1） |
| 2 | **直流增益** | ≈ 1 |
| 3 | **一半系数为 0** | 偶数偏移处全是 0 |

```python
import numpy as np

def design_halfband (n_taps=31, beta=6.0):
    """正确的半带滤波器设计"""
    assert n_taps % 2 == 1, "抽头数必须为奇数"
    M = (n_taps - 1) // 2
    n = np.arange (n_taps)
    off = n - M

    h = np.zeros (n_taps)
    h[M] = 0.5                                    # 中心
    for i in range (n_taps):
        if off[i] == 0 or off[i] % 2 == 0:
            continue                              # 偶数偏移 → 0
        h[i] = np.sin (np.pi*off[i]/2) / (np.pi*off[i])

    h *= np.kaiser (n_taps, beta)                 # 加窗
    return h

def verify_halfband (h, fs=96000.0, nfft=1<<16):
    h = np.asarray (h, float)
    N = len (h); M = (N-1)//2

    # ① 一半系数为 0
    off = np.arange (N) - M
    even_mask = (off % 2 == 0) & (off != 0)
    zeros_ok = np.all (np.abs (h[even_mask]) < 1e-12)
    print (f"  一半系数为 0: {'✅' if zeros_ok else '❌'}")

    # ② 直流增益
    dc = np.sum (h)
    print (f"  直流增益: {dc:.6f}  {'✅' if abs(dc-1) < 0.01 else '❌'}")

    # ③ fs/4 处 = -6.02 dB
    H = np.abs (np.fft.rfft (h, nfft))
    f = np.fft.rfftfreq (nfft, 1/fs)
    at_q = H[np.argmin (np.abs (f - fs/4))] / H[0]
    db_q = 20*np.log10 (at_q + 1e-20)
    print (f"  fs/4 处: {db_q:.2f} dB  {'✅' if abs(db_q + 6.02) < 0.1 else '❌'}")
    return zeros_ok and abs(dc-1) < 0.01 and abs(db_q + 6.02) < 0.1

print ("31 抽头:")
assert verify_halfband (design_halfband (31))
print ("✅ 全部通过")

# 抽头数对比
print ("\n抽头数 vs 阻带:")
fs = 96000.0
f = np.fft.rfftfreq (1<<16, 1/fs)
for nt in [11, 21, 31, 51, 101]:
    h = design_halfband (nt)
    H = np.abs (np.fft.rfft (h, 1<<16))
    db = 20*np.log10 (H + 1e-20)
    sb = db[f > fs/4*1.2].max()
    print (f"  {nt:>4} 抽头: 阻带 {sb:>6.1f} dB")
# 期望：-11.6 / -20.3 / -34.5 / -66.6 / -71.2 dB
```

> [!important] 三个断言的价值
> 1. **一半系数为 0** — 抓"用普通低通冒充半带"
> 2. **直流增益 ≈ 1** — 抓归一化错误（**我犯过这个错**）
> 3. **$f_s/4$ = -6.02 dB** — 抓最本质的定义错误
>
> 三条一起检查，任何"假半带"都逃不掉。
