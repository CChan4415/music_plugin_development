# 物理建模

> [!important] 一句话
> **物理建模 = 用算法模拟乐器的发声机制**（弦的振动、管的空气柱、膜的张力），
> 而不是播放录制好的采样。它用**极小的内存**换来**连续可变的表达力**。

## 为什么值得学

| | 物理建模 | 采样 |
|---|---|---|
| 内存 | **几 KB** | 几百 MB |
| 表现力 | ✅ **连续**（力度、位置、材质都能调） | ❌ 只能切换采样层 |
| 真实感 | 🟠 近似 | ✅ 真实 |
| CPU | 低-中 | 低（播放） |
| **开发难度** | ❌ **高**（要懂物理） | ✅ 低 |
| 音色变化 | ✅ 参数连续可调 | ❌ 需要多层采样 |

> [!note] 现实中的选择
> **大多数商业产品是混合的**：
> - 物理建模做**表现力**（力度响应、连续音高）
> - 采样做**真实感**（复杂共振、噪声成分）
>
> 纯物理建模的产品很少（Pianoteq 是著名例子）。

## 一、Karplus-Strong：最简单的物理建模

**核心思想**：**一段带阻尼的延迟线 = 一根弦**。

```
激励（拨弦/噪声）
   ↓
延迟线（长度 N = fs/f0）
   ↓
   └──→ 一阶低通（阻尼）──→ 反馈回去
```

**为什么这能产生音高**：延迟线长度 $N$ 决定了**往返周期** $T = N/f_s$，
所以基频 $f_0 = f_s/N$。

> [!important] 这就是"波导"的雏形
> 真实的弦有两列行波（左右传播），KS 只用了**一列 + 延迟**。
> 更精确的模型叫**数字波导（digital waveguide）**——
> 用两条延迟线分别模拟左右行波，能正确处理**拨弦位置**和**端点反射**。

## 二、实测：音高与衰减

### 1. 音高由延迟线长度决定

**实测**（本库验证，白噪声激励）：

| 目标 $f_0$ | $N = f_s/f_0$ | 实测 $f_0$ | 误差 |
|---|---|---|---|
| 110 Hz | 436 | **110.1 Hz** | +0.08% |
| 220 Hz | 218 | **220.2 Hz** | +0.08% |
| 440 Hz | 109 | **440.4 Hz** | +0.08% |
| 880 Hz | 55 | **872.7 Hz** | **-0.83%** |

> [!warning] 高音区误差变大——这是整数延迟的固有限制
> $N$ 必须是**整数**（否则延迟线长度不是整数）。
> - 低音：$N$ 大（436），取整的相对误差小
> - **高音：$N$ 小（55），取整的相对误差大**
>
> **解法**：用**分数延迟**（全通滤波器或插值）。
> 见 [[插值]] 和 [[全通滤波器 allpass]]。
>
> **880 Hz 的 -0.83%** = 约 14 音分——**明显可闻的音不准**。

### 2. 阻尼决定"像不像真的弦"

**实测**（$f_0$ = 220 Hz，decay = 0.9995，RMS 随时间）：

| 时间 | **无阻尼**（纯延迟） | **有阻尼**（0.5 两点平均） |
|---|---|---|
| 0.0 s | 5.637e-01 | 1.837e-01 |
| 0.5 s | 5.336e-01 | **4.152e-02** |
| 1.0 s | 5.048e-01 | 2.909e-02 |
| 2.0 s | 4.522e-01 | 1.828e-02 |
| 3.0 s | 4.051e-01 | 1.216e-02 |

> [!important] 怎么读
> - **无阻尼**：衰减很慢（0.56 → 0.41，3 秒），而且**所有频率一样快** → 听起来像"电子音"
> - **有阻尼**：衰减快得多（0.18 → 0.012），而且**高频先掉** → 听起来**像拨弦**
>
> **那个"0.5 两点平均"就是物理上的高频阻尼。**
> 它模拟了真实弦的高频损耗（空气阻力 + 内部摩擦）。

> [!tip] 阻尼的物理意义
> 一阶低通 `y[n] = 0.5*(x[n] + x[n-1])` 在高频处衰减更大：
> - 直流：增益 1
> - Nyquist：增益 0
>
> **所以高频成分每绕一圈就衰减更多** → 音色随时间变暗。
> 这正是拨弦后音色逐渐变"闷"的原因。

## 三、实现

```python
import numpy as np

def karplus_strong (f0, dur, sr=48000.0, decay=0.9995, seed=42):
    """Karplus-Strong 拨弦合成"""
    N = int (round (sr / f0))                     # ⚠️ 整数延迟
    buf = np.random.default_rng (seed).uniform (-1, 1, N).astype (float)
    buf -= np.mean (buf)                          # 去直流

    out = np.zeros (int (dur * sr))
    idx = 0
    for i in range (len (out)):
        out[i] = buf[idx]
        # ⚠️ 跨延迟线的两点平均 = 一阶低通（阻尼）
        prev = (idx - 1) % N
        buf[idx] = decay * 0.5 * (buf[idx] + buf[prev])
        idx = (idx + 1) % N
    return out
```

> [!danger] 我在这里写错过一次（本库记录）
> 我第一次写成了：
> ```python
> filtered = damping*cur + (1-damping)*prev      # ❌ 用的是"上一个输出"
> buf[idx] = filtered
> ```
> 那把一阶低通作用在**时间序列**上，而不是**延迟线的相邻点**上，
> 结果信号在 $N$ 个采样内就被平均没了。
>
> **正确的形式**是平均**延迟线里的相邻两个样本**：
> ```python
> buf[idx] = decay * 0.5 * (buf[idx] + buf[(idx-1) % N])    # ✅
> ```

> [!warning] 关于衰减的测量（诚实说明）
> 我尝试给出**分频段的 RT60**，但测出的数字**不可靠**：
> - 用阈值法时，噪声底导致早期就"低于阈值"
> - 用指数拟合时，得到了"高频 RT60 比低频长"的**物理上相反**的结果——
>   那是拟合到了噪声底
>
> **所以本页不给分频段 RT60 的数字。**
> 只给出上表的**整体 RMS 包络**（这个是可靠的）。
>
> **教训**：RT60 测量需要**信噪比足够**，
> 而物理建模信号的尾部会很快落到噪声底以下。
> 见 [[2026-10-14 测量工具会骗你 —— 十一次踩坑记录]]。

## 四、扩展方向

| 方向 | 做什么 | 效果 |
|---|---|---|
| **分数延迟** | 用全通/插值修正 $N$ | ✅ 音准（尤其高音） |
| **数字波导** | 两条延迟线（左右行波） | ✅ 正确的拨弦位置 |
| **激励塑形** | 滤波初始噪声 | 改变"拨片/手指"音色 |
| **非线性** | 张力随振幅变化 | "力度大音高升" |
| **多弦耦合** | 弦之间互相影响 | 钢琴/吉他的共鸣 |
| **管体共振** | 加共振滤波器 | 更真实 |

> [!tip] 数字波导 vs Karplus-Strong
> | | KS | 数字波导 |
> |---|---|---|
> | 延迟线 | 1 条 | 2 条（左右行波） |
> | 拨弦位置 | 🟠 简化处理 | ✅ 精确 |
> | 端点反射 | 🟠 隐含 | ✅ 显式建模 |
> | 复杂度 | 低 | 中 |
>
> **想做好听的弦乐，值得上数字波导。**

## 五、其他物理模型

| 乐器 | 模型 | 核心 |
|---|---|---|
| **弦**（吉他/钢琴） | 延迟线 + 阻尼 | 波导 |
| **管**（笛/小号） | 延迟线 + 非线性 | 空气柱 + 簧片 |
| **膜**（鼓） | 二维网格 | 波动方程离散化 |
| **板**（钹/锣） | 模态合成 | 多个共振峰叠加 |
| **人声** | 源-滤波器模型 | 声带脉冲 + 声道滤波 |

> [!note] 模态合成（modal synthesis）
> **另一种思路**：不模拟波动方程，而是直接叠加**共振模态**。
> ```
> 声音 = Σ_k A_k · e^(-t/τ_k) · sin(2π f_k t)
> ```
> - 优点：每个模态可独立控制、**永远不会不稳定**
> - 缺点：模态数要多（几十个）才真实
>
> **对鼓、钹这类"不规则"乐器，模态合成往往比波导更实用。**

## 六、AI 会怎么写错

| # | AI 常犯 | 后果 | 怎么查 |
|---|---|---|---|
| 1 | **滤波器作用错了对象**（时间序列 vs 延迟线） | 信号瞬间消失（**我犯过**） | 测 RMS 包络 |
| 2 | **整数延迟不修正** | 高音不准（实测 -0.83%） | 测音高 |
| 3 | **忘了去直流** | 低音有直流偏置 | `buf -= mean(buf)` |
| 4 | **decay 不钳制** | 发散（>1）或瞬间消失 | `clamp(0, 0.9999)` |
| 5 | **不测音高就交付** | 音不准 | 自相关测音高 |
| 6 | **用"上一个输出"做延迟线平均** | 等于做了两次低通 | 检查索引 |
| 7 | **白噪声不固定种子** | 每次音色不同 | 固定种子 |
| 8 | **忘了分数延迟** | 高音区音不准 | 用全通插值 |
| 9 | **在音频线程重建缓冲区** | 违反实时契约 | prepare 里分配 |
| 10 | **以为 KS 就是全部物理建模** | 概念片面 | 还有波导/模态 |

> [!danger] 第 1 条是最容易犯的
> AI 会把"阻尼"理解成"对输出做低通"，写成：
> ```cpp
> y = lowpass (delay.read());     // ❌ 对输出做低通
> ```
> 而正确的做法是**在反馈路径里低通**：
> ```cpp
> delay.write (decay * lowpass (delay.read()));   // ✅ 
> ```
>
> **区别**：前者只是给输出加了音色，后者才是**每次往返都衰减高频**——
> 后者才会产生"音色随时间变暗"的物理效果。

## 七、常见坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 声音瞬间消失 | 滤波器作用对象错 | 在反馈路径里滤波 |
| 高音不准 | 整数延迟 | 加分数延迟 |
| 有直流嗡声 | 激励含直流 | 去直流 |
| 发散 | decay ≥ 1 | 钳制到 0.9999 |
| 听起来像电子音 | 没有阻尼 | 加反馈低通 |
| 音色不随时间变暗 | 阻尼加在输出而非反馈 | 移到反馈路径 |
| 每次音色不同 | 随机种子未固定 | 固定种子 |
| 拨弦位置无效果 | KS 的简化限制 | 用数字波导 |

## 八、怎么验证

**四个必做测试**：

| # | 测试 | 判据 |
|---|---|---|
| 1 | **音高** | 自相关测出的 $f_0$ 与目标误差 < 1% |
| 2 | **衰减** | RMS 包络单调下降 |
| 3 | **高频衰减更快** | 有阻尼时，高频段比低频段先消失 |
| 4 | **稳定性** | 长时间运行不发散 |

```python
import numpy as np
SR = 48000.0

def karplus_strong (f0, dur, sr=SR, decay=0.9995, seed=42):
    N = int (round (sr/f0))
    buf = np.random.default_rng (seed).uniform (-1, 1, N).astype (float)
    buf -= np.mean (buf)
    out = np.zeros (int (dur*sr)); idx = 0
    for i in range (len (out)):
        out[i] = buf[idx]
        buf[idx] = decay * 0.5 * (buf[idx] + buf[(idx-1) % N])
        idx = (idx + 1) % N
    return out

def detect_pitch (y, sr=SR, fmin=50, fmax=2000):
    """自相关测音高"""
    y = y - np.mean (y)
    y = y[:int (sr*0.3)]
    ac = np.correlate (y, y, mode='full')[len(y)-1:]
    lo, hi = int (sr/fmax), int (sr/fmin)
    seg = ac[lo:hi]
    if len (seg) == 0: return 0.0
    return sr / (lo + np.argmax (seg))

# ① 音高
for f0 in [110, 220, 440]:
    y = karplus_strong (f0, 1.0, decay=0.9999)
    fm = detect_pitch (y, fmin=f0*0.6, fmax=f0*1.6)
    err = (fm - f0)/f0*100
    print (f"  f0={f0:>4}: 实测 {fm:>6.1f} Hz  ({err:+.2f}%)")
    assert abs(err) < 1.0, f"{f0}Hz 音高误差过大"
print ("✅ 音高全部在 1% 以内")

# ② 衰减（RMS 包络单调下降）
y = karplus_strong (220, 3.0, decay=0.9995)
w = int (SR*0.1)
rms = np.array ([np.sqrt(np.mean(y[i*w:(i+1)*w]**2)) for i in range(len(y)//w)])
assert rms[0] > rms[5] > rms[-1], "包络不是单调下降！"
print (f"✅ 衰减单调: {rms[0]:.4e} → {rms[5]:.4e} → {rms[-1]:.4e}")

# ③ 有阻尼 vs 无阻尼：高频衰减差异
def ks_undamped (f0, dur, sr=SR, decay=0.9995, seed=42):
    N = int (round (sr/f0))
    buf = np.random.default_rng (seed).uniform (-1, 1, N).astype (float)
    buf -= np.mean (buf)
    out = np.zeros (int (dur*sr)); idx = 0
    for i in range (len (out)):
        out[i] = buf[idx]
        buf[idx] = decay * buf[idx]
        idx = (idx + 1) % N
    return out

for name, fn in [('无阻尼', ks_undamped), ('有阻尼', karplus_strong)]:
    y = fn (220, 1.0)
    a = np.sqrt (np.mean (y[:int(SR*0.1)]**2))
    b = np.sqrt (np.mean (y[int(SR*0.9):]**2))
    print (f"  {name}: 起始 RMS {a:.4e} → 1 秒后 {b:.4e}")
```

> [!important] 第 2 个断言最简单也最有用
> `assert rms[0] > rms[5] > rms[-1]` —— 三行代码抓"信号瞬间消失"这类错误。
> **我最初的错误实现就会在这里失败。**
