# 软膝 soft knee

> [!important] 一句话
> **软膝让压缩在阈值附近"逐渐"开始，而不是突然拐弯。**
> 数学上就是**在膝宽区间内做一个平滑插值**——从"无压缩"过渡到"按比例压缩"。

## 为什么需要

**硬膝**的问题：

```
输入超过阈值 → 增益衰减**突然**开始
→ transfer curve 有**角点**（不可导）
→ 在阈值附近来回跳的信号会被"劈开"
```

**听觉后果**：

| 症状 | 原因 |
|---|---|
| 声音"发硬"、"有棱角" | transfer curve 的角点 |
| 在阈值附近的信号"抖动" | 增益在 0 和有衰减之间跳 |
| 大提琴、人声听起来"不自然" | 高次谐波（角点产生） |

> [!important] 软膝的价值
> **让 transfer curve 变成 $C^1$ 连续**（一阶导数连续）。
> 角点消失 → 高次谐波减少 → 听感自然。

---

## 一、三种膝的对比（实测）

**参数**：阈值 $T = -20$ dB，ratio $R = 4$，膝宽 $W = 10$ dB。

**公式**：设 $s = 1/R - 1$（斜率，负数），$ov = x - T$（超过阈值的量）

| 类型 | 增益衰减 $G(ov)$ |
|---|---|
| **硬膝** | $s \cdot ov$（若 $ov > 0$），否则 0 |
| **二次软膝** | $\dfrac{s\,(ov + W/2)^2}{2W}$（在 $[-W/2, W/2]$ 内） |

**实测**（增益衰减，dB）：

| 输入 dB | 硬膝 | **软膝** | 差 |
|---|---|---|---|
| **-30** | 0.000 | 0.000 | 0.000 |
| **-25**（膝下边界） | 0.000 | **0.000** | 0.000 |
| **-20**（阈值） | 0.000 | **-0.938** | **0.938** ← 差异所在 |
| **-15**（膝上边界） | -3.750 | **-3.750** | 0.000 |
| -10 | -7.500 | -7.500 | 0.000 |
| 0 | -15.000 | -15.000 | 0.000 |

> [!important] 怎么读
> - **膝区间外：两者完全相同**（-25 以下、-15 以上）
> - **膝区间内：软膝提前开始衰减**（-20 处已经衰减 0.938 dB）
> - 在阈值处**软膝已经压缩了将近 1 dB**
>
> **这就是"软膝听起来更早开始压缩"的原因。**

## 二、$C^1$ 连续性（软膝的核心性质）

> [!important] 二次软膝在两个边界上**导数精确接上**

**实测**（数值求导，$h = 10^{-6}$）：

| 边界 | 左导数 | 右导数 | 差 | 判定 |
|---|---|---|---|---|
| $ov = -W/2$（下端） | 0.000000 | -0.000000 | **3.75e-08** | ✅ $C^1$ |
| $ov = +W/2$（上端） | -0.750000 | -0.750000 | **3.77e-08** | ✅ $C^1$ |

**理论值**：下端导数为 0，上端导数为 $s = 1/4 - 1 = -0.75$ ✅

> [!tip] 为什么这很重要
> **$C^0$ 连续**（值连续）只保证没有跳变。
> **$C^1$ 连续**（导数连续）保证**没有"折角"**。
>
> 折角会在信号里产生**高次谐波**——正是你想避免的。
> 二次软膝的导数在两端恰好等于两侧的斜率，所以完全平滑。

## 三、二次软膝 = Hermite 插值（实测验证）

> [!important] 这不是巧合，是同一个东西

**二次软膝**：

$$G(ov) = \frac{s\,(ov + W/2)^2}{2W}$$

令 $t = (ov + W/2)/W \in [0,1]$，则：

$$G = \frac{s\,W}{2} t^2$$

**端点条件**：

| 位置 | 值 | 对 $ov$ 的导数 |
|---|---|---|
| $t = 0$（$ov = -W/2$） | $0$ | $0$ |
| $t = 1$（$ov = +W/2$） | $s\,W/2$ | $s$ |

**Hermite 三次插值**（给定两端值和两端导数）：

$$f(t) = h_{00}f_0 + h_{10}f'_0 + h_{01}f_1 + h_{11}f'_1$$

代入上面的端点条件，**结果恒等于 $\frac{sW}{2}t^2$**。

**实测**：

```
二次 vs Hermite（端点值 0 和 sW/2，导数 0 和 s）
最大差异 = 1.332e-15   ✅ 恒等
```

> [!danger] 这里我算错过一次（本库记录）
> 我第一次写 Hermite 时把**端点值写成了 $sW$**（应该是 $sW/2$），
> 结果在膝区间内得到**正值**——压缩器产生正增益，物理上不可能。
>
> 实测差异 7.29（而不是 ~1e-15）暴露了错误。
>
> **教训**：实现"平滑插值"时，**先把端点条件写下来核对**。
> 端点值错了，插值曲线会整体偏掉。

## 四、其他膝形状

| 形状 | 公式 | 特点 |
|---|---|---|
| **二次**（最常用） | $s\,t^2 W/2$ | $C^1$，够用 |
| **余弦** | $\frac{sW}{2}(1 - \cos\pi t)$ | 也 $C^1$，形状略不同 |
| **指数** | 类似二次 | 有时用于特定厂商风格 |
| **硬膝** | — | $C^0$ 但**不** $C^1$ |

**实测差异**（二次 vs 余弦）：

| 输入 dB | 二次 | 余弦 |
|---|---|---|
| -23.0 | **-0.150** | -0.716 |
| -21.0 | **-0.600** | -2.591 |
| -19.0 | **-1.350** | -4.909 |
| -17.0 | **-2.400** | -6.784 |

> [!warning] 两者差别很大！
> 余弦膝在膝区间内**压缩得更多**（更早开始、更陡）。
> 最大差异达 **4.384 dB**——这是**明显可闻**的。
>
> **所以"软膝"不是一种声音，是一族声音。**
> 换膝形状 = 换压缩器性格。

## 五、实现

```cpp
// 压缩器的 transfer curve（增益衰减量，dB）
class CompressorCurve
{
public:
    void setParams (float thresholdDb, float ratio, float kneeDb)
    {
        T = thresholdDb;
        R = std::max (1.0f, ratio);
        W = std::max (0.0f, kneeDb);
        s = 1.0f / R - 1.0f;              // 斜率（负数）
    }

    // 输入电平（dB）→ 增益衰减量（dB，<= 0）
    float gainReductionDb (float xDb) const noexcept
    {
        const float ov = xDb - T;          // 超过阈值的量

        if (W <= 1e-6f)                    // 硬膝（膝宽为 0）
            return (ov > 0.0f) ? s * ov : 0.0f;

        const float half = W * 0.5f;

        if (ov <= -half) return 0.0f;                       // 膝下：不压缩
        if (ov >=  half) return s * ov;                     // 膝上：正常压缩

        // 膝内：二次插值（C¹ 连续）
        const float t = (ov + half) / W;                    // 0 → 1
        return s * W * 0.5f * t * t;
    }

private:
    float T = -20.0f, R = 4.0f, W = 10.0f, s = -0.75f;
};
```

> [!warning] 三个实现细节
> 1. **膝宽为 0 时要走硬膝分支**（否则除零）
> 2. **ratio 钳制到 ≥ 1**（小于 1 就是扩展器了）
> 3. **膝宽钳制到 ≥ 0**
>
> 这些钳制是"用户能把参数拧到任何值"的必然要求。

**完整用法**（含检测器和增益应用）：

```cpp
void processBlock (juce::AudioBuffer<float>& buffer, juce::MidiBuffer&) override
{
    for (int ch = 0; ch < buffer.getNumChannels(); ++ch)
    {
        auto* data = buffer.getWritePointer (ch);
        for (int i = 0; i < buffer.getNumSamples(); ++i)
        {
            // ① 检测电平（见 [[包络跟随器 envelope follower]]）
            const float levelDb = env.process (std::abs (data[i]));

            // ② 算增益衰减
            const float grDb = curve.gainReductionDb (levelDb);

            // ③ 应用（平滑！见 [[参数平滑 parameter smoothing]]）
            data[i] *= juce::Decibels::decibelsToGain (grDb);
        }
    }
}
```

> [!danger] 别忘了几件事
> - **检测器**：用 dB 域还是线性域？本页假设 dB（要先 `log`）
> - **平滑**：`grDb` 每采样变化会导致失真 → 需要平滑
> - **makeup gain**：压缩后要补偿音量
> - **立体声链接**：左右应共用同一个增益衰减（否则声像漂移）
>
> 见 [[动态范围处理]] 和 [[包络跟随器 envelope follower]]。

## 六、AI 会怎么写错

| # | AI 常犯 | 后果 | 怎么查 |
|---|---|---|---|
| 1 | **膝宽为 0 时除零** | NaN | 检查是否有硬膝分支 |
| 2 | **ratio 不钳制** | ratio < 1 变成扩展器 | `max(1, ratio)` |
| 3 | **膝内公式的 W 用了整个膝宽而非半宽** | 曲线错位 | 公式是 $(ov+W/2)^2/(2W)$ |
| 4 | **端点条件写错**（如 $sW$ 而非 $sW/2$） | 产生正增益（物理不可能） | 验证膝内值 ≤ 0 |
| 5 | **以为所有软膝都一样** | 音色差 4 dB | 明确膝形状 |
| 6 | **忘了平滑增益衰减** | 失真 | 见 [[参数平滑 parameter smoothing]] |
| 7 | **立体声不链接** | 声像漂移 | 共用 GR |
| 8 | **在 dB 域和线性域混用** | 完全错的曲线 | 统一域 |
| 9 | **threshold 用线性值代入 dB 公式** | 曲线错 | 先转 dB |

> [!danger] 第 4 条是最隐蔽的
> 端点值写错时曲线**仍然看起来像一条平滑曲线**，
> 只是在某段产生了**正增益**（压缩器在放大）。
>
> **判据**：$G(ov) \le 0$ **对所有 $ov$ 成立**。
> 加一条断言就能抓到。

## 七、常见坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 膝宽设 0 时输出 NaN | 除零 | 硬膝分支 |
| ratio < 1 时声音变大 | 变成扩展器 | 钳制 ratio ≥ 1 |
| 阈值附近"抖动" | 硬膝的角点 | 用软膝 |
| 软膝在阈值处不衰减 | 膝宽符号错 | 检查公式 |
| 膝内出现正增益 | 端点值写错 | 验证 $G \le 0$ |
| 不同压缩器"软膝"差别大 | 膝形状不同 | 明确形状 |
| 压缩后有喀哒声 | GR 没平滑 | 加平滑 |
| 左右声道不一致 | 没链接 | 共用 GR |

## 八、怎么验证

**四个必做测试**：

| # | 测试 | 判据 |
|---|---|---|
| 1 | **$C^1$ 连续** | 两端导数差 < 1e-4 |
| 2 | **单调性** | $G$ 单调递减 |
| 3 | **不产生正增益** | $G(ov) \le 0$ 恒成立 |
| 4 | **膝外与硬膝一致** | 差异 = 0 |

```python
import numpy as np

def gain_reduction (x_db, T, R, W, knee='soft'):
    """增益衰减量（dB，<= 0）"""
    s = 1.0/R - 1.0
    ov = x_db - T

    if W <= 1e-9:                                   # 硬膝
        return s*ov if ov > 0 else 0.0
    half = W/2
    if ov <= -half: return 0.0
    if ov >=  half: return s*ov
    if knee == 'soft':
        t = (ov + half)/W
        return s*W*0.5*t*t
    elif knee == 'cosine':
        t = (ov + half)/W
        return s*W*0.5*(1 - np.cos(np.pi*t))
    raise ValueError (knee)

T, R, W = -20.0, 4.0, 10.0

# ① C¹ 连续
h = 1e-6
for x in [T-W/2, T+W/2]:
    dl = (gain_reduction(x,T,R,W) - gain_reduction(x-h,T,R,W))/h
    dr = (gain_reduction(x+h,T,R,W) - gain_reduction(x,T,R,W))/h
    assert abs(dl-dr) < 1e-4, f"{x} 处不 C¹"
print ("✅ C¹ 连续")

# ② 单调 + ③ 不产生正增益
xs = np.linspace (-60, 0, 1000)
g = np.array ([gain_reduction (x,T,R,W) for x in xs])
assert np.all (g <= 1e-12), f"出现正增益！max={g.max():.4f}"
assert np.all (np.diff(g) <= 1e-12), "非单调"
print ("✅ 单调且无正增益")

# ④ 膝外与硬膝一致
for x in [-40, -30, -26, -14, -10, 0]:
    a = gain_reduction (x,T,R,W,'soft')
    b = gain_reduction (x,T,R,W,0)          # 硬膝
    if abs(x-T) > W/2:
        assert abs(a-b) < 1e-12, f"{x} 处膝外不一致"
print ("✅ 膝外与硬膝一致")
```

**变异测试**（确认你的断言有牙）：

| 变异 | 应被哪个断言抓到 |
|---|---|
| 端点值改成 $sW$ | ③ 无正增益 |
| 漏掉硬膝分支 | ① 或崩溃 |
| ratio 不钳制 | ③（ratio<1 时产生正增益） |
