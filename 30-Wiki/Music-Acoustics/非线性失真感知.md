# 非线性失真感知

> [!important] 一句话
> **同样的 THD，听起来可以天差地别**——
> 关键不是"失真多少"，而是**谐波分布**和**是否混叠**。

## 为什么这一页重要

你在做失真/饱和类插件时，会面对一个反直觉的事实：

| 事实 | 后果 |
|---|---|
| 两个 THD 相同的失真，听感可能完全不同 | 不能只看 THD 数字 |
| **高次谐波**比低次刺耳得多 | 谐波衰减速率比总量更重要 |
| **混叠**产生非谐波成分 | 是"脏"的主要来源 |
| 人耳对**互调失真**比谐波失真敏感 | 多音信号比单音更能暴露问题 |

> [!note] 这一页的分工
> - [[非线性处理]] — 数学与实现
> - **本页** — **听感层面**的本质

## 一、实测：不同 shaper 的谐波分布

**测试**（本库验证，1kHz 正弦，幅度 0.5，整数周期落在 bin 上）：

| shaper | h1 | h2 | h3 | h4 | h5 | h6 | h7 |
|---|---|---|---|---|---|---|---|
| **恒等（无失真）** | **-6.0** | -220.7 | -234.2 | -242.5 | -248.7 | -253.6 | -257.7 |
| **软饱和 tanh** | -1.8 | **-215.8** | **-25.3** | -232.4 | **-46.9** | -245.2 | **-68.3** |
| **硬削波** | -0.0 | -214.6 | **-228.1** | -236.5 | -242.7 | -247.6 | -251.7 |
| **非对称** | -1.8 | **-21.4** | **-25.3** | **-38.3** | **-46.9** | -56.8 | **-68.3** |

（单位 dBFS；< -200 = 数值噪声 = 该次谐波**不存在**）

> [!tip] 第一行的作用：**验证测量框架**
> 恒等变换（无失真）只应该有基频 h1 = **-6.02 dBFS**（0.5 幅度的理论值），
> h2–h7 全部是噪声。
>
> 实测 h1 = **-6.0** ✅，h2–h7 都在 -220 以下 ✅
> **测量框架正确**，后面的数字才可信。
>
> **这个自检不能省**——本库曾因加窗未补偿相干增益，
> 导致所有幅度差 6.02 dB（见 [[窗函数]]）。

### 怎么读这张表

| 观察 | 含义 |
|---|---|
| **tanh 的 h2 = -215.8（噪声）** | 奇函数 → **没有偶次谐波**（见 [[非线性处理]]） |
| **tanh 的 h3 = -25.3，h5 = -46.9，h7 = -68.3** | 每级衰减约 **21 dB** → 高次谐波很少 |
| **硬削波的 h3 = -228（噪声！）** | ⚠️ **见下方说明** |
| **非对称的 h2 = -21.4** | 有真实的偶次谐波 → "温暖" |

> [!warning] 硬削波那行的 h3 异常，需要解释
> 上表里硬削波的 h3 = -228（噪声级），但**硬削波必然产生奇次谐波**。
>
> **原因**：上表的驱动量是 `drive=2.0`，输入 0.5 → `2×0.5 = 1.0`，
> 恰好**没有超过 ±1 的削波阈值** → 实际上**没有削波发生**！
>
> **这是一个"什么都没做"的测试**。
>
> **教训**：测试"失真"时，先确认**确实产生了失真**。

### 修正：用足够的驱动量重测（drive = 4.0）

| shaper | h1 | h2 | h3 | h5 |
|---|---|---|---|---|
| **tanh** | +1.0 | -212.2 | **-14.5** | **-27.3** |
| **硬削波** | +1.7 | -211.0 | **-11.1** | **-24.9** |
| **非对称** | +1.0 | **-18.3** | **-14.5** | **-27.3** |

> [!important] 这次数据是可信的
> - **硬削波的 h3 = -11.1**：确实在削波 ✅
> - **tanh 的 h2 = -212.2**（噪声）：奇函数 → 无偶次谐波 ✅
> - **非对称的 h2 = -18.3**：有真实偶次谐波 ✅
>
> **tanh vs 硬削波** 的 h3 差 3.4 dB、h5 差 2.4 dB——
> 差别不大（因为驱动量都不低）。
> **差别在更高次**：tanh 的衰减更快（见上一节的"每级 21 dB"）。

## 二、谐波次数与听感

> [!important] 感知上的经验规律
> | 谐波 | 听感倾向 |
> |---|---|
> | **2 次** | "温暖"、"厚"（八度） |
> | **3 次** | "有力"、"清晰"（八度+五度） |
> | **5、7 次** | 开始"刺"、"金属" |
> | **9 次以上** | 明显的"数字味"、"沙沙" |
> | **非谐波（混叠）** | 最刺耳——**不谐和** |

> [!note] 为什么低次谐波"好听"
> 2 次谐波 = 高八度 → 音乐上**协和**
> 3 次谐波 = 八度 + 五度 → 也协和
>
> **5 次以上**开始引入不协和音程（7 次是增四度附近）。
> 这是"温暖"vs"刺耳"的物理基础之一。

**从实测看**：

| shaper | 谐波衰减 | 听感（经验） |
|---|---|---|
| **tanh** | 每级约 21 dB | 温暖、平滑 |
| **非对称** | h2=-21, h3=-25, 之后每级约 10 dB | 温暖 + 稍厚 |
| **硬削波**（真削波时） | 约 -12 dB/oct（慢） | 激进、刺 |

> [!important] 衰减速率是关键
> **每级衰减 21 dB（tanh）vs 12 dB（硬削波）**：
> 在 h9 处相差 **约 60 dB**。
>
> 所以"tanh 听起来比硬削波温和"**不只是低次谐波少，而是高次谐波少得多**。

## 三、混叠：为什么它比谐波脏得多

> [!danger] 这是"数字味"的真正来源

| | 谐波 | **混叠** |
|---|---|---|
| 频率关系 | 与基频**成整数倍** | **无关系**（折返产物） |
| 音乐性 | 协和（音色变化） | **不谐和**（刺耳） |
| 能否事后去除 | — | ❌ **不可逆** |

**实测**（$f_0$ = 6kHz 硬削波，无过采样）：

| 成分 | 峰值 |
|---|---|
| 谐波峰值 | 61.8 dB |
| **混叠峰值** | **-44.0 dB** |
| 混叠/谐波 | **-105.9 dB** |

> [!note] 关于这个测量
> 上面的"混叠/谐波"比看起来很好（-105.9 dB），
> 但那是因为**测的是峰值**，而混叠是**分布在全频段的众多小成分**。
>
> **更有意义的指标是"混叠总能量 / 谐波能量"**——
> 本库在 [[抗混叠振荡器]] 里测的是这个：
> 朴素锯齿 -17.6 dB，PolyBLEP -67.3 dB。
>
> ⚠️ 本页的混叠测量方法与振荡器页不同，**两者不可直接比较**。

> [!tip] 一个简单的判断方法
> 把失真后的信号**降调播放**（或看频谱图）。
> - 谐波：随基频一起移动
> - **混叠：不跟着移动**（因为它是折返产物）
>
> 这是分辨"谐波失真"和"混叠"最直观的方法。

## 四、THD 之外：互调失真

> [!important] 单音测试测不出真实情况
> **THD 用单个正弦测量**，但音乐是**多音**的。
> 多音通过非线性会产生**互调失真（IMD）**：
>
> $$f_{\text{IMD}} = |m f_1 \pm n f_2|$$
>
> 这些**不是任何一个音的谐波** → 听起来"糊"、"脏"。

**实测对比**（同一 shaper，单音 vs 双音）：

| 测试信号 | 产生的成分 |
|---|---|
| 单音 1kHz | 1k, 2k, 3k... （谐波，协和） |
| **双音 1k + 1.1k** | 1k, 1.1k, **2.1k, 0.1k, 3.2k, ...**（互调，不协和） |

> [!danger] 为什么 IMD 更暴露问题
> 双音测试里，**差频成分**（如 0.1 kHz）落在低频——
> 那是"嗡嗡"声，**极易察觉**。
>
> **所以测失真插件时，除了单音扫频，一定要用双音测试。**

## 五、过采样真的能"变暖"吗？

> [!danger] 这是本库纠正过的一个误解
> 常见说法："加了过采样后声音变暖了。"
>
> **这是错觉。** 过采样只压低**混叠**（折返的成分），
> **不会改变带内的偶次谐波**。
>
> 见 [[非线性处理]] 的实测：偶次谐波是带内合法成分，过采样不动它。
>
> **想要"温暖"，要改的是 shaper 的对称性**（用非对称 shaper 产生偶次谐波），
> 不是过采样倍率。

**过采样的真实效果**（见 [[抗混叠振荡器]] 实测）：

| 方法 | 混叠/谐波 |
|---|---|
| 无处理 | -17.6 dB |
| 4× 过采样 | **-32.4 dB**（改善 14.9 dB） |
| PolyBLEP | -67.3 dB（改善 49.7 dB） |

→ 过采样让声音**更干净**（混叠少了），不是"更暖"。

## 六、AI 会怎么写错

| # | AI 常犯 | 后果 | 怎么查 |
|---|---|---|---|
| 1 | **只看 THD 数字** | 漏掉谐波分布差异 | 看各次谐波表 |
| 2 | **说"过采样让声音变暖"** | 概念错 | 暖来自 shaper 对称性 |
| 3 | **单音测试就下结论** | 漏掉 IMD | 加双音测试 |
| 4 | **不验证"失真真的发生了"** | 测了个恒等变换 | 看 h1 的增益变化 |
| 5 | **混淆谐波失真与混叠** | 诊断方向错 | 降调播放看是否跟随 |
| 6 | **以为"THD 低 = 好听"** | 忽略谐波分布 | 见第一节 |
| 7 | **测量不加窗 / 不加整数周期** | 数据全是泄漏 | 见 [[窗函数]] |
| 8 | **用相对基频的 dB 判断"有没有该次谐波"** | 误读（本库犯过） | 用**绝对**电平 |

> [!danger] 第 8 条是本库真实犯过的错
> 判断"某次谐波是否存在"时，必须看**绝对电平**（dBFS）。
> 用相对基频的 dB 时，如果基频接近 0（如偶函数），
> 相除会得到 **+200 dB** 这种无意义数字，被误读成"存在"。
>
> **判据**：绝对电平 **< -200 dBFS = 数值噪声 = 不存在**。

## 七、常见坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 高音区"沙沙" | 混叠 | 过采样 / 抗混叠 shaper |
| 声音"糊" | 互调失真 | 降低驱动量 |
| 测出 THD 很低但难听 | 高次谐波多 | 换谐波衰减快的 shaper |
| 测试什么都没变 | 驱动量不够，没真的削波 | 确认 h1 增益变化 |
| 加了过采样"变暖" | 错觉 | 暖来自对称性 |
| 不同插件"失真度"无法比较 | THD 定义/测量方式不同 | 看完整谐波表 |
| 单音测试通过但多音不行 | 没测 IMD | 加双音测试 |

## 八、怎么验证

```python
import numpy as np
SR = 48000

def harmonics (y, f0, sr=SR):
    """各次谐波的**绝对**电平（dBFS）"""
    w = np.hanning (len(y))
    X = np.abs (np.fft.rfft (y * w)) / np.sum (w) * 2      # ⚠️ 除以 sum(w)
    fr = np.fft.rfftfreq (len(y), 1/sr)
    def at (f): return X[np.argmin (np.abs (fr - f))]
    return [20*np.log10 (at (k*f0) + 1e-20) for k in range(1, 16) if k*f0 < sr/2]

# ⚠️ 整数周期 + 落在 bin 上（本库的教训）
F0, CYCLES = 1000.0, 1000
N = int (SR * CYCLES / F0)
f0 = round (F0 * N / SR) * SR / N
t = np.arange (N) / SR
x = 0.5 * np.sin (2*np.pi*f0*t)

# ① 先用恒等变换校准测量框架
h_id = harmonics (x, f0)
assert abs(h_id[0] + 6.02) < 0.1, f"基频应为 -6.02 dBFS，实测 {h_id[0]:.2f}"
assert max(h_id[1:]) < -200, "恒等变换不应有谐波！"
print (f"✅ 测量框架正确（h1 = {h_id[0]:.2f} dBFS，无谐波）")

# ② 测失真（确认失真真的发生）
for name, fn in [('tanh',    lambda v: np.tanh (4.0*v)),
                 ('硬削波',   lambda v: np.clip (4.0*v, -1, 1)),
                 ('非对称',   lambda v: np.tanh(4.0*v) + 0.3*np.tanh(4.0*v)**2)]:
    h = harmonics (fn (x), f0)
    # ⚠️ 确认失真发生：h1 应该变了
    assert abs(h[0] - h_id[0]) > 0.5, f"{name} 似乎没产生失真"
    print (f"  {name:<8} h1={h[0]:>6.1f}  h2={h[1]:>7.1f}  h3={h[2]:>7.1f}  h5={h[4]:>7.1f}")

print ("✅ 所有 shaper 确实产生了失真")
```

> [!important] 两个断言的价值
> 1. `assert max(h_id[1:]) < -200` — 确认测量框架本身没引入假谐波
> 2. `assert abs(h[0] - h_id[0]) > 0.5` — 确认**失真真的发生了**
>
> 第二个尤其重要——本库实测中就出现过"驱动量不够，
> 硬削波根本没削波"的情况（见第一节的说明）。
