# exp-007：心理声学实测

这一批实验由子代理完成，**Lead 复核并修正了 3 处测试断言**。

|---|---|

## 可靠的实测结论

**ISO 226**：
- 公式 (1) 是 `Lp = (10/αf)·lg(Af) − LU + 94` —— **`− LU` 项极易漏抄**
  漏掉后在 1 kHz 处**看不出差异**（LU=0），但 100 Hz 处差 **8.1 dB**
- 公式 (2) 是 `(Lp + LU)`，不是 `(Lp − LU)`
- 1 kHz 处公式给 **40.0100 dB SPL**（不是精确 40.000，是标准自带偏差）
- `LU` 峰值 **+2.5 dB @ 3150 Hz**（不是 800 Hz）
- `Tf` 最小 **−6.0 dB @ 3150 Hz**；`Tf(20Hz) = 78.5 dB`
- `αf` 最小 **0.242 @ 4000/5000 Hz**；1 kHz = 0.250

**K 加权 / LUFS**：
- K 加权 @ **997 Hz = +0.6910 dB** → 这解释了 −0.691 dB 偏移
  → **这就是校准音用 997 Hz 而不是 1000 Hz 的原因**
- 峰值 −20 dBFS 的 997 Hz 正弦 = **−23.010 LUFS**（单声道）
- 同信号双声道 = **−20.000 LUFS** → **mono vs dual-mono 差 3.010 dB**

**临界频带**：
- Bark(1 kHz) = **8.511**（文献常引 8.5）
- ERB(1 kHz) = **132.64 Hz**（文献常引 ~132 Hz）
- Zwicker 临界带宽 / ERB 的比值**不是常数**：100 Hz 处 2.84，1 kHz 处最小 1.22

| # | 原断言 | 问题 | 修正 |
