# 采样与量化

> [!important] 一句话
> **采样**把时间离散化（每秒取多少个点），**量化**把幅度离散化（每个点用多少位表示）。
> 两者都会引入误差，但**性质完全不同**：
> 采样误差是**混叠**（可听、难修），量化误差是**噪声**（不可听、可用 dither 改善）。

## 为什么这一页重要

| 你做插件时会遇到 | 对应本页哪一节 |
|---|---|
| 为什么 44.1kHz 能表示 20kHz？ | 采样定理 |
| 为什么插件内部用 float 而不是 int？ | 浮点音频表示 |
| 位深转换时要不要加 dither？ | 抖动 dither |
| 为什么 int16 要除以 32768 而不是 32767？ | 量化与归一化 |
| 96kHz 到底有没有意义？ | 采样率的选择 |

## 一、采样：把时间离散化

**采样** = 每隔 $T = 1/f_s$ 秒取一个值。

$$x[n] = x(nT), \qquad T = \frac{1}{f_s}$$

### 采样定理（奈奎斯特-香农）

> 如果信号是**带限**的（最高频率为 $f_{max}$），
> 那么当 $f_s > 2 f_{max}$ 时，可以**无失真**地重建原信号。

**$f_s/2$ 称为奈奎斯特频率（Nyquist frequency）。**

> [!danger] 定理的前提条件最常被忽略
> 定理要求信号**严格带限**——即 $f_{max}$ 以上**完全没有能量**。
>
> 真实信号（尤其是**非线性处理之后**）**不是带限的**。
> 硬削波会产生无限多的谐波 → 采样定理的前提不成立 → **必然混叠**。
>
> **这就是为什么 [[过采样 oversampling]] 是必需的。**

### 混叠：采样误差的表现

超过奈奎斯特频率的成分**不会消失，而是折叠回来**：

$$f_{alias} = \left| f - f_s \cdot \mathrm{round}\!\left(\frac{f}{f_s}\right) \right|$$

**实测验证**（48kHz 采样率，奈奎斯特 = 24kHz）：

| 输入频率 | 理论折叠 | 实测（FFT） |
|---|---|---|
| 25 kHz | 23 kHz | 22998 Hz ✅ |
| 30 kHz | 18 kHz | 18000 Hz ✅ |
| 40 kHz | 8 kHz | 7998 Hz ✅ |
| 50 kHz | 2 kHz | 1998 Hz ✅ |
| 70 kHz | 22 kHz | 22002 Hz ✅ |

> [!warning] 混叠**不可逆**
> 一旦折回来，它和真实信号在数学上**完全无法区分**。
> 所以只能在**产生之前**防止（抗混叠滤波 / 过采样），不能事后修复。
>
> 详见 [[混叠 aliasing]]。

## 二、量化：把幅度离散化

**量化** = 把连续幅度映射到有限个离散电平。

$$x_q[n] = \Delta \cdot \mathrm{round}\!\left(\frac{x[n]}{\Delta}\right), \qquad \Delta = \frac{2A}{2^N}$$

其中 $N$ 是位深，$A$ 是满幅值。

### 量化误差

**误差范围**：$\pm \Delta/2$（半个 LSB）。

**如果假设误差在 $\pm\Delta/2$ 内均匀分布**：

$$\text{噪声功率} = \frac{\Delta^2}{12}$$

**满幅正弦的功率** = $(A/\sqrt{2})^2 = A^2/2$。

所以：

$$\mathrm{SNR} = 10\log_{10}\frac{A^2/2}{\Delta^2/12} = 10\log_{10}\frac{6A^2}{\Delta^2}$$

代入 $\Delta = 2A/2^N$：

$$\boxed{\mathrm{SNR_{dB}} \approx 6.02N + 1.76}$$

> [!important] 这个公式的来源
> **6.02** = $20\log_{10}(2)$ —— 每增加 1 bit，动态范围增加约 6 dB。
> **1.76** 来自"满幅正弦"和"均匀分布误差"这两个假设。
>
> 如果信号不是正弦（比如方波、或者信号没到满幅），实际值会不同。

**实测验证**：

| 位深 | 理论 SNR | 实测 SNR |
|---|---|---|
| 8-bit | 49.92 dB | 49.40 dB ✅ |
| 16-bit | 98.08 dB | 102.11 dB |
| 24-bit | 146.24 dB | 145.90 dB ✅ |

（16-bit 实测偏高是因为测试信号幅度 0.99 且量化误差不完全均匀——公式是**近似**。）

## 三、位深与动态范围

| 位深 | 理论动态范围 | 实际用途 |
|---|---|---|
| 8-bit | ~50 dB | 电话、老游戏 |
| 16-bit | ~98 dB | CD、大部分发行格式 |
| 24-bit | ~146 dB | 录音、混音工程 |
| **32-bit float** | **~1500 dB** | **插件内部处理** |

> [!important] 32-bit float 不是"更多位深"
> 它是**浮点表示**，不是整数。区别很大：
>
> | | 24-bit 整数 | 32-bit 浮点 |
> |---|---|---|
> | 表示方式 | 定点 | 尾数 + 指数 |
> | 动态范围 | 146 dB（固定） | ~1500 dB |
> | 能否超过 ±1.0 | ❌ 不能 | ✅ 可以（有 headroom） |
> | 小信号精度 | 绝对（固定 LSB） | **相对**（始终约 24 bit 有效） |
>
> **为什么插件内部必须用 float**：
> 中间结果可能超过 ±1.0（多个信号相加、滤波器振铃），
> 整数会**回绕**（wrap around）→ 变成刺耳的噪声；
> 浮点只是"超出范围"，后续衰减回来就没事。

## 四、抖动 dither：为什么加噪声反而更好

> [!important] 反直觉但真实
> **在降低位深时加一点点噪声，听起来会更好。**

### 原理

不用 dither 时，量化误差**与信号相关** → 表现为**谐波失真**（听起来像音色改变）。
用 dither 后，误差变成**不相关的白噪声**（听起来像嘶声）。

**人耳对宽带噪声的容忍度远高于谐波失真。**

### 实测验证

输入：极低电平（0.5–3 LSB）的 1kHz 正弦，16-bit 量化。

| 信号幅度 | dither | 谐波电平 | 噪声电平 | 谐波 - 噪声 |
|---|---|---|---|---|
| 1.0 LSB | 无 | **-101.6 dB** | -145.8 dB | **44.2 dB** |
| 1.0 LSB | **有** | **-131.2 dB** | -138.1 dB | **6.9 dB** |
| 3.0 LSB | 无 | **-104.5 dB** | -141.9 dB | **37.4 dB** |
| 3.0 LSB | **有** | **-129.8 dB** | -137.6 dB | **7.7 dB** |

> [!tip] 怎么读这张表
> - **谐波降低了约 27 dB**（-101.6 → -131.2）
> - **噪声抬高了约 8 dB**（-145.8 → -138.1）
> - **"谐波 - 噪声"从 44 dB 降到 7 dB**
>
> 也就是说：**总失真没变小，但失真的"性质"变了**——
> 从"跟着信号走的谐波"变成"恒定的宽带噪声"。
> 后者在听感上"干净"得多。

### 实现

```cpp
// 最简单的 dither：加 1 LSB 的三角分布噪声（TPDF）
float tpdfDither (std::mt19937& rng)
{
    std::uniform_real_distribution<float> d (-0.5f, 0.5f);
    return d (rng) + d (rng);        // 两个均匀分布相加 = 三角分布
}

// 降位深时
float d = tpdfDither (rng) / (float)(1 << (bits - 1));
float x_dithered = x + d;
int16_t q = (int16_t) std::lround (std::clamp (x_dithered, -1.0f, 1.0f) * 32767.0f);
```

> [!warning] dither 只在**降位深**时需要
> - ✅ 32-bit float → 16-bit（导出、发行）
> - ❌ 32-bit float → 24-bit（差距太小，几乎无意义）
> - ❌ 插件内部处理（本来就该用 float，不该降位深）
>
> **不要在插件内部处理链里加 dither。**

## 五、归一化的坑：32767 还是 32768

> [!warning] 这两个值不同，而且各有理由
> ```cpp
> x = sample / 32767.0f;   // 让 +32767 映射到 +1.0
> x = sample / 32768.0f;   // 让 int16 的范围映射到 [-1, 1)
> ```
>
> | 除数 | 优点 | 缺点 |
> |---|---|---|
> | **32767** | +1.0 可达，对称 | 负半轴不对称（-32768 → -1.00003） |
> | **32768** | 完美对称，数学干净 | 最大正值只到 0.99997 |
>
> **业界两种都有用。** 关键是**转换的两个方向要用同一个约定**，
> 否则 round-trip 会有误差。

> [!danger] AI 常在这里出错
> AI 经常**混用**：读取用 32768，写入用 32767（或反过来）。
> 后果是 round-trip 后信号**幅度有微小偏差**，或者 null test 停在 -90dB
> 而不是 -inf。
>
> **见 [[音频测量基础]] 的取整陷阱。**

## 六、制作人视角的翻译表

| 你熟悉的说法 | 工程含义 |
|---|---|
| "这个文件是 24/48" | 位深 24-bit，采样率 48kHz |
| "升到 96k 更好" | 采样率翻倍，但**不能修复已混叠的内容** |
| "导出时要不要 dither" | 降位深时应该要；不降就不需要 |
| "这个插件有数字味" | 可能是混叠，也可能是量化，见 [[混叠 aliasing]] |
| "32-bit float 录音" | 有巨大 headroom，几乎不可能削波 |
| "削波了" | 超过 ±1.0（浮点）或整数回绕（定点） |
| "位深不够听着糙" | 量化噪声 + 缺 dither 的谐波失真 |

## 七、AI 会怎么写错

| # | AI 常犯 | 后果 | 怎么查 |
|---|---|---|---|
| 1 | **归一化除数混用**（32767/32768） | round-trip 有偏差，null test 失败 | 检查读写是否用同一约定 |
| 2 | **不做参数钳制直接转 int** | 整数回绕 → 刺耳噪声 | 检查转换前有没有 `clamp` |
| 3 | **用 `(int)` 截断而不是 `lround`** | 系统性偏差（-0.5 LSB） | 检查是否用 `std::lround` |
| 4 | **在插件内部降位深** | 白白损失精度 | 内部应全程 float |
| 5 | **以为 32-bit float 是"更多位深"** | 概念错误 → 错误设计 | 记住它是浮点，有 headroom |
| 6 | **dither 用了均匀分布而非三角** | 噪声调制（noise modulation） | 用两个均匀分布相加 |
| 7 | **以为提高采样率能修复混叠** | 混叠已经不可逆 | 必须在产生前防止 |
| 8 | **忘了 int16 的 -32768 特殊值** | `-(-32768)` 溢出 | 用 int32 中间变量 |

> [!warning] 第 8 条是个经典的 C++ 陷阱
> `int16_t` 的范围是 **-32768 到 32767**（不对称！）。
> ```cpp
> int16_t x = -32768;
> int16_t y = -x;        // ❌ 溢出！-(-32768) = 32768 超出范围
> int32_t y = -(int32_t)x;  // ✅ 先提升到 int32
> ```
> 这是 C++ 里少数**有符号整数溢出**的真实案例。

## 八、常见坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 导出后声音变刺耳 | 整数回绕（没钳制） | 转换前 `clamp` |
| 频谱有非谐波成分 | 混叠 | 见 [[混叠 aliasing]] |
| 低电平信号听起来"颗粒感" | 量化 + 无 dither | 加 dither（仅降位深时） |
| null test 停在 -90dB | 归一化/取整约定不一致 | 统一约定，或比浮点 |
| 读 WAV 后幅度略偏 | 32767 vs 32768 | 检查除数 |
| 24-bit 转 16-bit 后变差 | 没做 dither | 加 TPDF dither |
| 32-bit float 文件读成噪声 | 当成整数解析了 | 检查格式标记（`fmt ` 的 format 字段） |

## 九、怎么验证

| 测试 | 方法 | 期望 |
|---|---|---|
| **量化 SNR** | 满幅正弦量化，测 SNR | ≈ 6.02N + 1.76 dB |
| **dither 有效** | 低电平正弦，比谐波电平 | 谐波降低 ~25 dB |
| **round-trip** | int → float → int | 完全一致（同一约定下） |
| **无回绕** | 喂 ±1.5，看输出 | 应钳制，不应突变 |
| **折叠公式** | 喂 > Nyquist 的正弦，看 FFT | 位置 = 折叠公式 |

```python
import numpy as np
# 验证量化 SNR 公式
SR, N = 48000, 48000
t = np.arange(N)/SR
x = 0.99*np.sin(2*np.pi*1000*t)
for bits in [8, 16, 24]:
    s = 2**(bits-1) - 1
    q = np.round(x*s)/s
    snr = 10*np.log10(np.mean(x**2)/np.mean((x-q)**2))
    print(f"{bits:>3}-bit: 实测 {snr:>6.1f} dB, 理论 {6.02*bits+1.76:>6.1f} dB")
```
