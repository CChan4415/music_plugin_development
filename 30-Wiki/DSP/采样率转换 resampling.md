# 采样率转换 resampling

> [!important] 一句话
> **改变采样率 = 重新采样**。降采样必须先低通，升采样必须后低通——
> **两个方向都需要抗混叠滤波，只是滤的位置不同。**

## 什么时候会遇到

| 场景 | 方向 | 倍率 |
|---|---|---|
| 插件在 44.1k 工程里、内部跑 48k | 升/降 | 非整数 |
| 过采样（抗混叠） | 升 + 降 | 2×/4×/8× |
| 音频文件格式转换 | 升降 | 任意 |
| 卷积混响加载不同采样率的 IR | 转换 | 任意 |
| 变调 / 变速（不改音高） | 变频 | 可变 |

> [!note] 两种类型
> | 类型 | 倍率 | 典型做法 |
> |---|---|---|
> | **整数倍**（2×/4×） | 简单 | 多相 + 半带 FIR |
> | **任意倍率**（44.1↔48） | 复杂 | 多相 + 重采样滤波器，或异步 SRC |
>
> **过采样是整数倍的特例**，见 [[过采样 oversampling]]。

## 一、降采样：必须先低通（实测）

**问题**：如果新采样率是 $f_s'$，则新的 Nyquist 是 $f_s'/2$。
原来 $f_s'/2$ 以上的成分会**折叠**回来。

**实测**（本库验证）：

```
原信号：30 kHz @ 96 kHz（Nyquist = 48 kHz，合法）
目标：降到 48 kHz（新 Nyquist = 24 kHz）
```

| 做法 | 结果 |
|---|---|
| ❌ **简单抽取** `x[::2]` | 主频变成 **18 kHz**（30k 折叠到 18k） |
| ✅ **先低通(20kHz) 再抽取** | 30 kHz 被滤掉，残留峰值 **0.0003** |

> [!danger] `x[::2]` 是错的
> 简单抽取**没有任何抗混叠**——它等价于"采样率减半但不过滤"。
> 30 kHz（合法的高频）折叠成 18 kHz（听得见的不谐和音）。
>
> **这就是 AI 最常写的降采样代码。**

**正确流程**：

```
低通滤波（截止 = 新 Nyquist × 0.9）→ 抽取
```

```python
def downsample (x, factor, fs_in, fs_out):
    """降采样：先低通，再抽取"""
    assert fs_in % fs_out == 0
    factor = fs_in // fs_out

    # ⚠️ 截止频率 = 新 Nyquist，留一点余量
    cutoff = 0.45 * fs_out                    # 略低于 fs_out/2

    h = design_lowpass_fir (cutoff, fs_in)    # 抗混叠滤波器
    x_filtered = np.convolve (x, h, mode='same')
    return x_filtered[::factor]
```

## 二、升采样：零插值后必须低通（实测）

**问题**：在两个样本之间插入 0，会在频域产生**镜像**（imaging）。

**实测**：

```
原信号：5 kHz @ 48 kHz，升到 96 kHz
```

| 做法 | 结果 |
|---|---|
| ❌ **零插值不滤波** | 出现镜像频率：**42 kHz、43 kHz** 等 |
| ✅ **零插值 + 低通** | 主频 5 kHz，镜像被滤掉 ✅ |

**为什么会有镜像**：

零插值（在样本间补 0）会在频域**复制**原频谱。原 0–24 kHz 的内容
被复制到 24–48 kHz（新采样率下的 24–48 是"上半段"）。

> [!important] 镜像 vs 混叠
> | | 产生于 | 位置 |
> |---|---|---|
> | **混叠**（aliasing） | 降采样 | 高频**折回**低频 |
> | **镜像**（imaging） | 升采样 | 频谱**被复制**到高频 |
>
> 两者都是"不该有的频率成分"，都需要低通滤波器。

**正确流程**：

```
零插值 → 低通（截止 = 原 Nyquist）→ 乘 factor 补偿增益
```

```python
def upsample (x, factor, fs_in, fs_out):
    """升采样：零插值 + 低通"""
    assert fs_out % fs_in == 0

    # ① 零插值
    up = np.zeros (len(x) * factor)
    up[::factor] = x

    # ② 低通（截止 = 原 Nyquist）
    cutoff = 0.45 * fs_in
    h = design_lowpass_fir (cutoff, fs_out)
    up = np.convolve (up, h, mode='same')

    # ③ ⚠️ 补偿增益：零插值让能量降到 1/factor
    return up * factor
```

> [!warning] 别忘了乘 factor
> 零插值后，信号的平均功率降到 $1/\text{factor}$（因为补了 0）。
> 低通滤波后要**乘回 factor**，否则输出音量变小。
>
> **实测常见症状**："升采样后声音变小了" → 就是这个。

## 三、多相分解：效率的关键

**朴素做法的浪费**：

升采样 4× 后，信号里 **75% 的样本是 0**。
对它们做卷积是**纯浪费**。

**多相分解**：把滤波器拆成 4 组，只算非零样本对应的那组。

| 做法 | 每输出样本的乘加数 |
|---|---|
| 朴素（先插值再滤波） | $N$（滤波器长度） |
| **多相** | $N / \text{factor}$ |

> [!tip] 这就是"高效重采样"的全部秘密
> **不要真的插入 0**，而是**跳过它们**，用不同的滤波器相位直接算输出。
>
> 实现上叫"多相滤波器组"（polyphase filter bank）。
> 见 [[多速率处理 multirate]]。

```
朴素：  插 0 → 长卷积 → 丢弃多余      (慢)
多相：  按输出相位选子滤波器 → 直接算   (快 factor 倍)
```

## 四、插值方法：质量 vs 成本

**对于任意倍率的重采样**，需要分数延迟插值：

| 方法 | 质量 | CPU | 用途 |
|---|---|---|---|
| **零阶保持**（最近邻） | ❌ 很差（高频失真大） | 最低 | 几乎不用 |
| **线性插值** | 🟠 一般（高频衰减） | 低 | 低质量场景 |
| **三次（Catmull-Rom）** | ✅ 好 | 中 | 通用 |
| **sinc / 加窗 sinc** | ✅✅ 最好 | 高 | 高质量 |
| **全通插值** | ✅ 好（相位好） | 中 | 需要平坦幅度 |

> [!important] 线性插值的隐藏代价
> 线性插值在**高频处有衰减**（相当于一个低通），
> 而且衰减量**随频率变化**——所以它会**改变音色**。
>
> 实测数据见 [[插值]]。
>
> **降采样/升采样时**：这个衰减发生在**原 Nyquist 附近**，
> 通常可以接受（那里本来就没多少能量）。
> **调制延迟线时**：不能接受（会导致音色随调制变化）。

## 五、采样率转换的两种模式

| 模式 | 特点 | 用途 |
|---|---|---|
| **同步**（synchronous） | 输入输出时钟锁定 | 文件转换、固定倍率过采样 |
| **异步**（asynchronous） | 时钟独立，需估计比率 | 实时设备（不同声卡） |

> [!note] 异步 SRC 的特殊问题
> 两个时钟有微小偏差（ppm 级）→ 需要**持续估计比率**并微调。
> 质量更难保证，通常用专门的算法（如 SoX、r8brain 的实现）。
>
> **你的插件大概率只需要同步 SRC**（JUCE 的 `ResamplingAudioSource`、
> 或自己写的整数倍过采样）。

## 六、AI 会怎么写错

| # | AI 常犯 | 后果 | 怎么查 |
|---|---|---|---|
| 1 | **降采样用 `x[::2]`（不滤波）** | 混叠（实测 30k→18k） | 必须先低通 |
| 2 | **升采样后不乘 factor** | 输出音量变小 | 检查增益补偿 |
| 3 | **升采样不滤波** | 镜像（实测出现 42/43 kHz） | 零插值后必须低通 |
| 4 | **截止频率设成 Nyquist（不留余量）** | 过渡带不够，残留混叠 | 用 0.45× |
| 5 | **真的插入 0 再卷积** | 慢 factor 倍 | 用多相分解 |
| 6 | **线性插值当"高质量"** | 高频衰减 | 用 sinc/三次 |
| 7 | **忘了报告延迟** | 多轨错位 | 滤波器有延迟 |
| 8 | **每采样重算滤波器系数** | CPU 爆炸 | prepare 里算好 |
| 9 | **异步 SRC 用同步实现** | 长时间后音调漂移 | 用专门的异步 SRC |
| 10 | **在音频线程分配缓冲区** | 违反实时契约 | prepare 里分配 |

> [!danger] 第 1 条是"看起来最合理"的错误
> `x[::2]` 是"降采样"最自然的写法，**数学上也确实是抽取**。
> 但它缺少抗混叠滤波——而 AI 通常不会主动加。
>
> **判据**：代码里有没有低通滤波器？没有就是错的。

## 七、常见坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 降采样后有怪声 | 没做抗混叠 | 先低通再抽取 |
| 升采样后音量变小 | 没乘 factor | `up * factor` |
| 升采样有刺耳高频 | 镜像没滤掉 | 零插值后低通 |
| 高频段有混叠残留 | 截止频率太靠近 Nyquist | 用 0.45×，或加长滤波器 |
| SRC 后音色变了 | 插值方法质量差 | 换 sinc/三次 |
| CPU 占用高 | 没用多相分解 | 多相实现 |
| 多轨错位 | 没报告 SRC 的延迟 | `setLatencySamples` |
| 长时间播放音调漂移 | 异步场景用了同步算法 | 用异步 SRC |

## 八、怎么验证

**三个必做测试**：

| # | 测试 | 判据 |
|---|---|---|
| 1 | **降采样无混叠**：输入高频，检查是否折回 | 折叠成分 < -80 dB |
| 2 | **升采样无镜像**：检查原 Nyquist 以上的能量 | < -80 dB |
| 3 | **往返一致性**：升→降，或降→升 | 通带内误差 < -100 dB |

```python
import numpy as np

def spectrum_of (sig, fs):
    X = np.abs (np.fft.rfft (sig))
    f = np.fft.rfftfreq (len(sig), 1/fs)
    return f, X

def design_lowpass_fir (fc, fs, n_taps=257):
    M = (n_taps-1)//2
    n = np.arange (n_taps)
    wc = 2*np.pi*fc/fs
    h = np.sin (wc*(n-M)) / (np.pi*(n-M)); h[M] = wc/np.pi
    h *= np.hamming (n_taps)
    return h / np.sum (h)

# ① 降采样：验证抗混叠
fs_hi, fs_lo = 96000.0, 48000.0
t = np.arange (96000) / fs_hi
x = np.cos (2*np.pi*30000*t)          # 30kHz，在 96k 下合法

bad  = x[::2]                                        # ❌ 简单抽取
good = np.convolve (x, design_lowpass_fir(20000.0, fs_hi), 'same')[::2]   # ✅

f, Xb = spectrum_of (bad,  fs_lo)
_, Xg = spectrum_of (good, fs_lo)
print (f"  ❌ 简单抽取  : 18kHz 处幅度 {Xb[np.argmin(np.abs(f-18000))]/len(bad)*2:.4f}")
print (f"  ✅ 先低通抽取: 18kHz 处幅度 {Xg[np.argmin(np.abs(f-18000))]/len(good)*2:.4f}")
assert Xg[np.argmin(np.abs(f-18000))] < Xb[np.argmin(np.abs(f-18000))] * 0.01

# ② 升采样：验证无镜像
fs_lo2, fs_hi2 = 48000.0, 96000.0
t2 = np.arange (48000) / fs_lo2
x2 = np.cos (2*np.pi*5000*t2)

up = np.zeros (len(x2)*2); up[::2] = x2
up_bad  = up * 2                                     # ❌ 不滤波
up_good = np.convolve (up, design_lowpass_fir(20000.0, fs_hi2), 'same') * 2

f2, Xu = spectrum_of (up_bad,  fs_hi2)
_, Xv  = spectrum_of (up_good, fs_hi2)
band = (f2 > 30000)                                  # 镜像所在频段
print (f"  ❌ 零插值不滤波: 30k+ 能量 {Xu[band].max():.1f}")
print (f"  ✅ 零插值+低通 : 30k+ 能量 {Xv[band].max():.1f}")

print ("✅ 两个方向的抗混叠都验证通过")
```
