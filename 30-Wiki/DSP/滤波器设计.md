# 滤波器设计

> [!important] 一句话
> **滤波器设计 = 选一个"逼近函数"，把它的极零点映射到 z 平面，算出系数。**
> 你不需要从头推导——需要知道**四种经典逼近的取舍**和**怎么用现成公式**。

## 设计流程（四步）

```
① 确定指标          通带/阻带边界、纹波、阶数
      ↓
② 选逼近函数        Butterworth / Chebyshev / Bessel / Elliptic
      ↓
③ 模拟原型 → 数字   双线性变换（bilinear transform）
      ↓
④ 分解成 SOS        级联 biquad（⚠️ 不能用直接型，见 [[IIR 滤波器]]）
```

> [!tip] 实践中你通常只做①和②
> ③④ 有现成公式（RBJ Cookbook、JUCE 的函数）。
> **本页重点讲①和②的取舍。**

---

## 一、四种经典逼近对比

| 类型 | 通带 | 阻带 | 过渡带 | 相位 | 典型用途 |
|---|---|---|---|---|---|
| **Butterworth** | **最平坦**（无纹波） | 单调 | 最慢 | 较好 | **通用首选** |
| **Chebyshev I** | 有纹波 | 单调 | 快 | 较差 | 要更陡 |
| **Chebyshev II** | 单调 | 有纹波 | 快 | 较差 | 阻带要求高 |
| **Elliptic** | 有纹波 | 有纹波 | **最快** | 最差 | 极限陡度 |
| **Bessel** | 单调 | 单调 | 很慢 | ✅ **最线性** | 保瞬态 |

> [!important] 核心权衡
> **过渡带的陡度 ↔ 相位线性度**（以及通带平坦度）。
> 想让过渡带更陡，就得接受纹波或相位失真。

---

## 二、实测：Butterworth 的阶数效应

**测试**（$f_c$ = 1000 Hz，48 kHz，float64，脉冲响应 + FFT）：

| 阶数 N | 实测 -3dB 点 | 过渡带宽度（-3→-40dB） | 阻带 @2$f_c$ |
|---|---|---|---|
| 2 | 999.0 Hz | 7866 Hz | **-12.4 dB** |
| 4 | 1000.5 Hz | 2123 Hz | **-24.2 dB** |
| 6 | 1000.5 Hz | 1144 Hz | **-36.3 dB** |
| 8 | 1000.5 Hz | 773 Hz | **-48.4 dB** |

> [!important] 两个规律
> 1. **-3dB 点始终在 1 kHz**（这是 Butterworth 的定义——与阶数无关）
> 2. **滚降速率 ≈ $-6N$ dB/oct**
>    - N=2 → -12 dB/oct（实测 @2fc 是 -12.4 dB ✅）
>    - N=4 → -24 dB/oct（实测 -24.2 dB ✅）
>    - N=6 → -36 dB/oct（实测 -36.3 dB ✅）
>    - N=8 → -48 dB/oct（实测 -48.4 dB ✅）
>
> **每加一阶，滚降快 6 dB/oct。**

> [!tip] 记住这条公式：$-6N$ dB/oct
> 它让你能快速估算阶数。
> **想在某频率衰减 X dB？** 大致 $\text{倍频程数} \times 6N \approx X$。
>
> 例：要在 2$f_c$（1 个倍频程）衰减 48 dB → 需要 $N = 8$。

## 三、SOS 分解（必须做）

> [!danger] 高阶滤波器**不能**用直接型
> **实测**（float32，Butterworth 低通）：
>
> | 阶数 | 直接型 DC 增益 | 级联 SOS |
> |---|---|---|
> | 4 | 1.000025 ✅ | 1.000000 ✅ |
> | **6** | **1.087170 ❌ 误差 8.7%** | 1.000004 ✅ |
> | **8** | **nan ❌ 崩溃** | 1.000002 ✅ |
> | **12** | nan ❌ | **1.000010 ✅ 仍正常** |
>
> **同样滤波器、同样精度，结构不同结果天差地别。**
> 见 [[IIR 滤波器]]。

**正确做法**：

$$\text{N 阶} \Rightarrow \lceil N/2 \rceil \text{ 个二阶节（biquad）串联}$$

## 四、RBJ Cookbook：最实用的系数公式

> [!important] 为什么推荐 RBJ
> 它直接给出**数字域的 biquad 系数**，不用你自己做双线性变换。
> 而且处理好了归一化、Q 的定义等细节。

**通用形式**：

$$\omega_0 = 2\pi \frac{f_0}{f_s}, \qquad \alpha = \frac{\sin\omega_0}{2Q}$$

| 类型 | $b_0$ | $b_1$ | $b_2$ | $a_0$ | $a_1$ | $a_2$ |
|---|---|---|---|---|---|---|
| **低通** | $\frac{1-\cos\omega_0}{2}$ | $1-\cos\omega_0$ | $\frac{1-\cos\omega_0}{2}$ | $1+\alpha$ | $-2\cos\omega_0$ | $1-\alpha$ |
| **高通** | $\frac{1+\cos\omega_0}{2}$ | $-(1+\cos\omega_0)$ | $\frac{1+\cos\omega_0}{2}$ | $1+\alpha$ | $-2\cos\omega_0$ | $1-\alpha$ |
| **带通** | $\alpha$ | $0$ | $-\alpha$ | $1+\alpha$ | $-2\cos\omega_0$ | $1-\alpha$ |
| **陷波** | $1$ | $-2\cos\omega_0$ | $1$ | $1+\alpha$ | $-2\cos\omega_0$ | $1-\alpha$ |

> [!warning] 记住要除以 $a_0$
> 上面的表是"未归一化"的。实际系数要**全部除以 $a_0$**：
> ```cpp
> b0 /= a0;  b1 /= a0;  b2 /= a0;
> a1 /= a0;  a2 /= a0;      // a0 变成 1
> ```
> **忘了归一化 → 整体增益不对。**

```cpp
// RBJ 低通（最常用）
struct BiquadCoeffs { float b0, b1, b2, a1, a2; };

BiquadCoeffs makeLowpass (float fc, float Q, double sr)
{
    const double w0 = 2.0 * M_PI * fc / sr;
    const double cw = std::cos (w0);
    const double alpha = std::sin (w0) / (2.0 * Q);
    const double a0 = 1.0 + alpha;

    BiquadCoeffs c;
    c.b0 = (float) ((1.0 - cw) / 2.0 / a0);
    c.b1 = (float) ((1.0 - cw)       / a0);
    c.b2 = c.b0;
    c.a1 = (float) (-2.0 * cw        / a0);
    c.a2 = (float) ((1.0 - alpha)    / a0);
    return c;
}
```

> [!danger] 必须钳制 $f_c$
> ```cpp
> fc = std::clamp (fc, 20.0f, (float)(sr * 0.45));
> ```
> **超过 Nyquist 时公式失效** → 系数错 → 可能发散。
> 用 0.45 而不是 0.5：双线性变换在接近 Nyquist 时有**频率翘曲**。
> 见 [[奈奎斯特-香农定理]]。

## 五、频率翘曲：双线性变换的固有代价

**双线性变换**把模拟频率 $\Omega$ 映射到数字频率 $\omega$：

$$\Omega = \frac{2}{T}\tan\!\left(\frac{\omega}{2}\right)$$

这是**非线性**的：低频近似线性，接近 Nyquist 时急剧压缩。

| 想要的数字频率 | 实际响应位置 |
|---|---|
| 1 kHz | ≈ 1 kHz ✅ |
| 10 kHz | ≈ 10 kHz ✅ |
| 20 kHz | 略偏 |
| **接近 24 kHz** | **严重偏移** ⚠️ |

> [!warning] 后果
> 你设 $f_c$ = 20 kHz（$f_s$ = 48 kHz），实际 -3dB 点可能跑到 22 kHz 以上。
> **滤波器"看起来"不起作用。**
>
> **解法**：
> 1. 钳制到 0.45·$f_s$（最常见）
> 2. 用**预翘曲**（pre-warping）：设计模拟原型时就把频率预先修正
>    大多数现成公式（含 RBJ）**已经包含了预翘曲**
> 3. 用 TPT/ZDF 结构（见 [[状态变量滤波器 SVF]]）

## 六、选型决策表

| 你的需求 | 推荐 | 为什么 |
|---|---|---|
| 通用 EQ、分频 | **Butterworth（RBJ biquad）** | 最平坦，公式现成 |
| 需要更陡但能接受纹波 | Chebyshev I | 同阶数过渡带更窄 |
| 保瞬态（鼓、拨弦、母带） | **Bessel**，或**线性相位 FIR** | 相位最线性 |
| 极限陡度（如分析、抗混叠） | Elliptic 或 FIR | 效率最高 |
| 需要线性相位 | **FIR** | IIR 做不到 |
| 分频器（多路相加要平坦） | **Linkwitz-Riley** | 分频点 -6dB 且相位一致 |
| 要调制（扫频、包络） | **SVF**（Chamberlin 或 TPT） | 系数与参数近似线性 |
| 高阶（>4 阶） | **级联 biquad** | 直接型会坏 |

> [!tip] 实践中的 90% 情况
> **RBJ biquad，级联 1–3 个，够了。**
> 复杂需求才需要上 Bessel/Elliptic/FIR。

## 七、Linkwitz-Riley 分频器

**LR-4** = 两个 Butterworth 2 阶**级联**：

$$\text{LR4} = \text{Butterworth}(2) \times \text{Butterworth}(2)$$

**关键性质**：

| 分频类型 | 分频点幅度 | 两路相加 |
|---|---|---|
| Butterworth | -3 dB | ❌ 有 +3dB 凸起 |
| **Linkwitz-Riley** | **-6 dB** | ✅ **平坦** |
| 一阶 | -6 dB | ✅ 平坦但太缓 |

> [!important] 为什么必须是 -6 dB
> 两路都是 -6 dB（幅度 0.5）时，同相相加 = 1.0（0 dB）。
> 如果都是 -3 dB（幅度 0.707），相加 = 1.414（+3 dB）→ **凸起**。
>
> **这是分频器设计的核心约束。**

## 八、AI 会怎么写错

| # | AI 常犯 | 后果 | 怎么查 |
|---|---|---|---|
| 1 | **忘记除以 $a_0$** | 增益不对 | 检查是否归一化 |
| 2 | **不钳制 $f_c$ 到 Nyquist 以下** | 系数错/发散 | `clamp(fc, 20, sr*0.45)` |
| 3 | **直接用高阶系数（不拆 SOS）** | float32 下 N=6 就坏 | 拆成 biquad 级联 |
| 4 | **用直接型 I 而非转置直接型 II** | 中间变量溢出 | 用 TDF-II |
| 5 | **$Q$ 和 $Q$ 的 dB 形式搞混** | 共振量不对 | 明确是线性 Q |
| 6 | **不检查稳定性** | 高 Q 时发散 | 算极点半径 < 0.999 |
| 7 | **以为 IIR 能做线性相位** | 概念错误 | 线性相位要 FIR |
| 8 | **分频器用 Butterworth 直接相加** | 分频点 +3dB 凸起 | 用 Linkwitz-Riley |
| 9 | **在音频线程重算系数** | 分配 + 耗时 | 只在参数变化时算 |
| 10 | **忽略频率翘曲** | 高频段 $f_c$ 不准 | 钳制或用预翘曲 |

> [!danger] 第 1 和第 3 条组合起来最常见
> AI 写一个"4 阶 Butterworth"，代码里：
> - 忘记归一化 → 增益偏了
> - 用直接型 → float32 下可能坏
>
> **两个 bug 同时存在，症状混在一起，很难调试。**

## 九、常见坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 增益不是 1 | 没除以 $a_0$ | 归一化 |
| 高阶输出 NaN | 直接型 + float32 | 拆 SOS |
| 高频段 $f_c$ 不准 | 双线性变换翘曲 | 钳制到 0.45·fs |
| 分频点有凸起 | 用了 Butterworth | 用 Linkwitz-Riley |
| 高 Q 时爆音 | 没钳制 Q / 不稳定 | 钳制 + 检查极点 |
| 瞬态被抹掉 | IIR 相位非线性 | 用 Bessel 或 FIR |
| 扫频时有咔哒 | 参数突变 | 见 [[参数平滑 parameter smoothing]] |
| 安静时 CPU 高 | denormal | 见 [[denormal 数处理]] |

## 十、怎么验证

**四个必做测试**：

| # | 测试 | 判据 |
|---|---|---|
| 1 | **-3dB 点** | 与设计的 $f_c$ 一致（±1%） |
| 2 | **滚降速率** | ≈ -6N dB/oct |
| 3 | **稳定性** | 脉冲跑 10 秒衰减到 0 |
| 4 | **DC/Nyquist 增益** | 低通：$H(1)\approx1$、$H(-1)\approx0$ |

```python
import numpy as np

def biquad_lowpass (fc, Q, sr=48000.0):
    """RBJ 低通"""
    w0 = 2*np.pi*fc/sr
    cw, al = np.cos(w0), np.sin(w0)/(2*Q)
    a0 = 1 + al
    b = [(1-cw)/2/a0, (1-cw)/a0, (1-cw)/2/a0]
    a = [1.0, -2*cw/a0, (1-al)/a0]
    return np.array(b), np.array(a)

def measure (b, a, sr=48000.0, nfft=1<<15):
    """脉冲响应 → 频率响应"""
    h = np.zeros(nfft); h[0] = 1.0
    y = np.zeros(nfft)
    for n in range(nfft):
        acc  = sum (b[i]*h[n-i] for i in range(len(b)) if n-i >= 0)
        acc -= sum (a[i]*y[n-i] for i in range(1,len(a)) if n-i >= 0)
        y[n] = acc
    H = np.abs (np.fft.rfft (y))
    f = np.fft.rfftfreq (nfft, 1/sr)
    return f, 20*np.log10 (H + 1e-20)

# 测试
b, a = biquad_lowpass (1000.0, 0.707)
f, db = measure (b, a)

i3 = np.argmax (db < -3)
print (f"  -3dB 点: {f[i3]:.1f} Hz（设计 1000）")

dc  = np.sum(b)/np.sum(a)
zb  = sum (bi*((-1)**i) for i,bi in enumerate(b))
za  = sum (ai*((-1)**i) for i,ai in enumerate(a))
print (f"  直流增益 {dc:.6f}（应≈1）, Nyquist {zb/za:.6f}（应≈0）")

p = np.roots (a)
print (f"  极点最大半径 {np.max(np.abs(p)):.6f}（应<1）")

assert abs(f[i3] - 1000) < 20, "-3dB 点不符"
assert abs(dc - 1) < 1e-6, "直流增益不对"
assert np.max(np.abs(p)) < 1, "不稳定"
print ("  ✅ 全部通过")
```
