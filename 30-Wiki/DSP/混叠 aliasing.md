# 混叠 aliasing

> [!note] 一句话
> 采样率不够时，高于奈奎斯特频率（Nyquist frequency，$f_s/2$）的成分**不会消失，
> 而是"折叠"回来变成低频的假信号**。
> 这个假信号**不可逆**——一旦折回来，它和真实信号在数学上完全无法区分。

> [!important] 为什么这一页对你特别重要
> 你听过"数字味"、"塑料味"、"金属感"、"刺耳"——**混叠是这些听感最主要的技术来源之一**。
> 而且它有个残酷的性质：**你越是想让声音"更狠"（加失真、加饱和），它就越严重。**
>
> 这一页把两件事接起来：**你的耳朵听到的 → 频谱上发生了什么 → AI 会怎么给你写错。**

---

## 一、定义与数学

### 采样定理（前提条件常被忽略）

奈奎斯特-香农定理说：采样率 $f_s$ 能**无失真**表示的最高频率是

$$f_{\text{Nyquist}} = \frac{f_s}{2}$$

**但定理有一个前提**：信号必须是**带限**（band-limited）的——即高于 $f_s/2$ 的成分必须为零。

> [!warning] 关键在这
> 现实中的信号（尤其是**非线性处理之后**的信号）**不是带限的**。
> 定理的前提不成立时，定理的结论也就不成立——**多出来的成分不会凭空消失**。

### 折叠公式

一个频率为 $f$ 的成分，被 $f_s$ 采样后，会出现在：

$$f_{\text{alias}} = \left| f - k \cdot f_s \right| \quad \text{其中 } k \text{ 取使结果落入 } [0, f_s/2] \text{ 的最近整数}$$

更简洁的等价写法（先取模再折叠）：

$$f_{\text{alias}} = \left| \left( (f + f_s/2) \bmod f_s \right) - f_s/2 \right|$$

<!-- derived: 由采样定理的频谱周期延拓直接得出；下方数字表为脚本实测 -->

### 具体数字（$f_s = 48\,\text{kHz}$，$f_{\text{Nyquist}} = 24\,\text{kHz}$）

| 原始频率 | 折叠后落点 | 说明 |
|---|---|---|
| 25 kHz | **23 kHz** | 只超出 1 kHz，就折到 23 kHz——**紧贴可听上限** |
| 27 kHz | 21 kHz | |
| 30 kHz | 18 kHz | |
| 36 kHz | 12 kHz | |
| 47 kHz | 1 kHz | 折到低频，最"脏"的情况 |
| 49 kHz | 1 kHz | 47k 和 49k **折到同一个地方**——不可逆 |
| 72 kHz | 24 kHz | 恰好落在奈奎斯特 |
| 96 kHz | 0 Hz | 折成直流 |

> [!tip] 必须记住的两个例子
> **48 kHz 下，25 kHz 的正弦会变成 23 kHz**——只超出一点点，却折回来一大截。
> **47 kHz 和 49 kHz 折到同一个 1 kHz**——这就是它不可逆的原因。

## 二、为什么"折叠"（而不是被滤掉）

**时域看**：采样 = 把连续信号乘以一串冲激（impulse train）。
**频域看**：时域相乘 = 频域**卷积**，而冲激串的频谱还是冲激串。
所以采样后的频谱 = **原始频谱以 $f_s$ 为周期无限复制**。

```
原始（带限）:      /\          采样后（周期延拓）:  /\      /\      /\
              ___/  \___                          __/  \____/  \____/  \__
              0    f_max                         -fs     0      fs
                                                ↑ 副本重叠 → 这就是混叠
```

只要 $f_{\max} > f_s/2$，相邻的复制体就会**重叠**。重叠部分的能量不会消失，
它在数学上等价于一个**较低频率**的成分——这就是"折叠"。

> [!note] 一句话理解
> **混叠不是"信号被破坏"，是"频谱副本重叠"。**
> 重叠之后你无法区分哪个是原件、哪个是副本——所以它不可逆。

## 三、为什么非线性处理**必然**产生混叠

这是本页最重要的一条因果链：

```
非线性（削波/饱和/waveshaping）
   → 波形被"压扁"，产生尖锐的拐点
   → 尖锐拐点 = 无限宽的频谱
   → 产生无限多个谐波 (f, 3f, 5f, 7f, ...)
   → 高次谐波必然超过 f_s/2
   → 折叠回可听频段 = 混叠
```

**即使输入是纯正弦也一样。** 硬削波一个 1 kHz 正弦，输出是方波，而方波的傅里叶级数包含**所有奇次谐波**，理论上无限多。

## 四、音乐人的听感 ↔ 工程原因 ⭐

**这一节是这一页存在的理由。**

| 你的听感 | 工程原因 | 怎么确认 |
|---|---|---|
| "数字味" / "塑料味" | 混叠产生的**非谐波**成分，与乐音没有谐波关系 | 频谱里出现非整数倍频率 |
| "刺耳" / "沙沙的" | 混叠能量堆在 10–20 kHz，正是人耳最敏感的区域 | 高频失真后测 12–23 kHz |
| "金属感" | 混叠成分之间**互调**，产生不谐和的密集频率簇 | 多个非谐波峰 |
| "亮但不干净" | **真谐波**（亮）与**混叠**（脏）同时存在，混在一起 | 对比过采样前后的频谱差 |
| "越加失真越糊" | 失真越狠 → 拐点越尖 → 高次谐波越多 → 混叠越强 | 扫 drive 参数看混叠能量 |
| "高音区特别糟" | 基频越高，**越多次谐波超过奈奎斯特**（见下） | 同一音色在不同音区对比 |
| "这个音色脏"（FM/粒子） | 调制/重采样产生的边带越界折返 | 见 [[合成原理与 DSP 拓扑]] |

### 为什么混叠听起来特别"不自然"

> [!important] 核心区别：**谐波 vs 非谐波**
> - **谐波失真**（过载的温暖感）：产生 $2f, 3f, 4f \dots$——**都是基频的整数倍**。
>   耳朵会把它们**融合进同一个音**里，听成"音色变厚/变亮"。
> - **混叠**：产生的是 $f_s - nf$ 这类频率——**通常不是基频的整数倍**。
>   耳朵无法把它们归属到任何音上，于是听成**"脏"、"沙"、"外来的东西"**。

**这就是"塑料味"和"温暖过载"的根本区别**：不是失真量的问题，是**失真产物的频率关系**的问题。

### 为什么高音区更明显

设基频 $f_0$，第 $n$ 次谐波是 $n f_0$。它超过奈奎斯特的条件是：

$$n > \frac{f_s}{2 f_0}$$

| 基频 $f_0$ | 超过奈奎斯特的最低谐波次数 | 越界谐波数量 |
|---|---|---|
| 100 Hz | 第 240 次 | 极少（前 239 次都合法） |
| 1 kHz | 第 24 次 | 中等 |
| 5 kHz | 第 5 次 | **很多** |
| 10 kHz | 第 3 次 | **极多** |

<!-- derived: 由 n > fs/(2·f0) 直接计算，fs=48kHz -->

**结论：同一个失真插件，在低音区可能听起来很好，在高音区就"塑料"。**
这不是你的错觉，是数学。

### ⚠️ 两个反直觉的实测发现

> [!warning] 发现 1：混叠的频率会**跟着音高反向移动**
> 追踪第 7 次谐波（$7 f_0$）在 $f_s$ = 48 kHz 下的落点：
>
> | $f_0$ | $7f_0$ | 混叠落点 | 方向 |
> |---|---|---|---|
> | 3500 Hz | 24500 Hz | 23500 Hz | — |
> | 4000 Hz | 28000 Hz | 20000 Hz | ↓ |
> | 5000 Hz | 35000 Hz | 13000 Hz | ↓ |
> | 7000 Hz | 49000 Hz | 1000 Hz | ↓ |
>
> **音高上升，混叠成分反而下降。** 这会产生一种"音高往上走、
> 但有个奇怪的哨音往下滑"的效果——这是混叠最容易辨认的特征之一。
>
> 这也是为什么**弹奏一条旋律**比弹单个音更容易听出混叠。

> [!warning] 发现 2：某些频率下，混叠会"藏"在谐波里（测量的坑）
> 如果 $\dfrac{f_s}{f_0}$ 是**整数**，那么所有折叠回来的频率**恰好落在谐波位置上**，
> 频谱上看不到任何非谐波成分。实测（硬削波，drive = 3）：
>
> | $f_s$ | $f_0$ | $f_s / f_0$ | 整数？ | 测到的非谐波能量 |
> |---|---|---|---|---|
> | 48000 | 1000 | 48.0 | 是 | **-200 dB（测不到）** |
> | 48000 | 5000 | 9.6 | 否 | -17.0 dB |
> | 48000 | 10000 | 4.8 | 否 | -9.0 dB |
> | 44100 | 1000 | 44.1 | 否 | **-41.6 dB** |
>
> **同一条 1 kHz 测试音，在 48 kHz 下测不出混叠，在 44.1 kHz 下就能测出来。**
>
> **教训**：不要用"整数关系"的测试频率验证抗混叠。
> 用 5 kHz、7 kHz、10 kHz 这类**故意不和采样率成整数比**的频率。
> 这与 [[2026-10-14 测量工具会骗你 —— 十次踩坑记录]] 是同一类陷阱：
> **不是代码对了，是测量方法选择了看不见。**

## 五、哪些处理会产生混叠

### ✅ 会产生（必须处理）

| 处理 | 为什么 | 严重程度 |
|---|---|---|
| **硬削波 / 失真 / 饱和** | 拐点最尖 → 谐波最丰富 | 🔴 极严重 |
| **waveshaping**（任意非线性函数） | 同上，函数越"弯"越严重 | 🔴 极严重 |
| **压缩器** | 增益平滑本身是线性的；但**增益计算/软膝/比率**里的非线性会产生 | 🟠 中等 |
| **理想锯齿波 / 方波振荡器** | 理想波形带宽**无限** | 🔴 极严重 |
| **FM / 相位调制** | 边带无限宽（Carson 带宽） | 🔴 极严重 |
| **降采样不滤波** | 直接把高频折回来 | 🔴 极严重 |
| **变采样率播放**（粒子、变调） | 本质是重采样 | 🟠 中等 |
| **快速调制的滤波器** | 时变系数 → 产生边带，调制够快时折返 | 🟡 轻微（见下） |
| **快速调制的延迟线** | 多普勒 + 边带 | 🟡 轻微 |
| **任何"每 block 更新一次参数"的处理** | 参数跳变 = 阶跃 = 宽带 | 🟡 轻微但常见 |

### ❌ 不会产生（常见误解，必须澄清）

> [!important] 线性时不变（LTI）操作**不产生混叠**
> **增益、EQ、延迟、混响（线性部分）、声像、滤波** —— 这些**不会**产生新的频率成分。
> 它们只改变已有成分的**幅度和相位**。
>
> **一个设计正确的 biquad 低通，即使截止频率很低，也不会产生混叠。**
> 因为它不创造新频率——它只是衰减已有的。
>
> 为什么这个澄清重要：**如果你以为 EQ 会混叠，你就会给整个插件加过采样，白白浪费 CPU。**
> 见 [[过采样 oversampling]] 第 8 节。

> [!warning] 唯一的例外：线性**时变**（LTV）
> 滤波器的**系数被快速调制**时，系统不再是时不变的，会产生**边带**（sideband）。
> 实测：8 kHz 正弦 + 截止被 3 kHz LFO 快速调制，1x 处理比 8x 参考在 5217 Hz 处高出 **10.8 dB**。
>
> **但**：正常音乐里的 LFO 是 0.1–10 Hz，边带紧贴基频，不会越界。
> **只有调制快到可与音频频率相比时（几十 Hz 以上）才需要担心。**
> 另一个更常见的相关问题是**参数更新率太低**（每 block 才更新一次系数）——实测：
>
> | 系数更新率 | 杂散 |
> |---|---|
> | 每 1 样本 | 干净（无杂散） |
> | 每 16 样本 | -80.2 dB |
> | 每 64 样本 | -64.8 dB |
> | 每 256 样本 | -54.8 dB |
>
> 这**不是混叠**，是参数跳变产生的宽带杂散。解法是 [[参数平滑 parameter smoothing]]，不是过采样。

## 六、三种解决方案（简述）

> [!note] 详细内容见 [[过采样 oversampling]]

| 方案 | 思路 | 适用 | 代价 |
|---|---|---|---|
| **过采样（oversampling）** | 在更高采样率下做非线性，滤掉带外成分再降回来 | **最通用**，任何非线性都能用 | CPU、延迟 |
| **抗混叠振荡器** | BLIT / BLEP / DPW / PolyBLEP：在波形**不连续点**加带限修正 | 振荡器 | 实现复杂，见 [[抗混叠振荡器]] |
| **带限波形整形** | 预先把非线性函数做成带限的（BLAMP 等） | waveshaping | 数学门槛高，不易调参 |

> [!important] 关键区别：**过采样是"事后补救"，后两者是"生成时就正确"**
> 过采样是**通用**的——你不需要理解非线性函数的数学，套上去就行。
> 这也是为什么它是**默认选择**。
>
> 但它有极限：如果非线性产生的谐波**太**丰富（比如 10 kHz 输入 + 极端失真），
> 4x 过采样也救不回来。此时要么提高倍率，要么降低失真量。

## 七、怎么测量 / 听到混叠

### 听感测试（最快的判据）

1. 用 **5–10 kHz 的高频正弦**（不是 100 Hz！）作为测试信号
2. 加大失真/饱和量
3. **注意听有没有出现"沙沙"的、和不谐和的成分**
4. 关键动作：**扫 drive 参数**——混叠会随 drive 增加而突然"冒出来"

> [!tip] 更灵敏的听法
> 用一个**缓慢滑音**（sine sweep）而不是固定音高。
> 因为混叠频率会**反向移动**（见第四节发现 1），滑音时那种"逆着走的哨音"非常容易辨认。

### 频谱测试（数值优先）

**输入 5 kHz，硬削波后应该看到：**
- 5 kHz（基频）、15 kHz（3 次谐波）——**合法谐波**
- 25 kHz（5 次谐波）——**超过奈奎斯特，会折叠到 23 kHz**
- 35 kHz（7 次谐波）——折到 13 kHz

**实测对照**（5 kHz 正弦，drive = 3，$f_s$ = 48 kHz）：

| 频率 | 不过采样 | 4x 过采样 | 判定 |
|---|---|---|---|
| 5 kHz（基频） | +1.9 dB | +1.9 dB | ✅ 合法，应保持不变 |
| 15 kHz（3 次谐波） | -9.3 dB | -9.4 dB | ✅ 合法，应保持不变 |
| **23 kHz** | **-17.6 dB** | **-47.7 dB** | ❌ **混叠，4x 后改善 30.1 dB** |
| **13 kHz** | **-29.2 dB** | -69.4 dB | ❌ **混叠，改善 40.3 dB** |
| 7 kHz | -32.0 dB | -53.3 dB | ❌ 混叠，改善 21.3 dB |

<!-- derived: 实测，脚本见下 -->

> [!important] 判据
> **基频和它的真谐波，过采样前后应该几乎不变**（这是信号，不能动）。
> **非谐波成分，过采样后应该大幅下降**（这是混叠，要干掉）。
>
> 如果过采样后**连真谐波也变了**，说明你的抗混叠滤波器把有用信号也滤掉了——
> 滤波器设计有问题，见 [[过采样 oversampling]] 第 4 节。

### 可运行的 Python 代码

```python
#!/usr/bin/env python3
"""听到混叠：不过采样的硬削波 vs 4x 过采样。
放在 50-Playground/exp-aliasing/ 下运行，需要 audio_io.py 在同目录或 PYTHONPATH 上。
"""
import numpy as np
from audio_io import sine, write_wav, spectrum, peak_db

SR, F0, DRIVE = 48000, 5000.0, 3.0      # 5 kHz：谐波最容易越界


def fir_lowpass(cutoff_hz, sr, taps):
    """窗函数法线性相位 FIR 低通。"""
    n = np.arange(taps) - (taps - 1) / 2.0
    W = cutoff_hz / sr                   # 归一化截止（cycles/sample）
    h = 2.0 * W * np.sinc(2.0 * W * n)   # 理想低通
    h *= np.hamming(taps)                # 加窗抑制旁瓣
    return h / h.sum()                   # 直流增益归一化


def fir_apply(x, h):
    """卷积并补偿群延迟，保持长度不变。"""
    y = np.convolve(x, h, mode='full')
    d = (len(h) - 1) // 2
    return y[d:d + len(x)]


def up2(x, taps=127):
    """2x 升采样：插零 + 抗镜像低通。"""
    u = np.zeros(len(x) * 2)
    u[::2] = x * 2.0                     # 乘 2 补偿插零的能量损失
    return fir_apply(u, fir_lowpass(SR / 2, SR * 2, taps))


def down2(x, taps=127):
    """2x 降采样：抗混叠低通 + 抽取。"""
    return fir_apply(x, fir_lowpass(SR / 2, SR * 2, taps))[::2]


def clip(x, drive):
    return np.clip(x * drive, -1.0, 1.0)


def oversampled_clip(x, drive, factor=4):
    """在 factor 倍采样率下削波，再降回来。"""
    y = x.copy()
    for _ in range(int(np.log2(factor))):
        y = up2(y)
    y = clip(y, drive)
    for _ in range(int(np.log2(factor))):
        y = down2(y)
    return y


if __name__ == '__main__':
    x = sine(F0, 0.5, SR, amp=0.9)
    naive = clip(x, DRIVE)
    over4 = oversampled_clip(x, DRIVE, factor=4)

    for label, y in (("不过采样", naive), ("4x 过采样", over4)):
        f, mag = spectrum(y, SR)
        print(f"\n── {label} ──")
        for hz in (5000, 15000, 23000, 13000, 7000):
            i = np.argmin(np.abs(f - hz))
            ratio = hz / F0
            tag = "谐波" if abs(ratio - round(ratio)) < 0.02 else "混叠"
            print(f"   {hz:>6} Hz ({tag:2s})  {mag[i]:7.1f} dB")

    write_wav('alias_naive.wav', naive, SR)
    write_wav('alias_4x.wav', over4, SR)
    print(f"\n峰值: naive {peak_db(naive):.2f} | 4x {peak_db(over4):.2f} dBFS")
    print("→ 用耳朵 A/B 这两个文件")
```

**实测输出**（本机验证过）：

```
── 不过采样 ──
     5000 Hz (谐波)      1.9 dB
    15000 Hz (谐波)     -9.3 dB
    23000 Hz (混叠)    -17.6 dB
    13000 Hz (混叠)    -29.2 dB
     7000 Hz (混叠)    -32.0 dB

── 4x 过采样 ──
     5000 Hz (谐波)      1.9 dB     ← 信号不变 ✅
    15000 Hz (谐波)     -9.4 dB     ← 信号不变 ✅
    23000 Hz (混叠)    -47.7 dB     ← 改善 30.1 dB ✅
    13000 Hz (混叠)    -69.4 dB     ← 改善 40.3 dB ✅
     7000 Hz (混叠)    -53.3 dB     ← 改善 21.3 dB ✅
```

> [!warning] 这段代码的简化之处（别直接抄进插件）
> 1. `fir_apply` 用 `np.convolve` **补偿了群延迟**——实时插件里**不能**这样，
>    延迟必须如实报告给宿主，见 [[过采样 oversampling]] 第 5 节
> 2. `taps=127` 是随手选的，没有做通带/阻带优化
> 3. 只处理单声道，没有多通道状态管理
>
> 它是**验证概念**用的，不是产品代码。

## 八、AI 会怎么写错

> [!danger] 这是本页最实用的部分
> 下面每一条都是 AI 生成 DSP 代码时的**高频错误**，而且**它通常不会主动告诉你**。

### 错误 1：写了失真，完全不提过采样

```cpp
// ❌ AI 的典型输出：能跑，能出声，但是错的
float processSample (float x)
{
    return std::tanh (x * drive);      // 没有过采样 → 混叠
}
```

**AI 不会说**："这个会产生混叠，你需要过采样。"
它只会说"这是一个软削波饱和器"。

**你要问的问题**：*"这个非线性处理有没有过采样？混叠会落在哪里？"*

### 错误 2：把 `tanh` 写成硬削波（混叠更严重）

```cpp
// ❌ 硬削波：拐点是一阶不连续 → 谐波衰减极慢
return std::clamp (x * drive, -1.0f, 1.0f);

// ✅ tanh：处处光滑 → 高次谐波衰减快得多
return std::tanh (x * drive);
```

**实测对比**（5 kHz，drive = 3）：

| 成分 | 硬削波 | `tanh` | 差异 |
|---|---|---|---|
| 23 kHz（混叠） | -17.6 dB | -21.8 dB | **tanh 好 4.1 dB** |
| 13 kHz（混叠） | -29.2 dB | -31.5 dB | tanh 好 2.3 dB |
| 7 kHz（混叠） | -32.0 dB | -50.7 dB | **tanh 好 18.7 dB** |

**两者都不够**（都需要过采样），但 `tanh` 的混叠明显更少。
**AI 常把两者当成"差不多的饱和"**——它们不是。

### 错误 3：朴素振荡器（相位累加 + 查表）

```cpp
// ❌ AI 最常写的振荡器：严重混叠
float saw (float phase) { return 2.0f * phase - 1.0f; }
// phase += freq / sampleRate;  if (phase >= 1) phase -= 1;
```

**实测**：朴素锯齿的混叠能量（非谐波成分总能量）：

| 基频 | 混叠能量 | 说明 |
|---|---|---|
| 110 Hz | -56.6 dB | 低音区勉强可接受 |
| 440 Hz | -28.2 dB | 开始明显 |
| 1 kHz | -27.6 dB | 明显 |
| 2 kHz | -21.6 dB | 严重 |
| 4 kHz | -15.6 dB | 很严重 |
| 8 kHz | -9.5 dB | 灾难 |

**注意规律：每升高一个八度，混叠恶化约 6 dB。**
这就是"合成器高音区有沙沙声"的定量来源。

**你要问的问题**：*"这个振荡器是抗混叠的吗？用的是 BLEP、DPW 还是过采样？"*
见 [[抗混叠振荡器]]。

### 错误 4：升采样了，但降采样不滤波

```cpp
// ❌ 只升不滤：混叠一点没少，还多花了 CPU
auto up = oversampleUp (x);       // 升到 4x
auto y  = processNonlinear (up);  // 非线性
return y[::4];                    // 直接抽取 —— 高频原封不动折回来！
```

**抽取（decimation）之前必须低通。** 只做升采样等于什么都没做。
见 [[过采样 oversampling]] 第 2 节。

### 错误 5：给你一个"不需要过采样"的结论

AI 可能说："EQ 也会产生混叠，所以整个插件都要过采样。"
**这是错的**（见第五节）。**线性处理不需要过采样。**

> [!tip] 一条通用规则
> **每当 AI 给你一段非线性处理（失真、饱和、削波、waveshaper、压缩器增益计算），
> 你都要主动问一句："这里混叠吗？要不要过采样？"**
>
> 它**不会**主动说。这不是它藏私，是这类"缺失的约束"通常不在它的默认输出里。

## 九、常见坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 高频失真有"沙沙"声 | 非线性产生的谐波越界折返 | 过采样，见 [[过采样 oversampling]] |
| 高音区音色明显变脏 | 基频高 → 越界谐波多 | 抗混叠振荡器 / 过采样 |
| 加了过采样但没改善 | 只升采样没降采样滤波 | 抽取前必须低通 |
| 加了过采样后声音变闷 | 抗混叠滤波器通带太窄，削掉了有用高频 | 放宽通带 / 增加 taps |
| 测不出混叠，以为代码没问题 | 测试频率与采样率成整数比（**见第四节发现 2**） | 换 5k / 7k / 10k 测试 |
| 过采样后输出有"咔哒"声 | 滤波器状态未 reset，或 block 边界不连续 | 处理前后 `reset()`，见 [[实时音频线程契约]] |
| 过采样后与干信号相位不对 | 没补偿过采样延迟 | 报告 latency，见 [[过采样 oversampling]] |
| 调参数时有"阶梯感/杂散" | 参数更新率太低（不是混叠！） | [[参数平滑 parameter smoothing]] |
| 降采样后低频有"隆隆"声 | 抽取前滤波器阻带衰减不够 | 提高 taps / 换等波纹设计 |
| 混响/延迟里出现金属味 | **不是混叠**，是梳状滤波驻波 | 见 [[混响的原理]] |

> [!warning] 最后一行很重要
> "金属味"至少有三个完全不同的技术来源：
> **① 混叠**（本页）、**② 梳状滤波驻波**（[[混响的原理]]）、**③ 快速调制**。
> **不要一听到金属味就去加过采样。** 先判断是哪一个——
> 混叠的特征是"**非谐波成分**"，驻波的特征是"**等间隔的峰谷**"。

## 十、怎么验证

### 数值验证（优先，不靠耳朵）

| # | 测试 | 方法 | 期望结果 |
|---|---|---|---|
| 1 | **折叠公式自检** | 生成 25 kHz 正弦 @48k，测主频 | 应该是 **23 kHz** |
| 2 | **非线性产生混叠** | 5 kHz 正弦 + 硬削波，测 23 kHz 处能量 | 明显高于噪声底（约 -18 dB） |
| 3 | **过采样改善** | 同一信号过 4x，再测 23 kHz | 应下降 **20 dB 以上** |
| 4 | **信号不受损** | 测基频和 3 次谐波 | 过采样前后应**几乎不变**（<1 dB） |
| 5 | **线性不混叠** | 用同一个 5 kHz 正弦过 biquad 低通 | 非谐波成分应在噪声底（< -150 dB） |
| 6 | **振荡器抗混叠** | 8 kHz 锯齿做 FFT，找非谐波峰 | 朴素实现应有明显非谐波成分 |

> [!tip] 测试 1 是最重要的自检
> **如果你测 25 kHz 正弦却得不到 23 kHz，那你的测量方法有问题**（不是代码有问题）。
> 这与 [[2026-10-14 测量工具会骗你 —— 十次踩坑记录]] 的防御手段一致：
> **先用已知正确的简单例子校准测量方法。**

> [!warning] 写这一页时踩到的坑：频谱幅度差了正好 6 dB
> 本页第一版的**所有** dB 数字都比真实值低 6.02 dB——
> 因为 `audio_io.spectrum()` 加窗后除以了 $N$，而不是除以**窗函数之和**。
>
> **它的危险之处**：所有**相对**关系（谐波比基频低多少）完全正确，
> 只有绝对幅度错了；而且 6.02 dB 恰好是"幅度减半"，看起来非常合理。
>
> 完整记录见 [[2026-10-14 测量工具会骗你 —— 十次踩坑记录]] 陷阱 7。
> **本页所有 dB 数字均已用修正后的 `spectrum()` 重新实测。**

### 判据速查

```
有混叠  → 频谱出现非谐波峰，且过采样后大幅下降
无混叠  → 只有谐波峰，过采样前后几乎不变
测不到  → 先怀疑测试频率选得不好（整数比），再怀疑代码
```
