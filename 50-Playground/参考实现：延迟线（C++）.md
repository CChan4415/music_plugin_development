# 参考实现：延迟线（C++）

编译运行：

```bash
clang++ -std=c++17 -Wall -Wextra ref-delay-line.cpp -o dl && ./dl
```

## 已验证（2026-10-14）

| 检查 | 结果 |
|---|---|
| 整数延迟 d=20（脉冲位置） | 1.0000 ✅ |
| d=0（最近写入） | 0.0000 ✅ |
| 分数延迟 d=20.5 | 0.5000 ✅（线性插值正确） |
| 分数延迟 d=20.25 | 0.7500 ✅ |
| C++ 负数取模 `-1 % 100` | **-1**（Python 是 99）→ `while` 循环绕过 |

## 同时验证了线性插值的频率响应

用解析公式 $|H| = \sqrt{(1-\phi)^2 + \phi^2 + 2\phi(1-\phi)\cos(2\pi f/f_s)}$：

| frac | 1 kHz | 5 kHz | 10 kHz | 20 kHz |
|---|---|---|---|---|
| 0.0 | 0.00 | 0.00 | 0.00 | 0.00 |
| 0.25 | -0.01 | -0.35 | -1.41 | -5.23 |
| **0.5** | -0.02 | -0.47 | -2.01 | **-11.74** |
| 0.75 | -0.01 | -0.35 | -1.41 | -5.23 |

→ **这就是"分数延迟听起来发闷"的原因**，见 [[延迟线 delay line]]。

> [!note] 测试方法的一个教训
> 我第一次测试时写错了脉冲距离（以为脉冲在 20 个采样前，实际在 99 个），
> 得到"全部是 0"的结果，差点以为实现有问题。
> **又一次"测量方法错而非代码错"。**
