# exp-003: 从延迟到混响

> [!important] 这是 [[混响的原理]] 的可运行版本
> 你点名要看"混响的原理"——这一页让你**亲手搭出来**，而不只是读原理。

## 运行

```bash
python3 reverb.py --no-play
```

## 四个构件，逐步搭起来

```
1. 反馈延迟        → 一个回声。理解 RT60 ↔ 反馈增益
2. 梳状滤波器(+阻尼) → 多个回声。阻尼让尾巴变暗、变自然
3. 全通滤波器      → 打散相位，增加密度
4. 8 梳状 + 4 全通  → 完整混响（Freeverb 结构）
```

## 验证结果

### RT60 公式（已验证）

| RT60 设定 | 延迟 | 算出的 feedback | 实测 RT60 | 偏差 |
|---|---|---|---|---|
| 0.5 s | 23.3 ms | 0.7251 | 0.51 s | +2.4% |
| 1.0 s | 23.3 ms | 0.8515 | 1.00 s | +0.1% |
| 2.0 s | 23.3 ms | 0.9228 | 2.00 s | +0.1% |
| 3.0 s | 46.5 ms | 0.8985 | 3.02 s | +0.7% |

→ 这个公式可以直接用在插件里，把用户的 "decay 秒数" 换算成反馈增益。

### 阻尼的作用（已验证）

| damp | 高频-低频 能量差 @0-0.1s | @0.5-0.6s | @1.0-1.1s |
|---|---|---|---|
| 0.0 | +11.9 dB | +11.7 dB | +11.4 dB |
| 0.5 | +9.1 dB | **-35.3 dB** | **-68.4 dB** |
| 0.8 | +7.9 dB | **-131.3 dB** | **-156.9 dB** |

→ damp=0 时高低频衰减一样快（差值恒定）；damp 越大，高频衰减越快。
→ **这就是"数字味混响"和"自然混响"的区别。**

## 踩到的坑（**三次**都是测量方法错，不是代码错）

| 现象 | 我以为是 | 实际是 |
|---|---|---|
| 高频/中频能量比不单调 | 阻尼实现有 bug | 该比值受**整体电平**影响，不反映衰减速度 |
| 分频段测 RT60 全是 3.00s | 测量代码坏了 | 阈值穿越法在信号未衰减到阈值时**饱和** |
| 线性拟合斜率显示高频衰减**更慢** | 阻尼方向反了 | 信号衰减到**噪声底**后，拟合出的斜率是噪声的斜率 |

**正确做法**：比较**不同时间段**的分频段能量。
