# 40-Projects

具体的插件项目。一个项目一个文件，用 [[tpl-project]] 模板。

## 与 Playground 的区别

| | 50-Playground | 40-Projects |
|---|---|---|
| 目的 | 搞懂一个概念 | 做出一个能用的东西 |
| 生命周期 | 一次性 | 长期维护 |
| 代码质量 | 能跑就行 | 要给别人用 |
| 有 UI 吗 | 通常没有 | 有 |
| 会发布吗 | 不会 | 可能 |

## 项目文件里应该有什么

1. **一句话说明**：给谁用、解决什么问题
2. **技术选型**及理由（用 [[tpl-decision]] 单独记决策）
3. **进度**与阻塞
4. **踩过的坑**（链接到 `#gotcha` 笔记）
5. **用户反馈**（发布后）

> [!tip] 每个项目结束时
> 把可复用的部分（DSP 模块、UI 组件、测试脚本）提炼出来，
> 写成 Wiki 页或放进 `50-Playground/tools/`。
> **项目会死，知识应该活下来。**
