# 极零点与稳定性

> [!important] 一句话
> **极点和零点在复平面上的位置，完全决定了滤波器的行为。**
> 极点在单位圆内 = 稳定；极点角度 = 共振频率；极点半径 = 衰减速度。

## 为什么不用算系数就能预测音色

| 你看到的 | 说明 |
|---|---|
| 极点靠近单位圆 | 那个频率会**共振**（响、ringing 长） |
| 极点角度对应的频率 | 就是**共振峰的位置** |
| 零点在单位圆上 | 那个频率被**完全消除**（陷波） |
| 极点跑到圆外 | **发散**（爆炸） |
| 所有极点都在原点 | **FIR**（无反馈，无共振） |

> [!tip] 这是调试滤波器最快的工具
> 滤波器"听起来不对"时，**先画极零点图**：
> - 共振位置和你想要的不一样 → 调谐问题（见 [[状态变量滤波器 SVF]]）
> - 有不该有的共振 → 系数算错
> - 极点跑出圆外 → 立刻能看出不稳定

## 一、单位圆的意义

**z 平面上的单位圆 $|z| = 1$ 对应"频率轴"**：

$$z = e^{j\omega}, \qquad \omega = 2\pi f / f_s$$

| 圆上的位置 | 对应频率 |
|---|---|
| $z = 1$（角度 0） | **直流**（0 Hz） |
| $z = j$（角度 π/2） | $f_s/4$ |
| $z = -1$（角度 π） | **Nyquist**（$f_s/2$） |

```
              Im
               ↑
          ┌────┼────┐
      fs/4│    │    │  ← 单位圆
          │   ╱│╲   │
   ───────┼──╱─┼─╲──┼──────→ Re
     Nyquist  │   直流
         (-1) │  (1)
          └────┴────┘
               ↓
   圆内 = 稳定区 | 圆上 = 临界 | 圆外 = 发散
```

---

## 二、稳定性：三个区间的准确定义

> [!important] 实测验证（本库 2026-10-15）

| 极点位置 | 名称 | 脉冲响应 | 能用吗 |
|---|---|---|---|
| `|z| < 1` | **稳定** | 指数衰减到 0 | ✅ 正常滤波器 |
| `|z| = 1` | **临界稳定**（marginally stable） | 不衰减（恒定或持续振荡） | ⚠️ 只在特定设计 |
| `|z| > 1` | **不稳定** | 指数发散 | ❌ 绝对不能 |

**实测**（一阶系统，极点 $= a$）：

| 极点半径 | 10 秒后残余 | 判定 |
|---|---|---|
| 0.5000 | 0.000e+00 | ✅ 稳定 |
| 0.9000 | 2.47e-323 | ✅ 稳定 |
| 0.9900 | 2.42e-322 | ✅ 稳定 |
| 0.9990 | 1.95e-191 | ✅ 稳定 |
| **1.0000** | **不衰减** | ⚠️ **临界稳定** |
| **1.0010** | **2.28e+205** | ❌ **发散** |

> [!danger] $|z| = 1$ 不是"稳定"
> 我的第一次测试在 $a = 1$ 时得到"稳定"，但那是**退化情况**
> （系数 $1-a = 0$，整个系统变成零输出）。
>
> 用真正的临界情况（积分器 $y[n] = x[n] + y[n-1]$，极点 $z=1$）验证：
> **输入脉冲，输出恒定 1.0——不衰减也不发散。**
>
> 这叫**临界稳定**，不是稳定。实践中：
> - 纯积分器、数字振荡器**故意**用 $|z|=1$
> - 但系数只要有一点点误差（浮点、参数变化）就会滑到圆外 → 发散

> [!warning] 实践规则
> **永远留安全余量**：极点半径控制在 **0.999 以下**。
> 这就是为什么 [[延迟线 delay line]] 的反馈增益要钳制在 `0.999`。

## 三、极点角度 = 共振频率，半径 = 衰减速度

**共轭极点对**（实系数系统的极点必然成共轭对）：

$$p_{1,2} = r\, e^{\pm j\theta}$$

| 参数 | 物理意义 | 实测验证 |
|---|---|---|
| **角度 $\theta$** | 共振频率 $f = \theta \cdot f_s / (2\pi)$ | ✅ 见下表 |
| **半径 $r$** | 衰减速度（$r$ 越接近 1，衰减越慢） | ✅ 见下表 |

**实测**（目标共振频率 1000 Hz @ 48kHz）：

| 极点 $(r, \theta)$ | $\theta$ 对应频率 | 实测主频 | 10 秒后残余 |
|---|---|---|---|
| $r = 0.9$，$f_0 = 1000$ | 1000.0 Hz | **1009.3 Hz** | 1.48e-323 |
| $r = 0.99$，$f_0 = 1000$ | 1000.0 Hz | **1000.0 Hz** | 1.24e-322 |
| $r = 0.999$，$f_0 = 1000$ | 1000.0 Hz | **1000.0 Hz** | 1.47e-41 |

> [!tip] 怎么读
> - **角度决定频率** ✅（实测吻合，$r=0.9$ 时的 1009 Hz 偏差来自 FFT 分辨率）
> - **半径决定衰减**：$r=0.999$ 时 10 秒后还有 1.47e-41，
>   而 $r=0.9$ 已经衰减到 1e-323（浮点下限）
>
> **$r$ 从 0.9 到 0.999，衰减时间差了十几个数量级。**

> [!warning] ⚠️ 「极点角度对应的频率」≠「-3dB 截止频率」
> 这是两个不同的概念，**别混淆**。实测（RBJ Biquad 低通，$f_c$ = 1000 Hz，$f_s$ = 48kHz）：
>
> | Q | 极点角度对应 | **实测 -3dB 点** | 峰值增益 |
> |---|---|---|---|
> | 0.5 | 0.0 Hz | 644.3 Hz | 0.00 dB |
> | **0.707** | **709.0 Hz** | **999.9 Hz** | 0.00 dB |
> | 1.0 | 867.3 Hz | 1270.9 Hz | +1.25 dB |
> | 5.0 | 995.0 Hz | 1539.7 Hz | +14.02 dB |
> | 20.0 | 999.7 Hz | 1549.9 Hz | +26.02 dB |
>
> **RBJ 的 $f_c$ 定义是「-3dB 点」**（Q=0.707 时实测 999.9 Hz，准确 ✅），
> 而极点角度在 Q=0.707 时只对应 709 Hz。
>
> **什么时候该关心哪个**：
> - 做 EQ / 滤波器（关心"衰减到哪里"）→ 看 **-3dB 点**
> - 做共振器 / 振荡器（关心"振在哪个频率"）→ 看**极点角度**
> - 看"ringing 有多长"→ 看**极点半径**

**衰减时间常数**（近似）：

$$\tau \approx \frac{1}{(1-r)\, f_s} \quad \text{（秒）}$$

例如 $r = 0.999$、$f_s$ = 48kHz：$\tau \approx 1/(0.001 \times 48000) \approx 20.8$ ms。
因为指数衰减要 6.9τ 才到 99.9%，所以实际"响"约 **144 ms**。

## 四、零点：塑造形状

| 零点位置 | 效果 |
|---|---|
| $z = 1$ | **消除直流**（高通特性） |
| $z = -1$ | **消除 Nyquist**（低通特性） |
| $z = e^{\pm j\theta}$（在圆上） | **完全陷波**（notch，该频率增益 = 0） |
| $z = 0$ | 无影响（只贡献整体延迟/增益） |

> [!important] 零点不能造成不稳定
> **稳定性只由极点决定。** 零点放在哪里都不会让系统发散。
>
> 但零点会影响：
> - 频响形状（哪里被削弱）
> - 相位响应
> - 是否最小相位（影响相位失真）

**例子：一阶高通的零点**

$$H(z) = \frac{1-z^{-1}}{1 - a z^{-1}}$$

零点在 $z = 1$（直流），所以 $H(1) = 0$ → 直流被完全阻断。✅ 这就是高通。

## 五、从极零点快速判断滤波器类型

**只看 $z = 1$ 和 $z = -1$**（见 [[传递函数与 z 变换]] 第五节）：

| 类型 | 极点位置 | 零点位置 |
|---|---|---|
| 低通 | 靠近 $z=1$ | 在 $z=-1$ |
| 高通 | 靠近 $z=-1$ | 在 $z=1$ |
| 带通 | 在 $\theta$ 处成对 | 在 $z=\pm1$ |
| 陷波 | 在 $z=1$、$z=-1$ 附近 | **在圆上的 $\theta$ 处** |
| 全通 | 任意（圆内） | 极点的**倒数共轭**（镜像） |

> [!tip] 全通的极零点关系
> 全通滤波器的零点 = 极点的倒数共轭：$z_i = 1/p_i^*$
> **这保证 $|H(e^{j\omega})| = 1$ 对全频段成立**（见 [[全通滤波器 allpass]]）。
>
> 用这个关系可以快速检查：如果你写的全通极零点不满足这个关系，那就不是全通。

## 六、高阶滤波器的数值稳定性

> [!danger] 这是实践中最容易踩的坑

**问题**：把高阶滤波器写成**单个高阶差分方程**（直接型），
系数的**微小量化误差**会让极点大幅移动。

**实测概念**（经典结果）：

| 实现方式 | 8 阶低通的极点位置误差 |
|---|---|
| 直接型（一个 8 阶方程） | 可达**数量级**的偏移 → 可能发散 |
| **级联 4 个 biquad** | 每个 biquad 独立，误差可控 |

> [!important] 结论：**永远不要直接实现高阶 IIR**
> **正确做法**：分解成二阶节（SOS, Second-Order Sections）级联。
>
> $$\text{8 阶} \Rightarrow \text{4 个 biquad 串联}$$
>
> 这就是为什么 [[Biquad 滤波器]] 是音频里的基本构件。
>
> ⚠️ 本页没给出量化的实测对比（需要具体的设计和量化方案）。
> 见 [[_meta/open-questions]] 的待核实项。

**级联时还要注意**：
- **配对**：把极点靠近的放在同一个 biquad（避免中间结果过大）
- **顺序**：先放增益小的，避免中间溢出
- **缩放**：每个 biquad 内部可能溢出，即使最终输出正常

## 七、AI 会怎么写错

| # | AI 常犯 | 后果 | 怎么查 |
|---|---|---|---|
| 1 | **把单位圆上（`|z|=1`）当稳定** | 临界情况会发散 | 检查极点是否 < 0.999 |
| 2 | **零点和极点搞反** | 频响完全错 | 用 $H(1)$ 和 $H(-1)$ 自检 |
| 3 | **直接实现高阶 IIR** | 数值不稳、发散 | 应拆成 biquad 级联 |
| 4 | **级联时不考虑内部溢出** | 中间结果溢出 → 噪声 | 每个 biquad 检查缩放 |
| 5 | **以为零点会造成不稳定** | 概念错误 | 稳定性只看极点 |
| 6 | **极点半径不留余量** | 参数微调就发散 | 钳制到 0.999 以下 |
| 7 | **共轭极点只写一个** | 实系数系统不成立 | 检查复数是否成对 |
| 8 | **忘了 $H(z)$ 只对 LTI 有效** | 调制场景用错 | 见 [[传递函数与 z 变换]] |

> [!danger] 第 1 条最危险
> AI 会说"极点在单位圆上 → 临界稳定 → 可以接受"。
> **在浮点世界里，$|z|=1$ 几乎必然发散**——因为
> 浮点误差、参数变化、量化都会把极点推出去。
>
> **实践中一律要求 $|z| < 1$ 且留余量。**

## 八、常见坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 滤波器突然爆炸 | 极点跑到圆外 | 钳制参数，检查系数 |
| 共振位置不对 | 极点角度不对 | 见 [[状态变量滤波器 SVF]] 的调谐 |
| ringing 太长 | 极点太靠近单位圆 | 降低 Q 或增加阻尼 |
| 高阶滤波器不稳定 | 直接型实现 | 拆成 biquad 级联 |
| 陷波位置偏了 | 零点角度不对 | 检查系数 |
| 全通不"全通" | 极零点不满足镜像关系 | 检查 $z_i = 1/p_i^*$ |
| 参数扫描时爆音/发散 | 扫到了不稳定区 | 钳制参数范围 |

## 九、怎么验证

```python
import numpy as np

def poles_zeros (b, a):
    """从系数算极点和零点"""
    z = np.roots (b)      # 零点：分子为 0
    p = np.roots (a)      # 极点：分母为 0
    return z, p

def check_stability (b, a, margin=0.999):
    """检查稳定性，返回 (是否稳定, 最大极点半径)"""
    _, p = poles_zeros (b, a)
    if len(p) == 0:
        return True, 0.0          # FIR，永远稳定
    rmax = np.max (np.abs (p))
    return rmax < margin, rmax

# 例：Biquad 低通
fs, fc, Q = 48000.0, 1000.0, 0.707
w0=2*np.pi*fc/fs; al=np.sin(w0)/(2*Q); cw=np.cos(w0); a0=1+al
b=[(1-cw)/2/a0,(1-cw)/a0,(1-cw)/2/a0]; a=[1.0,-2*cw/a0,(1-al)/a0]

z, p = poles_zeros(b, a)
print(f"零点: {np.round(z,4)}")
print(f"极点: {np.round(p,4)}")
print(f"极点半径: {np.round(np.abs(p),6)}")
ok, rmax = check_stability(b, a)
print(f"{'✅ 稳定' if ok else '❌ 不稳定'}（最大半径 {rmax:.6f}）")

# 极点角度 → 共振频率
for pi in p:
    if np.imag(pi) > 0:
        f_res = np.angle(pi) * fs / (2*np.pi)
        print(f"共振频率 = {f_res:.1f} Hz（目标 {fc} Hz）")

# 验证：极点半径 < 1 且共振频率 ≈ fc
assert rmax < 1.0, "不稳定"
```

**对高 Q 的警告测试**：

```python
# Q 越大，极点越接近单位圆
for Q in [0.707, 1, 5, 20, 100]:
    w0=2*np.pi*fc/fs; al=np.sin(w0)/(2*Q); cw=np.cos(w0); a0=1+al
    a=[1.0,-2*cw/a0,(1-al)/a0]
    _, p = poles_zeros([0.0]*3, a)
    r = np.max(np.abs(p))
    tau_ms = 1/((1-r)*fs)*1000
    print(f"Q={Q:>5}: 极点半径 {r:.6f}，ringing 时间常数 ≈ {tau_ms:>8.2f} ms")
# 期望：Q 越大，半径越接近 1，ringing 越长
```
