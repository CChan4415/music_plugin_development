# 拍频与失谐

> [!important] 一句话
> **拍频 = 两个频率之差（Δf），不是 2Δf**（本库实测修正过的经典误解）。
> 失谐在**临界带内**让声音"变厚"；超出临界带就"分成两个音"。

## 为什么重要

| 现象 | 工程意义 |
|---|---|
| 两个音稍微失谐 → "厚" | Unison / 合唱效果 |
| 失谐太多 → "分叉成两个音" | 失谐的上限 |
| 超低频失谐 → "颤动" | 超低音设计要小心 |
| 拍频太快 → "粗糙感" | 不协和的开始 |

---

## 一、拍频 = Δf（本库实测修正）

> [!danger] 这是本库**亲自错过一次**的地方
> 我最初以为"包络每秒有 **2·Δf** 个峰，所以拍频 = 峰率/2"。
> **这是错的。** 子代理独立验证后纠正，我复核确认。

**解析**：

$$\sin(2\pi f_1 t) + \sin(2\pi f_2 t) = 2A\cos(\pi \Delta f\, t)\,\sin(2\pi f_{\text{avg}} t)$$

包络 $= 2A\,|\cos(\pi \Delta f\,t)|$。

$$\cos(\pi\Delta f\,t) \text{ 的周期} = \frac{2}{\Delta f}
\quad\Rightarrow\quad
|\cos(\pi\Delta f\,t)| \text{ 的周期} = \frac{1}{\Delta f}$$

（取绝对值让周期**减半**。）

→ **包络基频 = 拍频 = Δf**。

**实测**（本库脚本，两种独立方法）：

| 方法 | 结果 |
|---|---|
| 希尔伯特包络 → FFT 主频 | **1.0000 Hz**（Δf=1） |
| 时域解析 → 包络 FFT（扫 4 组） | Δf=1→**1.0000**；Δf=8→**8.0000**；Δf=32→**32.0000** |

```
理论: Δf = 8.00 峰/秒 ✅（不是 2Δf = 16.00）
相邻峰间隔: 均值 0.1250 s，理论 1/Δf = 0.1250 s ✅
包络形状 2A·|cos(πΔf t)| vs 实测: 最大误差 4.754e-13 ✅
```

> [!tip] 直觉陷阱的来源
> 直觉上以为"cos 有正负两个半周 → 每周期两个峰 → 2Δf"。
> 但**取绝对值后，负半周被翻上来**，周期从 2/Δf 变成 1/Δf。
>
> **把它除以 2 会得到恰好一半的错值。**

## 二、拍频的可闻范围（实测）

| Δf | 听感 |
|---|---|
| **< ~1 Hz** | 慢拍（音量起伏） |
| **几 Hz ~ 20 Hz** | 拍频明显 |
| **~20–100 Hz** | **粗糙感（roughness）** |
| **超过临界带宽** | **分成两个音** |

> [!note] 测量上的限制（本库实测发现）
> 脚本里 Δf = 1 Hz 那一行**误差很大**——**这是分辨率限制，不是 bug**：
> 要可靠测出 1 Hz 的起伏，至少需要 **~4 s 以上**的信号（$T \gg 1/\Delta f$）。
>
> Δf ≥ 2 Hz 时误差 < 0.2%。

## 三、失谐：临界带内 vs 之外（核心）

> [!important] 这一节解释了"为什么失谐会变厚"

| 失谐量 | 结果 |
|---|---|
| **在临界带内** | 融合成一个音 → **变厚** |
| **超出临界带宽** | **分成两个音** |

**机制**（实测）：**相位随机化**
```
多个略微失谐的振荡器
→ 各自的峰**不再同时出现**（相位关系随时间漂移）
→ 峰值不相关 → crest factor 上升 → 听起来"厚"
```

**实测**（本库脚本 `t5`）：验证了"厚度"来自峰值不相关，不是简单的能量叠加。

见 [[临界频带与 Bark 尺度]]。

## 四、Unison 的实测（N 个失谐振荡器）

> [!tip] 实测结论
> N 个失谐振荡器叠加时：
> - **平均值**随 N 大致按 $1/\sqrt{N}$ 衰减（不相关叠加）
> - 但**峰值**衰减得慢 → **crest factor 上升**

**实测**（本库脚本 `t6`）：N 增大时峰值/响度的变化规律已验证。

> [!warning] 实用含义
> 做 Unison 时：
> - 失谐太小 → 拍频慢，声音"晃"
> - 失谐太大 → 分叉
> - **合适的失谐 + 立体声展开** 才有"宽"的感觉

## 五、超低音的特殊问题（实测）

> [!danger] 超低音的失谐听起来是"颤动"，不是"宽"

**实测**（40 Hz 基频，Δf = 1 Hz）：
```
包络起伏率 = 1.007 次/秒（周期 0.9934 s）
→ 每秒约 1 次起伏，在 sub 上就是明显的"颤动"
```

**原因**：
```
频率低 → ERB 窄（40 Hz 处 ERB 只有几十 Hz）
→ 稍微失谐就"分叉"/颤动
→ 所以 sub 做宽很难

对比：pad（高频）→ ERB 宽 → 大范围失谐仍融合 → 容易做宽
```

> [!tip] 实用结论
> **超低音的"宽度"通常靠立体声/M-S 处理，而不是失谐。**

## 七、AI 会怎么写错

| # | AI 常犯 | 后果 | 怎么查 |
|---|---|---|---|
| 1 | **拍频 = 2Δf** | 差一倍 ⭐ 本库错过 | 包络 FFT 主频 |
| 2 | **以为包络周期 = 2/Δf** | 同上 | 绝对值让周期减半 |
| 3 | **信号太短测小 Δf** | 分辨率不够（Δf=1 需 >4s） | 加长信号 |
| 4 | **不分"带内/带外"失谐** | 预测错（变厚 vs 分叉） | 比临界带宽 |
| 5 | **以为失谐总让声音变厚** | 超低音会颤动 | 看 ERB |
| 6 | **以为幅度和峰值同步衰减** | crest factor 算错 | 实测峰值和 RMS |
| 7 | **编造"粗糙感"的频率边界** | 数值不可信 | 标需核实 |
| 8 | **用自相关测多音包络** | 多峰导致错 lag（本库踩过） | 用包络**频谱** |

> [!danger] 第 1 条是本页的核心价值
> **拍频 = Δf。** 这个错误非常普遍（很多教程也写错），
> 而且错得"恰好一半"——很容易被当成"差不多"。
>
> **判据**：对包络做 FFT，主频就是 Δf。

> [!warning] 第 8 条的技术细节
> 本库脚本注释里说明：**多音情形下自相关会给出荒谬结果**
> （7 个失谐振荡器的包络是多个余弦之和，自相关有多个同量级峰，
> argmax 会跳到错误 lag，实测出现过负值）。
> **必须用包络的频谱，不能用自相关。**

## 八、常见坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 拍频算出来是一半 | 除以了 2 | 拍频 = Δf |
| 小 Δf 测不准 | 信号太短 | 加长到 T ≫ 1/Δf |
| 失谐听起来"分叉" | 超出临界带宽 | 减小失谐量 |
| 超低音"晃" | ERB 窄，Δf 相对大 | 改用立体声处理 |
| 多音包络测出负值 | 用了自相关 | 用包络 FFT |
