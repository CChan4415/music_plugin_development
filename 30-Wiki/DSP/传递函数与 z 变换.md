# 传递函数与 z 变换

> [!important] 一句话
> **$z^{-1}$ 就是"延迟一个采样"。** 把这个记号代入差分方程，就能把"时域的递推"变成"代数的比值"——
> 这个比值就是传递函数 $H(z)$，它**完整描述**一个线性时不变系统。

## 为什么这一页对你有用

| 你想知道 | $H(z)$ 怎么回答 |
|---|---|
| 这个滤波器稳定吗 | 看极点在不在单位圆内 |
| 它在 1kHz 的增益是多少 | 代入 $z = e^{j2\pi f/f_s}$ |
| 它是低通还是高通 | 看 $z=1$（直流）和 $z=-1$（Nyquist）处的值 |
| 改这个系数会发生什么 | 看极点怎么移动 |
| 两个滤波器串联的结果 | $H_1(z) \cdot H_2(z)$ |

> [!note] 别被符号吓到
> 你**不需要会推导 z 变换**。你需要的是：
> 1. 认识 $z^{-1}$ = 延迟
> 2. 会把差分方程改写成 $H(z)$
> 3. 会代入 $z = e^{j\omega}$ 算频响
>
> 就这三件事，覆盖插件开发 95% 的场景。

## 一、$z^{-1}$ 就是"延迟一个采样"

这是全部直觉的来源。

| 时域 | z 域 |
|---|---|
| $x[n]$ | $X(z)$ |
| $x[n-1]$（延迟 1 采样） | $z^{-1} X(z)$ |
| $x[n-2]$（延迟 2 采样） | $z^{-2} X(z)$ |
| $x[n-D]$ | $z^{-D} X(z)$ |
| $y[n-1]$（输出延迟 1） | $z^{-1} Y(z)$ |

> [!tip] 为什么是 $z^{-1}$ 而不是 $z$
> 只是记号约定。$z^{-1}$ 表示"往后看一个采样"，
> 这样延迟 N 个采样写作 $z^{-N}$，幂次和延迟量一致，读起来直观。

---

## 二、从差分方程得到 $H(z)$

**步骤**：把每一项换成 z 域形式，然后解出 $Y(z)/X(z)$。

### 例 1：一阶低通

时域：

$$y[n] = (1-a)\,x[n] + a\,y[n-1]$$

**第一步**：逐项替换

$$Y(z) = (1-a)X(z) + a\,z^{-1}Y(z)$$

**第二步**：把含 $Y$ 的项移到左边

$$Y(z)\left(1 - a z^{-1}\right) = (1-a)X(z)$$

**第三步**：解出比值

$$\boxed{H(z) = \frac{Y(z)}{X(z)} = \frac{1-a}{1 - a z^{-1}}}$$

> [!important] 关键观察
> 分子和分母的系数**就是差分方程的系数**。
> - 分子（$1-a$）来自"输入的系数"
> - 分母（$1 - az^{-1}$）来自"输出的系数"
>
> **所以从差分方程到 $H(z)$ 是机械操作，不需要理解变换本身。**

### 例 2：带反馈的延迟（梳状）

$$y[n] = x[n] + g\,y[n-D]$$

$$H(z) = \frac{1}{1 - g z^{-D}}$$

### 例 3：前馈（FIR）

$$y[n] = b_0 x[n] + b_1 x[n-1] + b_2 x[n-2]$$

$$H(z) = b_0 + b_1 z^{-1} + b_2 z^{-2}$$

> [!note] 一个有用的区分
> - **分母有 $z$** → 有反馈 → **IIR**（无限脉冲响应）
> - **只有分子** → 无反馈 → **FIR**（有限脉冲响应）
>
> 见 [[IIR 滤波器]] / [[FIR 滤波器]]。

## 三、$H(z)$ 的通用形式

$$H(z) = \frac{b_0 + b_1 z^{-1} + \cdots + b_M z^{-M}}{1 + a_1 z^{-1} + \cdots + a_N z^{-N}}$$

**写成极零点形式**（更有洞察力）：

$$H(z) = K \cdot \frac{(1 - z_1 z^{-1})(1 - z_2 z^{-1})\cdots}{(1 - p_1 z^{-1})(1 - p_2 z^{-1})\cdots}$$

| 记号 | 名称 | 作用 |
|---|---|---|
| $z_i$ | **零点** | 让该频率的增益为 0（陷波） |
| $p_i$ | **极点** | 让该频率的增益飙升（共振） |
| $K$ | 增益常数 | 整体幅度 |

> [!important] 这个形式的威力
> **极点和零点的位置，完全决定了频响形状。**
> 你不需要算系数，只要知道极零点在哪，就知道这个滤波器听起来什么样。
>
> 详见 [[极零点与稳定性]]。

## 四、从 $H(z)$ 算频率响应

**代入** $z = e^{j\omega}$，其中 $\omega = 2\pi f / f_s$：

$$H(e^{j\omega}) = H(z)\Big|_{z=e^{j\omega}}$$

$|H|$ 是幅度响应，$\angle H$ 是相位响应。

### 实测验证：两种算法必须一致

一阶低通（$f_c$ = 1kHz，$f_s$ = 48kHz，$a = e^{-2\pi f_c/f_s} = 0.877306$）：

| 频率 | 极零点法 | 直接代入 | 差 |
|---|---|---|---|
| 100 Hz | 0.995044 | 0.995044 | 0.00e+00 |
| 1000 Hz | 0.707611 | 0.707611 | 0.00e+00 |
| 5000 Hz | 0.199658 | 0.199658 | 0.00e+00 |
| 10000 Hz | 0.106973 | 0.106973 | 0.00e+00 |

> [!tip] 注意 1kHz 处是 0.7076 ≈ $1/\sqrt{2}$
> 这就是 **-3 dB 点**——截止频率的定义。
> 所以"$f_c$ 处衰减 3 dB"这件事可以从 $H(z)$ 直接算出来，不用听。

```python
import numpy as np

def H_from_diff_eq (f, fs=48000.0, fc=1000.0):
    """一阶低通 y[n]=(1-a)x[n]+a·y[n-1] 的频率响应"""
    a = np.exp (-2*np.pi*fc/fs)
    z = np.exp (1j*2*np.pi*f/fs)
    return (1-a) / (1 - a/z)          # H(z) 代入 z=e^{jω}

def H_from_pole_zero (f, fs=48000.0, fc=1000.0):
    """同一系统，用极零点形式算"""
    a = np.exp (-2*np.pi*fc/fs)
    z = np.exp (1j*2*np.pi*f/fs)
    return (1-a) * 1.0 / (1 - a/z)    # 极点 p=a，无零点（除 z=0）

for f in [100, 1000, 5000, 10000]:
    h1, h2 = abs(H_from_diff_eq(f)), abs(H_from_pole_zero(f))
    assert abs(h1-h2) < 1e-15
print("✅ 两种算法一致：极零点完整描述系统")

# 顺便验证 -3dB 点
h_fc = abs(H_from_diff_eq(1000.0))
print(f"✅ fc 处增益 = {20*np.log10(h_fc):.2f} dB（理论 -3.01 dB）")
```

## 五、直流与 Nyquist：快速判断滤波器类型

**只要看两个点**，就能判断滤波器类型：

| 检查点 | $z$ 的值 | 对应频率 |
|---|---|---|
| **直流** | $z = 1$ | 0 Hz |
| **Nyquist** | $z = -1$ | $f_s/2$ |

| 滤波器类型 | $H(1)$（直流） | $H(-1)$（Nyquist） |
|---|---|---|
| **低通** | 1（通过） | 0（阻断） |
| **高通** | 0 | 1 |
| **带通** | 0 | 0 |
| **全通** | 1 | 1（且全频段都是 1） |

> [!tip] 这是最快的自检方法
> 写完一个滤波器，先算 $H(1)$ 和 $H(-1)$：
> - 低通的 $H(1)$ 应该是 1（直流完全通过）
> - 高通的 $H(-1)$ 应该接近 1
>
> **如果不对，说明系数抄错了。** 比做 FFT 快得多。

```python
def dc_gain (b, a):
    """直流增益 H(z=1) = sum(b)/sum(a)"""
    return np.sum(b) / np.sum(a)

def nyquist_gain (b, a):
    """Nyquist 增益 H(z=-1)：交替符号求和"""
    zb = sum (bi * ((-1)**i) for i, bi in enumerate(b))
    za = sum (ai * ((-1)**i) for i, ai in enumerate(a))
    return zb / za

# Biquad 低通（RBJ, fc=1kHz, Q=0.707）
import numpy as np
fs, fc, Q = 48000.0, 1000.0, 0.707
w0 = 2*np.pi*fc/fs; alpha = np.sin(w0)/(2*Q); cw = np.cos(w0)
a0 = 1+alpha
b = [(1-cw)/2/a0, (1-cw)/a0, (1-cw)/2/a0]
a = [1.0, -2*cw/a0, (1-alpha)/a0]
print(f"Biquad 低通: 直流增益 {dc_gain(b,a):.6f}（应≈1）")
print(f"             Nyquist 增益 {nyquist_gain(b,a):.6f}（应≈0）")
```

## 六、串联与并联

| 连接 | 传递函数 | 时域对应 |
|---|---|---|
| **串联**（级联） | $H(z) = H_1(z)\cdot H_2(z)$ | 先过 1 再过 2 |
| **并联** | $H(z) = H_1(z) + H_2(z)$ | 两路相加 |

> [!important] 串联的实用推论
> **4 阶滤波器 = 两个 2 阶（biquad）串联。**
> 这是实践中的标准做法——因为直接算 4 阶的系数会有数值问题。
> 见 [[极零点与稳定性]] 的"高阶数值稳定性"。

## 七、AI 会怎么写错

| # | AI 常犯 | 后果 | 怎么查 |
|---|---|---|---|
| 1 | **$z^{-1}$ 和 $z$ 混用** | 极零点位置反了（倒数） | 检查推导：延迟对应 $z^{-1}$ |
| 2 | **符号约定不一致** | 分母系数符号错 → 发散 | 确认 $1 + a_1z^{-1}$ 还是 $1 - a_1z^{-1}$ |
| 3 | **把 $H(1)$ 当成恒定增益** | 只对直流成立 | 频响要逐点算 |
| 4 | **混淆幅度和功率 dB** | 差一倍 | 幅度用 $20\log_{10}$ |
| 5 | **忽略 $H(z)$ 只在 LTI 下有效** | 时变系统用错工具 | 调制/非线性系统不适用 |
| 6 | **忘了归一化 $a_0$** | 增益不对 | 检查是否除以 a0 |
| 7 | **用 $z=e^{j\omega}$ 但 $\omega$ 单位错** | 频率差 $2\pi$ 倍 | $\omega = 2\pi f/f_s$ |

> [!warning] 第 5 条容易被忽略
> $H(z)$ 描述的是**线性时不变**系统。
> 如果你的滤波器系数**每采样都在变**（LFO 调制），
> 那它**不是 LTI**，$H(z)$ 严格来说不适用。
>
> 实践中仍可以"瞬时"地用 $H(z)$ 近似（叫"冻结系数近似"），
> 但要意识到：**快速调制时实际响应和 $H(z)$ 预测的不一样**。

## 八、常见坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 滤波器发散 | 极点跑到单位圆外 | 见 [[极零点与稳定性]] |
| 增益差一个常数倍 | 没归一化 $a_0$ | 所有系数除以 a0 |
| 系数量化后行为变了 | 高阶直接型的数值问题 | 拆成级联 biquad |
| 频响和公式对不上 | $\omega$ 或符号约定错 | 用 $H(1)$/H(-1)$ 自检 |
| 并联后增益变大 | 忘了并联是相加 | 需要时加 1/N |
| 调制时听感与预期不符 | 非 LTI 系统 | 见第 5 条警告 |

## 九、怎么验证

```python
import numpy as np

def verify_H (b, a, fs=48000.0, nfft=1<<14):
    """三个自检：直流、Nyquist、与脉冲响应 FFT 对比"""
    # 1. 直流 / Nyquist（解析）
    dc  = np.sum(b) / np.sum(a)
    zb  = sum (bi*((-1)**i) for i,bi in enumerate(b))
    za  = sum (ai*((-1)**i) for i,ai in enumerate(a))
    nyq = zb/za

    # 2. 实测脉冲响应的频响
    x = np.zeros(nfft); x[0] = 1.0
    y = np.zeros(nfft)
    for n in range(nfft):
        acc = sum (b[i]*x[n-i] for i in range(len(b)) if n-i >= 0)
        acc -= sum (a[i]*y[n-i] for i in range(1,len(a)) if n-i >= 0)
        y[n] = acc
    H = np.fft.rfft(y); f = np.fft.rfftfreq(nfft, 1/fs)

    # 3. 对比直流与 Nyquist
    print(f"  解析: H(1)={dc:.6f}, H(-1)={nyq:.6f}")
    print(f"  实测: H(0)={abs(H[0]):.6f}, H(fs/2)={abs(H[-1]):.6f}")
    assert abs(abs(H[0]) - abs(dc)) < 1e-6, "直流不一致"
    print("  ✅ 一致")

# Biquad 低通
fs, fc, Q = 48000.0, 1000.0, 0.707
w0=2*np.pi*fc/fs; al=np.sin(w0)/(2*Q); cw=np.cos(w0); a0=1+al
b=[(1-cw)/2/a0,(1-cw)/a0,(1-cw)/2/a0]; a=[1.0,-2*cw/a0,(1-al)/a0]
verify_H(b, a)
```

> [!tip] 最快的一条自检
> **写任何滤波器，先算 $H(1)$ 和 $H(-1)$。**
> 低通：$H(1)\approx 1$、$H(-1)\approx 0$。
> 不对就是系数错了——不用做 FFT，不用听。
