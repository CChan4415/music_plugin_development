# 20-Notes

**你的**理解、判断、疑问、实验记录。

## 为什么单独一层

如果知识库只有 `10-Sources` 和 `30-Wiki`，它会变成"AI 整理的资料库"。
`20-Notes` 是唯一记录**你怎么想**的地方——而这恰恰是知识库里唯一不可替代的部分。

## 什么时候写

- 你搞懂了一个之前不懂的概念
- 你对某个来源的说法**不同意**
- 你做了实验，有结论
- 你踩了坑（用 [[tpl-gotcha]] 模板，打 `#gotcha` 标签）
- 你有一个还没想清楚的问题

## 判断标准

> [!tip] 一个测试
> 如果一句话在论文里能找到原话，它属于 `10-Sources` 或 `30-Wiki`。
> 如果它是**你的**话——你的类比、你的判断、你的经验映射——它属于这里。

## 命名

`YYYY-MM-DD 主题.md`（日记式）或 `主题.md`（长期维护的思考页）
