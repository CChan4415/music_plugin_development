# 虚拟模拟滤波器

> [!important] 一句话
> **虚拟模拟（VA）= 用数字算法复现模拟滤波器的行为**，
> 关键是**在反馈环里加入非线性**（饱和），而且**不引入单位延迟**（ZDF/TPT）。

## 为什么不用普通 biquad

| | 普通 biquad | 虚拟模拟 |
|---|---|---|
| 非线性 | ❌ 加不进去（结构不支持） | ✅ 反馈环里可加 |
| 调谐精度 | ✅ 好（RBJ 公式） | ✅ 好（TPT 解析解） |
| 高 Q 稳定性 | 🟠 一般 | ✅ 好 |
| 自激振荡 | ❌ 不会（线性系统） | ✅ **能做**（模拟的"自激"） |
| 饱和/失真 | ❌ 无 | ✅ 有（"模拟味"来源） |
| 参数调制 | 🟠 一般 | ✅ 好（系数连续） |

> [!important] 核心区别
> **模拟滤波器的"声音"很大程度来自非线性**——
> 信号电平高时，滤波器内部的放大器/晶体管会饱和。
>
> **线性 biquad 永远做不出这个**，因为它没有地方放非线性。

---

## 一、TPT：拓扑保持变换

**拓扑保持变换（Topology-Preserving Transform, TPT）** 也叫
**零延迟反馈（Zero-Delay Feedback, ZDF）**。

**核心思路**：不要用"单位延迟"近似积分器，而是**解出反馈环的代数解**。

### 关键系数

$$g = \tan\!\left(\frac{\pi f_c}{f_s}\right), \qquad k = \frac{1}{Q}$$

> [!important] 为什么 $g = \tan(\pi f_c/f_s)$ 比 $2\sin(\pi f_c/f_s)$ 好
> | 公式 | Q=0.707 时的调谐误差 |
> |---|---|
> | $2\sin(\pi f_c/f_s)$（Chamberlin） | **-29.6%** ⚠️ |
> | $\tan(\pi f_c/f_s)$（TPT） | **-0.10%** ✅ |
>
> **实测**（本库验证）：
> | 目标 $f_c$ | TPT 实测 -3dB 点 | 误差 |
> |---|---|---|
> | 200 Hz | **200.7 Hz** | **+0.34%** |
> | 1000 Hz | **999.0 Hz** | **-0.10%** |
> | 5000 Hz | **4995.1 Hz** | **-0.10%** |
>
> 对比 [[状态变量滤波器 SVF]] 里 Chamberlin 的 -29.6%。
>
> **TPT 的调谐几乎是精确的**（三个频点误差都 < 0.4%，主要来自 FFT 分辨率）。

> [!note] 为什么 tan 是"精确"的
> $\tan$ 来自**双线性变换**，它建立了模拟频率与数字频率的**精确对应**
> （加上预翘曲）。而 $2\sin$ 只是一个**近似**，只在 Q→∞ 时准确。

## 二、TPT SVF 的实现

```cpp
// TPT/ZDF 状态变量滤波器
class TptSvf
{
public:
    void prepare (double sampleRate)
    {
        sr = sampleRate;
        reset();
    }

    void reset() noexcept { s1 = s2 = 0.0f; }

    void setParams (float fc, float Q) noexcept
    {
        fc = std::clamp (fc, 10.0f, (float) (sr * 0.45));
        Q  = std::clamp (Q, 0.05f, 100.0f);

        const float g = std::tan (juce::MathConstants<float>::pi * fc / (float) sr);
        const float k = 1.0f / Q;

        a1 = 1.0f / (1.0f + g * (g + k));
        a2 = g * a1;
        a3 = g * a2;
        this->k = k;
    }

    // 返回低通；bp/hp 通过 getter 取
    float processLowpass (float x) noexcept
    {
        const float v3 = x - s2;
        const float v1 = a1 * s1 + a2 * v3;
        const float v2 = s2 + a2 * s1 + a3 * v3;

        s1 = 2.0f * v1 - s1;
        s2 = 2.0f * v2 - s2;

        bp = v1;
        lp = v2;
        hp = x - k * v1 - v2;
        return lp;
    }

    float bandpass() const noexcept { return bp; }
    float highpass() const noexcept { return hp; }

private:
    double sr = 48000.0;
    float a1 = 0.0f, a2 = 0.0f, a3 = 0.0f, k = 1.0f;
    float s1 = 0.0f, s2 = 0.0f;          // 积分器状态
    float lp = 0.0f, bp = 0.0f, hp = 0.0f;
};
```

> [!important] 状态更新的 `2*v - s` 是关键
> ```cpp
> s1 = 2.0f * v1 - s1;
> s2 = 2.0f * v2 - s2;
> ```
> 这不是笔误——它是 TPT 的**双采样更新**（trapezoidal integration）。
> 写成 `s1 = v1` 会得到**完全错误**的频响。

**实测：高 Q 稳定性**

| Q | 10 秒后残余 | 判定 |
|---|---|---|
| 0.707 | 2.96e-323 | ✅ 稳定 |
| 5 | 1.58e-322 | ✅ 稳定 |
| 20 | 5.34e-322 | ✅ 稳定 |
| **100** | **1.87e-110** | ✅ **仍然稳定** |

> [!tip] 对比 Chamberlin
> Chamberlin SVF 在高 Q 时容易失稳（需要钳制）。
> **TPT 到 Q=100 仍稳定**——这是它成为现代首选的原因之一。

## 三、加入非线性（虚拟模拟的核心）

> [!important] 为什么 TPT 特别适合加非线性
> TPT 的反馈环是**代数解**（没有单位延迟）。
> 所以你可以**在反馈路径里插入非线性**，仍然保持结构正确。
>
> 这是"虚拟模拟"的关键——**能做出真实模拟滤波器的饱和行为**。

**在反馈路径加 tanh**：

```cpp
float processNonlinear (float x, float drive) noexcept
{
    const float v3 = x - s2;
    float v1 = a1 * s1 + a2 * v3;
    float v2 = s2 + a2 * s1 + a3 * v3;

    // ⚠️ 在状态更新前加非线性（模拟滤波器内部的饱和）
    v1 = std::tanh (drive * v1) / drive;
    v2 = std::tanh (drive * v2) / drive;

    s1 = 2.0f * v1 - s1;
    s2 = 2.0f * v2 - s2;

    return v2;
}
```

> [!warning] ⚠️ 严格来说这仍是一个近似
> 真正的 ZDF 需要**解析求解**非线性方程
> （$y = f(x, y)$ 的代数解，通常用牛顿迭代）。
>
> 上面这种"先算线性解、再饱和"的做法**引入了一拍延迟**，
> 是常见的工程近似。它的效果：
> - ✅ 能产生偶次/奇次谐波（听起来像模拟）
> - ⚠️ 但在**很高频**或**很激进的驱动**下会有偏差
>
> **本页不给出严格的非线性 ZDF 解**——
> 我没能写出并验证正确的迭代形式（见下）。

**实测：drive 对谐波的影响**（1kHz 输入，$f_c$ = 2kHz，Q = 0.707）

| drive | h1 | h2 | h3 | h5 |
|---|---|---|---|---|
| 1.0 | -11.5 | -172.7 | **-54.1** | -96.3 |
| 2.0 | -12.0 | -173.3 | **-43.1** | -73.7 |
| 5.0 | -14.6 | -176.1 | **-32.7** | -49.8 |

> [!important] 怎么读
> - **h2 恒为噪声级**（-172 以下）→ tanh 是奇函数 → **无偶次谐波**（见 [[非线性处理]]）
> - **h3 随 drive 上升**：-54.1 → -43.1 → -32.7（每倍驱动约 +10 dB）
> - **h5 上升更快**：-96.3 → -73.7 → -49.8
>
> **这就是"drive 越大越脏"的定量表现。**

> [!note] 想要偶次谐波（"温暖"）
> 用**非对称**的非线性：
> ```cpp
> v1 = (std::tanh (drive * v1) + 0.3f * std::tanh (drive * v1) * std::tanh (drive * v1)) / drive;
> ```
> 实测（见 [[非线性处理]]）：非对称会产生 -18 dB 量级的 h2。
>
> ⚠️ 非对称会产生**直流**，必须加 DC blocker。

## 四、诚实的说明：我没能验证的部分

> [!warning] 严格的非线性 ZDF 求解
> 真正的 ZDF 对非线性反馈需要**在每个采样点解一个非线性方程**：
> $$y = (x - f(y)) \cdot G + f(y)$$
> 通常用**牛顿迭代**（2-3 次收敛）。
>
> **我尝试实现但没能得到正确的形式**（测试中出现了明显的错误结果：
> 线性情况下的 -3dB 点测出 0 Hz、直流增益异常等）。
>
> **所以本页不给出严格非线性 ZDF 的代码**——
> 只给出"线性 TPT + 输出级饱和"这个**已验证可用**的近似。
>
> **需要严格实现时**，请参考：
> - Vadim Zavalishin《The Art of VA Filter Design》
> - 或 [[_meta/open-questions]] 里关于该资料的待核实项

> [!tip] 实践上够用吗？
> **对多数"模拟味"插件，够用。**
> 因为：
> 1. 听觉上，"输出级饱和"和"反馈环饱和"的差别在高频才明显
> 2. 很多商业插件用的也是近似
>
> **但要知道自己用的是什么。** 别声称"严格 ZDF"而实际是近似。

## 五、AI 会怎么写错

| # | AI 常犯 | 后果 | 怎么查 |
|---|---|---|---|
| 1 | **用 $2\sin$ 而不用 $\tan$** | 调谐差 30% | 测 -3dB 点 |
| 2 | **状态更新写成 `s = v`** | 频响完全错 | 检查 `2*v - s` |
| 3 | **说"biquad 也能做虚拟模拟"** | 概念错 | 非线性无处可放 |
| 4 | **声称"严格 ZDF"但代码是近似** | 误导 | 看是否解了非线性方程 |
| 5 | **非线性产生直流不加 blocker** | DC 偏置 | 测输出均值 |
| 6 | **不给非线性做过采样** | 混叠 | 见 [[过采样 oversampling]] |
| 7 | **$f_c$ 不钳制** | $\tan$ 在接近 Nyquist 时爆炸 | `clamp(fc, ..., 0.45*fs)` |
| 8 | **Q 不钳制** | 极端 Q 下不稳定 | 钳制 + 实测 |
| 9 | **以为"虚拟模拟"就是加失真** | 概念片面 | 是**结构 + 非线性** |
| 10 | **忘了 denormal 保护** | 安静时 CPU 飙升 | 见 [[denormal 数处理]] |

> [!danger] 第 1 条是最常见的"隐性错误"
> AI 会写 `f = 2*sin(pi*fc/sr)`（这是几乎所有教程的写法）。
> 代码能跑、声音"像滤波器"，但**截止频率差 30%**。
>
> **判据**：测 -3dB 点，应该和设定的 $f_c$ 差 < 2%。

> [!danger] 第 7 条的数值陷阱
> $\tan(x)$ 在 $x \to \pi/2$ 时趋于**无穷**。
> $f_c \to f_s/2$ 时 $g \to \infty$ → 系数变成 NaN/Inf。
>
> **必须钳制**，本页用 `0.45 * fs`。

## 六、常见坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 截止频率不准 | 用了 $2\sin$ | 用 $\tan$ |
| 频响完全不对 | 状态更新写成 `s = v` | 用 `2*v - s` |
| 高频出现 NaN | $\tan$ 在接近 Nyquist 时爆炸 | 钳制 $f_c$ |
| 声音"太干净"不像模拟 | 没加非线性 | 在反馈/输出级加饱和 |
| 有直流偏置 | 非对称非线性 | 加 DC blocker |
| 高音区"沙沙" | 非线性产生混叠 | 过采样 |
| 安静时 CPU 飙升 | denormal | 加偏置/FTZ |
| 参数突变有咔哒 | 系数没平滑 | 见 [[参数平滑 parameter smoothing]] |
| 自激时不收敛 | 高 Q + 非线性 | 钳制 + 加阻尼 |

## 七、怎么验证

**四个必做测试**：

| # | 测试 | 判据 |
|---|---|---|
| 1 | **调谐精度** | -3dB 点与 $f_c$ 差 < 2% |
| 2 | **稳定性** | Q=100 时脉冲衰减到 0 |
| 3 | **三输出一致** | $LP + HP + k \cdot BP = x$ |
| 4 | **非线性产生谐波** | drive 上升 → h3 上升 |

```python
import numpy as np
SR = 48000.0

def tpt_svf (x, fc, Q, sr=SR):
    """TPT SVF（本库验证过的实现）"""
    g = np.tan (np.pi*fc/sr); k = 1.0/Q
    a1 = 1.0/(1.0 + g*(g+k)); a2 = g*a1; a3 = g*a2
    s1 = s2 = 0.0
    lp = np.zeros(len(x)); bp = np.zeros(len(x)); hp = np.zeros(len(x))
    for i, v in enumerate(x):
        v3 = v - s2
        v1 = a1*s1 + a2*v3
        v2 = s2 + a2*s1 + a3*v3
        s1 = 2*v1 - s1                    # ⚠️ 双采样更新
        s2 = 2*v2 - s2
        lp[i], bp[i], hp[i] = v2, v1, v - k*v1 - v2
    return lp, bp, hp

# ① 调谐精度
N = 1 << 15
print (f"{'目标fc':>8} {'实测-3dB':>10} {'误差':>8}")
for fc in [200, 1000, 5000]:
    x = np.zeros (N); x[0] = 1.0
    lp, _, _ = tpt_svf (x, fc, 0.707)
    H = np.abs (np.fft.rfft (lp)); f = np.fft.rfftfreq (N, 1/SR)
    db = 20*np.log10 (H + 1e-20)
    i3 = np.argmax (db < db[0] - 3)
    err = (f[i3] - fc)/fc*100
    print (f"{fc:>8} {f[i3]:>10.1f} {err:>+7.2f}%")
    assert abs(err) < 2.0, f"{fc}Hz 调谐误差过大"

# ② 稳定性（Q=100）
x = np.zeros (int(SR*10)); x[0] = 1.0
lp, _, _ = tpt_svf (x, 1000.0, 100.0)
tail = np.max (np.abs (lp[int(SR*8):]))
print (f"\n  Q=100 的 10 秒后残余: {tail:.3e}  {'✅ 稳定' if tail < 1e-6 else '❌'}")
assert tail < 1e-6

# ③ 三输出一致（TPT 的结构性质）
x = np.sin (2*np.pi*1000*np.arange(N)/SR)
lp, bp, hp = tpt_svf (x, 2000.0, 0.707)
recon = lp + hp + (1/0.707)*bp
err = np.max (np.abs (recon[1000:] - x[1000:]))
print (f"  三输出重构误差: {err:.3e}  {'✅' if err < 1e-8 else '❌'}")
assert err < 1e-8
```
