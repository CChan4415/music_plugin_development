# exp-001: 听到你算出来的声音

> [!important] 这是你的第一个实验，**今天就能跑**
> 它验证的是 [[Python 优先的 DSP 学习路径]] 的前 4 个练习。

## 我想验证什么

1. 我能用代码算出声音，并听到它
2. 我能理解 dB 与线性增益的关系
3. 我能实现一个滤波器，并且**用数学证明它是对的**

## 怎么运行

```bash
pip install numpy
python3 demo.py                # 自动播放
python3 demo.py --no-play      # 只生成文件
```

## 你会得到什么

| 文件 | 听什么 |
|---|---|
| `01-sine440.wav` | 你自己算出来的 A4 |
| `02-white.wav` / `02-pink.wav` | 白噪声 vs 粉噪声的听感差别 |
| `03-compare.wav` | -6dB 到底是多少（先 0.5 后 0.25） |
| `04-lowpass-sweep.wav` | 滤波器扫截止频率：从"明亮"到"闷" |

## 结论（已验证）

| 检查项 | 结果 | 说明 |
|---|---|---|
| 440Hz 正弦主频 | **440.00 Hz**（FFT） | ✅ |
| 峰值 0.5 的 dB 值 | **-6.02 dBFS** | 与 `20*log10(0.5)` 一致 |
| 一阶低通 vs 解析解 | **最大偏差 0.0011 dB** | 实现正确 |

> [!tip] 最重要的收获不是这些数字
> 是**验证方法本身**：
> 1. 用**脉冲响应**测频响，不要用白噪声 FFT（有随机起伏，会误导你）
> 2. 和**解析解**对比，不要只靠耳朵（"听起来对"能骗过你，0.001dB 骗不过）
> 3. 这个测试可以**自动化** —— 以后改代码不会悄悄改坏

## 踩到的坑

1. **过零计数测频率是错的** —— 量化会产生恰好为 0 的样本，把一次过零数成多次。
   详见 [[2026-10-14 第一次验证：过零计数为什么错了]]
2. **白噪声的 amp 语义** —— 高斯分布有长尾，`amp * randn()` 的峰值会超出 amp 好几倍。
   已在 `tools/audio_io.py` 里修正为归一化。
