# 00-Inbox

未整理的碎片。**允许脏。**

## 什么可以丢进来

- 一个链接 + 一句"这个好像有用"
- 一个还没想清楚的问题
- 一段代码片段
- 一张截图
- 一个"我试试这个"的想法

## 规则

> [!warning] 唯一的规则：**定期清空**
> Inbox 满了不整理，这个知识库就退化成了一个收藏夹。
> 建议每周清一次，或者每次让 Agent 处理时顺手清空。

## 处理流程

```
00-Inbox/ 里的东西
   ↓
① 是外部资料？ → 10-Sources/（Agent 写摘要，原文链接保留）
② 是我的想法？ → 20-Notes/
③ 是待验证的？ → 30-Wiki/ 里建 stub 或补进已有页
④ 是待做的？   → 40-Projects/ 或 _meta/roadmap
⑤ 没用了？     → 删掉（不要留着占地方）
```

## 让 Agent 处理

```
读取 00-Inbox 的全部内容。
先搜索 30-Wiki 和 20-Notes 判断是否已有覆盖，
输出处理计划让我确认，然后再动手。
遵守 AGENTS.md 的溯源规则。
```

> [!tip] 现在 Inbox 是空的
> 这是好事。**不要为了填满而填满。**
> 等你真的遇到第一个问题时，再丢进来。
