# 奈奎斯特-香农定理

> [!important] 一句话
> **采样率必须大于信号最高频率的两倍**，否则高频会"伪装"成低频，且**无法事后区分**。

## 定理本身

> [!note] 采样定理（Nyquist–Shannon）
> 若信号 $x(t)$ 的最高频率不超过 $f_{\max}$，
> 那么用采样率 $f_s > 2 f_{\max}$ 采样后，**可以从样本无损重建 $x(t)$**。
>
> - $f_s / 2$ 叫 **Nyquist 频率**
> - $f_s > 2f_{\max}$ 是**严格大于**

**对你的意义**：

| 采样率 | Nyquist | 能无损表示的最高频率 |
|---|---|---|
| 44.1 kHz（CD） | 22.05 kHz | 22.05 kHz 以下 |
| 48 kHz（视频/专业） | 24 kHz | 24 kHz 以下 |
| 96 kHz | 48 kHz | 48 kHz 以下 |
| 192 kHz | 96 kHz | 96 kHz 以下 |

> [!note] 44.1 kHz 是怎么来的
> 人耳上限约 20 kHz，CD 标准留了一点余量 → 22.05 kHz。
> **是历史规格，不是物理必然。**

---

## 一、实测：混叠公式验证

**混叠公式**：采样率 $f_s$ 下，输入频率 $f$ 会折叠到

$$f_{\text{alias}} = \left| f - f_s \cdot \mathrm{round}\!\left(\frac{f}{f_s}\right) \right|$$

**实测**（$f_s$ = 48 kHz，本库验证）：

| 输入频率 | 理论混叠 | **实测主频** | 一致 |
|---|---|---|---|
| 1 000 Hz | 1 000 Hz | 1000.0 Hz | ✅ |
| 20 000 Hz | 20 000 Hz | 20000.0 Hz | ✅ |
| **25 000 Hz** | **23 000 Hz** | **23000.0 Hz** | ✅ |
| **30 000 Hz** | **18 000 Hz** | **18000.0 Hz** | ✅ |
| **47 000 Hz** | **1 000 Hz** | **1000.0 Hz** | ✅ |
| **50 000 Hz** | **2 000 Hz** | **2000.0 Hz** | ✅ |

> [!danger] 关键的可怕之处
> **47 kHz 的信号采样后听起来是 1 kHz。**
>
> 而且这个 1 kHz 和**真实的** 1 kHz **完全无法区分**——
> 它们的样本序列一模一样。
>
> **没有任何后处理能把它分开。** 这是信息论层面的不可逆。

> [!tip] 一个直觉模型
> 想象一个轮子的"马车轮效应"（wagon-wheel effect）：
> 转速超过某个值后，看起来在**倒转**。
> 采样也是一样——超过 Nyquist 后，频率"倒着走"折回来。

---

## 二、为什么必须"严格大于"

**实测边界**（$f_s$ = 48 kHz）：

| 信号最高频 | Nyquist | 能否无损重建 |
|---|---|---|
| 10 000 Hz | 24 000 Hz | ✅ 可以 |
| 20 000 Hz | 24 000 Hz | ✅ 可以 |
| **24 000 Hz** | 24 000 Hz | ❌ **临界，不满足** |
| 25 000 Hz | 24 000 Hz | ❌ 混叠 |

> [!warning] $f_{\max} = f_s/2$ 是临界情况
> 定理要求**严格大于**。而且实践中即使用 $f_s = 2f_{\max}$ 也不行，因为：
> 1. 需要**理想砖墙滤波器**（物理不可实现）
> 2. 任何实际滤波器都有过渡带
>
> **实践做法**：$f_s = 2.5 \sim 5 \times f_{\max}$，给抗混叠滤波器留过渡带。
>
> 48 kHz 采样、音频带宽 20 kHz → 24/20 = 1.2 倍。
> 抗混叠滤波器要在 20–24 kHz 之间从通带到阻带，**这是很陡的要求**。

## 三、混叠的两个方向

> [!important] 混叠发生在**两端**：ADC 和 DAC

| 环节 | 问题 | 解法 |
|---|---|---|
| **ADC（录音）** | 高于 Nyquist 的输入折叠进来 | 采样前加**抗混叠低通** |
| **DSP（处理）** | 非线性产生高于 Nyquist 的成分 | **过采样** 或带限处理 |
| **DAC（播放）** | 采样产生的镜像频谱 | 重建滤波器（硬件已做） |

**录音侧的实测例子**：

| 场景 | 结果 |
|---|---|
| 麦克风录到 30 kHz（超声） | 折叠成 18 kHz，**听得见！** |
| 48 kHz 采样率录 25 kHz | 折叠成 23 kHz |
| 加抗混叠滤波器后 | 30 kHz 被滤掉，无混叠 |

> [!danger] 录音侧的混叠为什么特别麻烦
> 混叠一旦录进文件，就**永久留在那里**了。
> 后期处理无法区分"真实的 18 kHz"和"30 kHz 折回来的 18 kHz"。
>
> 所以 ADC 的抗混叠滤波器是**必须**的（硬件层面已内置）。

**处理侧的混叠**（你这边的责任）：

| 产生混叠的操作 | 为什么 |
|---|---|
| 非线性（失真、饱和） | 产生无限次谐波 → 越过 Nyquist |
| 硬削波 | 同上，且谐波衰减慢 |
| 振荡器（朴素锯齿/方波） | 理想波形带宽无限 |
| 采样率转换 | 需要抗混叠滤波 |
| 量化 | 产生宽频谱 |

见 [[混叠 aliasing]] 和 [[过采样 oversampling]]。

## 四、你实际会遇到的三件事

### 1. 滤波器设计：截止频率不能超过 Nyquist

```cpp
// ❌ 危险：用户可以把截止频率拧到 100kHz
setCutoff (userValue);

// ✅ 钳制到 Nyquist 以下（留余量）
const float maxCutoff = (float) (sampleRate * 0.45);   // 略低于 0.5
cutoff = std::clamp (userValue, 20.0f, maxCutoff);
```

> [!warning] 为什么用 0.45 而不是 0.5
> 双线性变换（bilinear transform）在接近 Nyquist 时**频率翘曲**很严重——
> 你设定的 24 kHz 实际响应可能在 30 kHz 处。
>
> **留 10% 余量**是很常见的做法。见 [[Biquad 滤波器]]。

### 2. 振荡器：高音区必须抗混叠

```
A4 = 440Hz：谐波间隔 440Hz，第 54 次谐波才越过 24kHz
A6 = 1760Hz：谐波间隔 1760Hz，第 13 次谐波就越过了 → 更多混叠
```

**音越高，混叠越严重**。见 [[抗混叠振荡器]]。

### 3. 过采样：给非线性留空间

**实测**（朴素锯齿，$f_0$ = 2 kHz）：

| 方法 | 混叠/谐波 |
|---|---|
| 无处理 | -17.6 dB |
| **4× 过采样** | **-32.4 dB**（改善 14.9 dB） |
| PolyBLEP（另一种思路） | -67.3 dB（改善 49.7 dB） |

见 [[过采样 oversampling]]。

## 五、常见误解

| 误解 | 事实 |
|---|---|
| "96 kHz 录音音质更好" | 只有在**源信号有 >24 kHz 成分**且这些成分有用时才成立 |
| "高采样率能减少混叠" | ❌ **恰恰相反**：它让更多高频进入（如果源有的话） |
| "混叠可以后期修掉" | ❌ 信息已丢失，不可逆 |
| "CD 的 44.1 kHz 不够好" | 对**回放**足够（人耳上限 20 kHz） |
| "采样率高 = 精度高" | 采样率对应**带宽**，位深才对应**动态范围** |
| "Nyquist 频率之上的信号会消失" | ❌ 它们**折回来**，不会消失 |

> [!important] 采样率 vs 位深：两个独立的维度
> | | 决定 | 单位 |
> |---|---|---|
> | **采样率** | 频率**带宽** | Hz |
> | **位深** | 动态**范围** | bit |
>
> 提高采样率不会让量化噪声变小。见 [[位深与动态范围]]。

## 六、AI 会怎么写错

| # | AI 常犯 | 后果 | 怎么查 |
|---|---|---|---|
| 1 | **截止频率不钳制到 Nyquist 以下** | 滤波器发散/异常 | `std::clamp(f, 20, sr*0.45)` |
| 2 | **以为 Nyquist 之上"没有信号"** | 忽略混叠风险 | 记住会折回 |
| 3 | **说"采样率越高音质越好"** | 概念错误 | 区分带宽与动态范围 |
| 4 | **用 `f_s/2` 而不是 `0.45 f_s` 做上限** | 双线性变换翘曲 | 留余量 |
| 5 | **过采样倍率不够**（非线性） | 混叠残留 | 实测混叠能量 |
| 6 | **以为混叠可以后期修复** | 概念错误 | 不可逆 |
| 7 | **混淆 Nyquist 频率与 Nyquist 采样率** | 差 2 倍 | Nyquist **频率** = fs/2 |
| 8 | **采样率转换不做抗混叠** | 降采样时严重混叠 | 先低通再抽取 |
| 9 | **以为 44.1k 和 48k 音质有差** | 都是"足够"的 | 看源信号带宽 |

> [!danger] 第 8 条最容易被忽略
> **降采样（如 96k → 48k）必须先低通滤波**，
> 否则 24k 以上的成分会折叠回来。
>
> AI 常写的 `x[::2]`（简单抽取）**就是错的**——它等价于无抗混叠的降采样。
> 见 [[采样率转换 resampling]]。

## 七、常见坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 滤波器在高频异常 | 截止频率超过 Nyquist | 钳制到 0.45·fs |
| 高音区"金属味" | 振荡器混叠 | 抗混叠（PolyBLEP/过采样） |
| 失真后声音变脏 | 非线性产生混叠 | 过采样 |
| 降采样后有怪声 | 没做抗混叠滤波 | 先低通再抽取 |
| 混响/调制效果有刺耳高频 | 反馈路径的非线性 | 检查反馈里的非线性 |
| 高频滤波器不稳定 | 双线性变换翘曲 | 留余量，或用 TPT |

## 八、怎么验证

```python
import numpy as np

def check_aliasing (f_in, fs=48000.0, n=48000):
    """验证某频率采样后会折叠到哪里"""
    t = np.arange (n) / fs
    x = np.cos (2*np.pi*f_in*t)           # 用 cos 避免相位问题
    X = np.abs (np.fft.rfft (x))
    fr = np.fft.rfftfreq (n, 1/fs)
    measured = fr[np.argmax (X)]

    k = round (f_in / fs)
    theory = abs (f_in - k*fs)
    return measured, theory

print (f"{'输入':>9} {'理论混叠':>10} {'实测':>10}")
for f_in in [1000, 20000, 25000, 30000, 47000]:
    m, t = check_aliasing (f_in)
    flag = "✅" if abs(m-t) < 1 else "❌"
    print (f"{f_in:>8}Hz {t:>9.0f}Hz {m:>9.1f}Hz  {flag}")
    assert abs(m-t) < 1, f"{f_in}Hz 混叠计算不符"

print ("✅ 混叠公式验证通过")
```

**你的插件里的自检**：

```python
# 检查你的滤波器在极端参数下是否还在合理范围
def check_filter_safe (fc, fs):
    nyq = fs / 2
    assert fc < nyq, f"截止频率 {fc} 超过 Nyquist {nyq}！"
    if fc > 0.45*fs:
        print (f"⚠️ {fc}Hz 接近 Nyquist，双线性变换会翘曲，建议钳制到 {0.45*fs:.0f}Hz")
    return True
```
