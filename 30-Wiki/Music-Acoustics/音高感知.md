# 音高感知

> [!important] 一句话
> **音高不是"最低的那个频率"**——大脑从**谐波的整体模式**推断音高。
> 所以基频不存在时，你仍然能"听到"它。

## 为什么 DSP 开发者要懂

| 场景 | 需要什么 |
|---|---|
| **音高检测/调音器** | 知道人耳靠什么线索 |
| **变调** | 保持谐波关系才自然 |
| **减法合成** | 滤掉基频后音高**不变** |
| **电话/低音音箱** | 缺失基频现象 |

---

## 一、⚠️ 实测：缺失基频（本库验证）

**测试**（$f_0 = 220$ Hz）：

| 配置 | 自相关测得的音高 |
|---|---|
| 含 $f_0$（220, 440, 660, 880, 1100） | **220.2 Hz** |
| **缺 $f_0$**（只有 440, 660, 880, 1100） | **220.2 Hz** ✅ |

> [!important] 基频不存在，音高仍然正确
> **这就是"缺失基频"（missing fundamental）现象。**
>
> 自相关在 $1/f_0$ 处仍有明显峰——因为
> **440/660/880/1100 的最大公约数是 220**，它们的共同周期就是 $1/220$。

> [!tip] 生活中的例子
> | 现象 | 解释 |
> |---|---|
> | **电话里能听出男低音的音高** | 电话只传 300 Hz 以上，基频被切掉 |
> | **小音箱"听得到"低音** | 耳机放不出 50 Hz，但谐波让你"听到"了 |
> | 管风琴的低音音栓 | 故意强调谐波 |
>
> **实用**：小扬声器上做低音增强，**加谐波比加基频更有效**。

---

## 二、实测：非谐波破坏音高感

| 配置 | 自相关测得的音高 |
|---|---|
| **严格谐波**（$1,2,3,4,5,6 \times 220$） | **220.2 Hz** ✅ |
| **非谐波**（拉伸 $1, 2.1, 3.3, 4.6, 5.9, 7.3$） | **230.8 Hz** ⚠️ |

> [!important] 大脑要的是"谐波关系"
> 当分量是整数倍时，它们在 $1/f_0$ 处**同时回到同相** → 清晰的周期。
>
> 非谐波时**没有共同周期** → 音高感模糊 → "金属声"/"不准"。
>
> 见 [[谐波与泛音列]]。

## 三、音高的三个感知维度

> [!note] 音高不只是"频率高低"

| 维度 | 说明 |
|---|---|
| **音高高度**（pitch height） | 频率越高越"高" |
| **音级**（pitch chroma） | 八度等同（220 和 440 是"同一个音"） |
| **音高强度**（pitch strength） | 音高感有多明确 |

> [!important] 八度等同（octave equivalence）
> 220 Hz 和 440 Hz 听起来"是同一个音，只是高低不同"。
> 这是**所有音乐文化共有**的现象（虽然解释有争议）。
>
> **实用**：频率轴应该用**对数**（见 [[JUCE 的 Slider 与旋钮]]）。

## 四、频率与音分（cents）

$$\text{cents} = 1200 \log_2\left(\frac{f_2}{f_1}\right)$$

| 音程 | cents | 频率比 |
|---|---|---|
| 八度 | **1200** | 2:1 |
| 纯五度 | ~702 | 3:2 |
| 半音（十二平均律） | **100** | $2^{1/12}$ |

> [!tip] 实用换算
> | 变化 | 听感 |
> |---|---|
> | **< 5 cents** | 训练有素的人能察觉 |
> | 10 cents | 多数人能听出"不准" |
> | 50 cents | 明显走音 |
> | 100 cents | 一个半音 |

> [!danger] 本库实测过的一个坑
> Karplus-Strong 合成 880 Hz 时，**整数延迟**导致误差 **−0.83%** =
> 约 **14 音分** → **明显可闻的音不准**。
>
> 见 [[物理建模]]。

## 五、音高检测的两种方法

> [!important] 时域 vs 频域

| 方法 | 原理 | 优点 | 缺点 |
|---|---|---|---|
| **自相关** | 找波形自身的周期 | ✅ 能处理缺失基频 | 八度错误（octave error） |
| **FFT 峰值** | 找最低的显著峰 | 简单 | ❌ **缺基频时失败** |
| **YIN / pYIN** | 改进的自相关 | ✅ 较准 | 计算量大 |
| **HPS**（谐波积谱） | 各次谐波相乘 | 抑制八度错误 | 需要 FFT |

> [!danger] FFT 峰值法在缺基频时会错
> 实测：缺 $f_0$ 时，"最低的显著峰"是 **440 Hz**——
> 你会上报 440（高一个八度）。
>
> **自相关给出正确的 220。**
>
> **判据**：你的音高检测在"只有谐波没有基频"的输入上还准吗？

**自相关实现**：

```python
import numpy as np

def detect_pitch_autocorr (x, sr=48000.0, fmin=50.0, fmax=2000.0):
    """自相关音高检测（本库验证有效）"""
    x = x - np.mean (x)                     # ⚠️ 必须去直流
    # 限制搜索范围能避免八度错误
    lo, hi = int (sr/fmax), int (sr/fmin)
    ac = np.correlate (x, x, mode='full')[len(x)-1:]
    seg = ac[lo:hi]
    if len (seg) == 0:
        return 0.0
    return sr / (lo + np.argmax (seg))
```

> [!warning] 自相关的三个坑
> | # | 坑 | 解法 |
> |---|---|---|
> | 1 | **没去直流** | `x -= mean(x)` |
> | 2 | **搜索范围太宽** → 八度错误 | 限定 `[fmin, fmax]` |
> | 3 | **`np.correlate` 是 O(n²)** | 大信号用 FFT 自相关 |
>
> 第 3 条本库实测过：4 秒 @48kHz 的 `np.correlate` 要跑几分钟。

## 六、AI 会怎么写错

| # | AI 常犯 | 后果 | 怎么查 |
|---|---|---|---|
| 1 | **用 FFT 最低峰当音高** | 缺基频时高一个八度 | 用自相关 |
| 2 | **自相关不去直流** | 直流峰压过真实峰 | `x -= mean(x)` |
| 3 | **搜索范围不限** | 八度错误 | 限定 `[fmin,fmax]` |
| 4 | **用 `np.correlate` 处理长信号** | 慢到不可用 | 用 FFT |
| 5 | **以为音高 = 最低频率** | 概念错 | 是"感知"不是"物理" |
| 6 | **用线性频率轴做音乐参数** | 手感差 | 用对数 |
| 7 | **忘记音分换算** | 误差判断错 | 1200·log2(比值) |
| 8 | **在非整数周期上测** | 频谱泄漏 | 用整数周期 |

> [!danger] 第 1 条是最常见的实现错误
> ```python
> fft = np.abs(np.fft.rfft(x))
> f0 = freqs[np.argmax(fft)]        # ❌ 缺基频时错一个八度
> ```
> 这在**纯正弦**上工作正常，所以 AI 和测试都不会发现。
> **只有在真实的乐器音上才暴露。**

## 七、常见坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 音高差一个八度 | FFT 峰值法 / 搜索范围太宽 | 自相关 + 限范围 |
| 音高检测失败 | 没去直流 | `x -= mean(x)` |
| 检测很慢 | O(n²) 自相关 | 用 FFT |
| 低音检测不到 | 基频被滤掉 | 用自相关（抗缺基频） |
| 旋钮手感差 | 线性频率轴 | 对数刻度 |
| 变调后不自然 | 谐波关系被破坏 | 保持谐波 |

## 八、怎么验证

**四个必做测试**：

| # | 测试 | 判据 |
|---|---|---|
| 1 | **纯正弦** | 检测值 = 频率 |
| 2 | **缺失基频** ⭐ | 检测值仍 = $f_0$（不是 $2f_0$） |
| 3 | **带谐波的乐器音** | 检测值 = $f_0$ |
| 4 | **频率扫描** | 单调跟随 |

```python
import numpy as np
SR = 48000.0

def detect_pitch_autocorr (x, sr=SR, fmin=50.0, fmax=2000.0):
    x = x - np.mean (x)
    lo, hi = int (sr/fmax), int (sr/fmin)
    ac = np.correlate (x, x, mode='full')[len(x)-1:]
    seg = ac[lo:hi]
    return sr / (lo + np.argmax (seg)) if len (seg) else 0.0

t = np.arange (int(SR))/SR
f0 = 220.0

# ① 纯正弦
sine = np.sin (2*np.pi*f0*t)
print (f"  纯正弦:     {detect_pitch_autocorr(sine):>7.1f} Hz")

# ② ⭐ 缺失基频（只有 2f0, 3f0, 4f0, 5f0）
missing = sum (np.sin (2*np.pi*f0*n*t) for n in [2,3,4,5]) / 4
p = detect_pitch_autocorr (missing)
print (f"  缺基频:     {p:>7.1f} Hz  (期望 {f0})")
assert abs (p - f0) < 5, "缺失基频时音高检测失败！"

# ③ 带谐波的复杂音
rich = sum (np.sin (2*np.pi*f0*n*t)/n for n in range(1,11))
p2 = detect_pitch_autocorr (rich)
print (f"  10 次谐波:  {p2:>7.1f} Hz")
assert abs (p2 - f0) < 5

print ("  ✅ 全部通过")
```

> [!important] 第 2 条是**唯一能区分好坏实现**的测试
> 纯正弦上，FFT 峰值法和自相关**都能通过**。
> **只有缺失基频的测试能把它们分开。**
>
> 而真实的乐器音、电话音、小音箱回放**都是缺基频的**。
